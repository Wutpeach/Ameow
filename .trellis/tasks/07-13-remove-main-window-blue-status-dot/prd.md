# Remove main window blue status dot

## Goal

Remove the persistent blue status dot from the lower-left area of the main window so the compact surface feels quieter and more consistent with Ameow's minimal desktop-edge control language.

## Requirements

- Remove only the main window's blue status dot.
- Preserve the orange bootstrap/runtime status dot or indicator behavior.
- Preserve the Settings UI's automatic cookie update feature and related controls.
- Avoid unrelated layout, copy, or behavior changes.

## Acceptance Criteria

- [x] The main window no longer shows the persistent blue status dot in the lower-left area.
- [x] The bootstrap/runtime orange status indicator remains visible and functional wherever it currently appears.
- [x] Settings still expose and retain the automatic cookie update behavior.
- [x] No unrelated visual or behavior changes are introduced.
