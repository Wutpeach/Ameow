# Managed runtime provenance and notices

Stage A downloads only the fixed Windows x64 publisher releases in runtime-manifest.json. No binaries are shipped in this source tree; the managed cache is prepared by the app. Official HTTPS release/checksum matches are verified by SHA-256; detached signatures were not verified. Digest mismatch fails closed.

Source and complete notices: https://github.com/yt-dlp/yt-dlp/tree/2026.08.19 and its LICENSE/THIRD_PARTY_LICENSES files. This release bundles EJS 0.8.0 (Unlicense; meriyah ISC and astring MIT notices), https://github.com/yt-dlp/ejs/tree/0.8.0.
- Deno 2.9.7: MIT with third-party notices, official source/LICENSE https://github.com/denoland/deno/tree/v2.9.7.
- FFmpeg 9.0.2-essentials_build-www.gyan.dev: GPL-3.0-or-later static Windows x64 build from Gyan, a Windows build provider linked by https://ffmpeg.org/download.html. Fixed release/asset: https://github.com/GyanD/codexffmpeg/releases/tag/9.0.2 (ffmpeg-9.0.2-essentials_build.zip). FFmpeg source: https://github.com/FFmpeg/FFmpeg/tree/n9.0.2 (release commit 946fcce07b); builder information/dependency notices: https://www.gyan.dev/ffmpeg/builds/ and the archive README.txt. Archive SHA-256 60f467265b1e312373dbcd92200c2618a74850f98d3d078e94296bb3fa2047ba matches both the GitHub asset digest and the publisher versioned .sha256 at https://www.gyan.dev/ffmpeg/builds/packages/ffmpeg-9.0.2-essentials_build.zip.sha256. Archive includes LICENSE (GPLv3); the full GPL text is retained next to these notices. Native probes confirm --enable-gpl/--enable-version3 and no libfdk-aac. This replaces the unavailable dated yt-dlp FFmpeg autobuild; no rolling latest URL is used.

Runtime acquisition, cache integrity and source/license pointers are Stage A engineering artifacts. Redistribution/Portable ZIP with complete corresponding source and notices is a separately gated Stage C deliverable; no compliant ordinary-user ZIP is claimed here.
