# Design

## Context

沿 PR63 的扩展/stdio bridge 和 CLI 的当前用户桌面 IPC 实现；研究报告与用户最新决定见 proposal。独立树 base=13107cef，不合入 main/PR61。

## Goals / Non-Goals

**Goals:** 页面复用原播放链路，任务走既有 Coordinator/Accepted/验证发布。

**Non-Goals:** 不重建下载服务、不引入媒体预览库、不模拟文件完成。

## Decisions

- 范围以整数毫秒表达，结构内固定原生快速粗切策略；去重和重试仍使用同一冻结范围，不添加精确/粗切模式。
- 页面薄适配确认作品 URL、视频节点与分 P，UI 通过隔离 Shadow DOM 复用；不信任页面传来的任意媒体地址。启用标志存扩展本地，Cookie 授权保有独立状态。
- Peek 使用原播放器根与占位锚点进入 dialog 顶层，保存原样式/控制栏状态并在所有退出路径恢复。2026-11-20 专属 CfT 的两站公开点播验证了同节点/同源/同位置恢复；入口等待媒体就绪，播放器变化立即撤销。
- Native Messaging 增加只负责下载提交的消息，桥接调用现有 control 客户端启动/握手/真实受理逻辑，拒绝未知字段和旧能力。
- yt-dlp 原生 download-sections 让 FFmpeg 在远程输入寻址后复制流，不强制关键帧重编码。保持原选流 codec 并复用 MKV remux，计划只要求实际选中的音轨。输出允许前置 GOP，但超出所选时长10秒、明显截短或已知整源冒充片段均拒绝；这是支持边界，不是精确切点承诺。不提供完整下载后裁剪回退。
- 动效焦点为原播放器居中与返回的空间连续性；工具条向左展开且猫命中固定。CSS/WAAPI 在现值反向，拖动即时，低动效减少位移，空闲不 RAF 循环。

- 2026-11-20 用户试用反馈覆盖旧纯图标展开/tooltip 约束：入口高28px，展开为146px胶囊和12–13px图标/13px文字，下载组在右，展开状态无分隔、无 tooltip。Peek 使用32px控制、单一合并轨道及可编辑 I/O；800px宽时工具栏70px高（含分秒刻度与分层命中），窄窗紧凑折行。字体在 Shadow DOM 内层明确设置，避免继承站点衬线字。原播放器恢复、草稿、权限、真实 ACK 与快速粗切契约保持。

- 主轨道使用上层播放定位、两端24px命中及下沿选区平移命中分区；播放头是细线/顶帽，I/O 为蓝色端点与区间带。短选区两端命中向外展开，整体平移下沿至少24px宽；时间框与键盘继续提供毫秒编辑，增加仅切换可见窗口的「聚焦选区 / 全片」，显示窗口留必要前后余量；标尺、拖动和缓冲共用窗口映射，播放头越窗隐藏并显示方向提示，不做自由缩放。平移保长度并整体夹边，不改变播放位置。刻度按实际轨道宽与源时长选间隔，缓冲底层只读原媒体 buffered，不采集媒体分析。

## Risks / Trade-offs

- [站点 DOM/广告和时间映射变化] → 局部不可用，保留可解释原因；不宣称站点通用。
- [范围取数不一定省流] → 页面说明可能额外取数；失败保持明确，不整段暗降级。
- [关键帧带来的边界偏差] → 明确粗切，只验证有限偏差和实际内容/同步；长源短区间以服务器实际响应字节验证部分取数，不用成品时长代替网络证据。
- [独立原生测试与浏览器权限] → 所有 profile/注册/实例/输出为任务私有，权限预授证据与原生同意 UI 分开。


## 2026-11-20 Marker 试用反馈修订

用户新反馈覆盖上一轮“所有底部控件单行”：改为预览→全宽轨道→低矮图标栏。单 Marker 按钮首击建入标、再击补范围；完整范围再击更新出点，早于入点时保留原范围并提示。Alt 按下的左右侧固定本次入/出端，从单点可向左/右创建区间；精确输入按需展开，保留键盘与原冻结范围协议。

上方剪刀/下方broom-sparkles使用固定 Lucide 官方 SVG 与许可（不加运行依赖），Marker自绘一致网格/描边的向下尖角形，猫用原托盘资产。胶囊下载文字使用固定内容布局、裁剪显隐，避免宽度插值挤字。B站匿名真实DOM确认弹幕渲染顶层为bpx-player-render-dm-wrap；仅在原播放器带Peek类时隐藏，退出移除类即恢复，不调用站点弹幕开关。键盘基线实测按钮焦点吞掉I/O、舞台焦点正常；新处理将I/O与Space的交互控件排除规则分开，保护文本输入和原生按钮激活。
