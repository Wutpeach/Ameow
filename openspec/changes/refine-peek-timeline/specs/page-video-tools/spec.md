# Spec Delta

## MODIFIED Requirements

### Requirement: 原播放器可恢复 Peek
I/O SHALL 在页面中央打开带遮罩的 Peek，暂停背景滚动，沿用原播放器节点、播放链路及位置，隐藏并恢复原控制栏，提供播放/暂停、进度定位、可拖动与键盘调整的 I/O 和区间时长。布局 SHALL 从上到下依次为视频预览、独占宽度时间轴、低矮图标工具栏；移除时间编辑按钮和展开输入区，保留 I/O、标记拖动、方向键调整与时间显示。主轨道保留进度、标记/区间、刻度与缓冲分工，把手支持键盘操作，明确设置系统 UI 字体与行高。宽屏与320窄窗均不得横向溢出。B站 Peek 仅临时隐藏已确认的弹幕渲染容器，不更改站点偏好或隐藏字幕，所有退出/销毁路径恢复。Esc 或点遮罩 SHALL 恢复原位置、控制栏及焦点，同作品草稿保留；不得新建媒体链路、重载 iframe 或移除 CSP。

#### Scenario: 主轨道交互与状态
- **WHEN** 用户在主轨道编辑单区间
- **THEN** 自适应分秒刻度、独立细线/顶帽播放头、双端 I/O 与区间带分别呈现；空/单端草稿不显示有效整段选区，提交保持禁用。点击或拖动播放定位不平移选区；拖动区间内部保持时长并在源边界整体夹住，时间显示同步。悬停显示位置时间，边界/选区拖动显示操作时间与选区时长，拖动无缓动滞后；短选区的两个把手与平移命中分开，仍可分别拖动与键盘精调。可用缓冲范围为淡底层，seeking/buffering 给就近等待反馈并保留同作品草稿。

#### Scenario: 展示文字与时间编辑
- **WHEN** 用户拖动或双击 Peek 展示文字，或聚焦站点可编辑内容
- **THEN** 刻度、时间/时长、提示及工具栏等展示文本不可被浏览器选中；输入和可编辑内容保持原生选择、光标、键盘编辑。禁选仅作用于本浮窗，不影响宿主页文字，不用全局 preventDefault 抢走焦点或时间轴操作。

#### Scenario: 长视频短区间聚焦
- **WHEN** 用户点击聚焦按钮或在活动 Peek 按 F
- **THEN** 无标记或双端草稿无效时聚焦禁用；单标记聚焦附近，完整范围聚焦选区，再按返回完整时间轴。按钮与 F 共用行为、可用性和当前动作提示；仅改变可见时间窗口，I/O 和播放位置保持；刻度、悬停、指针换算、缓冲与标记共用同一映射。播放头不在视窗内时正确裁剪并显示方向提示，不钳成假的边界位置。聚焦后的双端与平移区仍可编辑，约束使用真实源边界；不增加自由缩放、滚轮导航或第二条轨道。

#### Scenario: 清除与关闭
- **WHEN** 用户清除 I/O 后仍留在 Peek
- **THEN** 只清草稿，片段提交禁用，不转为整段下载也不取消已提交队列任务；关闭后恢复原页。

#### Scenario: 单一下载胶囊与退出入口
- **WHEN** 用户进入切片浮窗并设置片段或退出浮窗
- **THEN** 底栏右侧提供现有Ameow纯色图标与「下载」文字组成的胶囊，左邻为精确模式开关，不另设关闭按钮；下载保留可访问名称、浅深/禁用态和等待/受理反馈。点击浮窗外或Esc返回后，页面右上胶囊、同作品草稿和页面工具开启偏好保留，可反复重新打开；显式关闭页面工具仍移除浮窗与胶囊并记住关闭偏好。


#### Scenario: 聚焦快捷键边界
- **WHEN** Peek 关闭、正在退出、输入文本、组合输入或按下修饰组合键
- **THEN** 不执行 F 聚焦；活动 Peek 内普通 F 被隔离于站点全屏键，无标记时只不执行聚焦，不误触站点全屏。

#### Scenario: 播放头抓手与重合命中
- **WHEN** 用户悬停、键盘聚焦或拖动播放位置，或播放头与标记重合
- **THEN** 中性色实心尖头抓手与贯穿轨道细线显示当前位置，入出标记保持蓝描边；实际抓手命中扩大且有局部反馈，拖动就近显示时间并在结束后收起。标记、播放头和区间平移分区可分别操作，浅深主题可辨，不新增常驻提示栏。

### Requirement: 片段精确模式按次选择

Peek SHALL 在下载按钮左侧提供32px高、勾选标记加「精确」文字的固定宽度按钮。默认关闭，开启有勾选及轻微选中底色，hover和键盘focus明确点击后开启或关闭精确切分，并说明重新编码可能耗时更长、快速切分边界可能略有偏移；不可用时只说明当前等待状态，不宣传可操作。Tab可聚焦、Space可切换，不另弹确认或toast。同作品关闭重开保留模式，清标记保留模式，换视频或分P重置关闭。切换不改变选区或播放位置；320px窄窗不得溢出。提交等待时禁用开关，拒绝保留选择。

#### Scenario: 模式草稿生命周期

- **WHEN** 用户开启精确、清除或调整标记、关闭重开同作品，再切换分P
- **THEN** 同作品的精确选择保留，切换分P后恢复关闭，所有切换均不修改已受理任务。

#### Scenario: 提交及旧端能力

- **WHEN** 提交精确片段，桥接或桌面未明确声明精确能力
- **THEN** 明确拒绝并保留草稿，不发送可被解释为粗切的请求；正常提交将范围与模式一起冻结，等待期间开关不可操作。
