# Proposal

## Why

本人已确认最终 MP4 样片在 DaVinci Resolve 和 Premiere Pro 中播放及声音正常，但日常开发实例被组件准备失败阻断。切片浮窗的播放头抓手、刻度定位及提示位置也与本人实际使用预期不符。

## What Changes

- 已选下载器版本全部等于编译推荐时，保持用户选择策略，通过编译可信清单正常准备推荐组合，补齐缺失推荐依赖；不同版本仍按原签名及离线认证合同。
- 左下工具栏增加键盘图标，按需展示现有快捷键；tooltip 保留动作名称和必要说明，不承担快捷键列表。
- 移除播放头独立拖拽手柄，保留细线及顶部小三角；刻度区支持点击和按住拖动定位，标记和区间仍独立操作。
- 修复工具按钮 tooltip 额外上移进入视频的问题，保留附近可读提示及键盘访问。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `runtime-management`：明确与编译推荐完全一致的显式选择可使用编译可信推荐准备，同时保留选择意图。
- `page-video-tools`：快捷键帮助、刻度区定位与播放头展示和提示位置。

## Impact

`runtime_update_trust.rs`、页面工具及原有浏览器交互检查、中英文手册草稿和设计参考。无新依赖、发行或账号操作。
