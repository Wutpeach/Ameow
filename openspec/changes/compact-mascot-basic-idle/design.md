# Design

## Context

动机和边界见 proposal.md。基线为本地 main 03c8fa53；origin/main 124f3720 是其祖先。现有 main 统一负责窗口形变与唤醒，Compact 60px、native 80px；现有 GPUI 已提供原生 SVG 栅格器和纹理绘制，无需新增依赖。

## Goals / Non-Goals

**Goals:**
保留 Figma 5:276/5:277 的 60px 几何和分层，在局部姿态上动画；行为与绘制为清晰独立模块。Light 依照 3:155 黑猫的实际填充/渐变修正，Night 白猫继续沿用。

**Non-Goals:**
不建立通用动画框架，不重构窗口/平台权威，不把 preview 或本机检查作为用户发行验收。

## Decisions

- 主题配色修正阶段，用户授权在指定 Compact 源稿内修改颜色：先将 5:276 的 16 个猫咪部件填充映射到 Page 1 / 3:155 对应层，移除其五处白猫专用浅灰描边，当时保留前景/细线和几何；再导出新版 SVG。Night 猫咪保持原样。5:279 展示画板背景同步应用 Compact 的 #232427。Page 1、v02/v03 和其他图标方案不改。
- 文件当前没有变量或共享 paint style，直接复用原稿精确 RGBA、gradientTransform 和 stops；黑猫浅眼窝、深瞳孔、白高光与灰鼻子从原稿映射，不反相。窗口圆底继续由应用 Palette 管理，不引入 1024px 图标底板/底托。
- 用户选定沿口探索页 19:426 / A frame 19:437 的圆润小窗沿。将原生 60px Light/Night 沿口组分别复制到正式 5:276/5:277，替换原前景与细线，保持猫咪 16 层、主题背景、裁剪及爪子位置。新版导出只替换应用 SVG 的固定前景层，沿口渐变和接触阴影依赖使用独立 ID；动作模块、窗口和主题 owner 不改。A/B/C 草案与 Page 1 原参考保留。
- 将只读导出的 SVG 按耳朵、头部、眼窝、瞳孔、高光增加原生变换组，不改路径。GPUI 自带 SVG 栅格器按当前 DPI 将该姿态绘制为纹理，保留多段渐变与 inside stroke。避免把原图整张 PNG 拉伸，也避免 GPUI 双色 gradient 丢失原多段渐变。
- 只缓存当前姿态/主题/DPI 的图像，替换时释放旧 atlas 图像；休止姿态复用缓存。动态图像仍由精确矢量姿态生成，不使用外部浏览器、Rive、Lottie 或预烘焙帧序列。
- 小型行为模块使用可见时间与有限变化时间表，三个局部通道可组合；隐藏时冻结最近姿态，恢复首帧不追赶墙钟。Reduced Motion 采用现有静止终态策略。
- main 只采样姿态、合入最早唤醒并显示 60px 猫咪；Full 目标激活即暂停，不增锁。原形变过程中只淡出/淡入猫咪，原 surface 几何仍归现有 owner。
- 原收起回弹会短暂压缩圆窗到 60px 以下；猫咪保持原素材坐标，由实际圆窗边界裁剪，避免前景越界。
- 隐藏/恢复的原生复验发现 GPUI 可见性缓存滞后；沿用当前 Native 适配器增加 `visible()` 读取所属窗口的显示/最小化状态，visibility 观察回调负责暂停可见时间。不重构平台消息或下载轮询。

## Risks / Trade-offs

- [动态 SVG 的解析与栅格成本] → 仅动作期间更新，当前图像有界；原生检查记录帧数和局部生成耗时，发生性能问题再扩大。
- [高 DPI 与 60px 视觉] → 使用当前 window scale 栅格，实际尺寸截图和高 DPI 原生运行分别记录；不把放大图当实尺寸证据。
- [平台差异] → 本轮 Windows 验证，绘制/行为无需 Win32；macOS 原生效果仍未验证。
- [窗口被完全遮挡] → 当前 Windows 后端缺少可靠遮挡通知，完全被其他窗口遮挡时仍可能播放；这是本轮明确限制，不声称该场景已通过。
