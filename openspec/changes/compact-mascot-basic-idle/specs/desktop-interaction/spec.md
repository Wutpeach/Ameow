# Spec Delta

## ADDED Requirements

### Requirement: Compact 基础猫咪待机

Compact SHALL 在实际 60px 圆窗内使用 Light 黑猫、Night 白猫，随现有主题切换。Light 配色/渐变来自指定 Figma「Ameow · B · 雾白黑猫」，背景使用现有 Compact 主题色，不引入应用图标底板或底托；保留已认可的构图、分层和圆形裁剪。爪子和前景下沿保持稳定。待机以低频眨眼为主，偶尔眼先动、停顿、头部轻跟随和左右错时耳动；不持续整图浮动或缩放，不显示下载信息，也不追踪鼠标。

#### Scenario: 主题切换

- **WHEN** 现有主题机制选择 Light 或 Night
- **THEN** 分别显示黑猫或白猫，使用该主题 Compact 背景；动作节奏与 60px 构图保持一致。

#### Scenario: 猫咪安静待机

- **WHEN** Compact 持续可见
- **THEN** 眨眼闭合与重开连贯，眼窝、瞳孔和高光协调；观察与耳动之间保留安静停顿，支点稳定且部件不越界。

### Requirement: 猫咪动作服从可见性与交互

猫咪 SHALL 从最近可见姿态接续，动作收尾自然回到当前待机。Compact 不可见或 Full 活跃时停止猫咪的持续刷新；减少动态时呈现静止待机并停止其唤醒。猫咪行为不得新增交互锁、延迟下载触发的 Full 展开或改变既有返回 Compact 的逻辑。

#### Scenario: 动作中展开再收起

- **WHEN** 猫咪动作途中触发现有 Full 展开，随后返回 Compact
- **THEN** 立即遵循既有窗口切换，隐藏期间不追赶动作时间，恢复时从最近可见姿态接续。

#### Scenario: 开启减少动态

- **WHEN** 系统或项目现有减少动态机制生效
- **THEN** 猫咪静止、无额外动画唤醒，下载与窗口操作继续按原有权限执行。
