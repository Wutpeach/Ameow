# Spec Delta

## ADDED Requirements

### Requirement: 单一全局呼出快捷键

Primary GUI SHALL 在运行期间支持一个可配置的普通修饰组合，用于呼出或隐藏同一下载浮窗。默认 SHALL 为 Ctrl+Shift+F，有组合即启用、清空即关闭；CLI、更新器、重复实例及预览不得注册生产组合。呼出不读取剪贴板，下载与设置窗口生命期保持独立，不额外创建常驻服务或全局输入监听。

#### Scenario: 从隐藏或 Compact 呼出
- **WHEN** 已启用且注册成功的组合在其他应用中被按下一次
- **THEN** 同一浮窗显示 Full、取得粘贴键盘焦点并保持，鼠标在外不立即收起；只有用户随后粘贴才沿既有下载入口读取剪贴板。

#### Scenario: 后台 Full 和再次隐藏
- **WHEN** Full 可见但未取得键盘焦点，或 Full 已持有键盘焦点
- **THEN** 前者按组合先聚焦，后者按组合隐藏下载浮窗；设置窗口不被关闭，后台下载继续。按住组合不反复切换。

#### Scenario: 释放键盘保持
- **WHEN** 用户按最外层 Esc 或浮窗失去键盘焦点
- **THEN** 释放键盘保持后交原有鼠标、下载、菜单和终态仲裁；已有内部 Esc 优先级不变，不统一改为失焦或 Esc 隐藏。Mac Compact 的 Spaces／不覆盖其他应用全屏约束及面板焦点模式继续成立，不保证跨所有桌面原地呼出。

### Requirement: 常规页的快捷键配置

常规设置 SHALL 仅增加小型“快捷键”区与一项“呼出／隐藏 Ameow”，支持录入、修改与清空，不提供独立启用开关，并沿用设置 owner、主题、双语及可访问键盘导航。不得列出其它操作按键、说明清单或独立快捷键页面。正常状态无说明卡；冲突和保存错误在控件附近简短反馈。

#### Scenario: 录入和取消
- **WHEN** 用户进入录入、按 Esc、用 Tab 离开或关闭设置
- **THEN** 录入期间旧组合不触发自身动作；Esc 取消录入且不关闭设置，Tab 可离开，未应用草稿不保存；退出录入恢复旧注册或准确显示恢复失败。

#### Scenario: 修改与清空
- **WHEN** 用户应用新组合或清空快捷键
- **THEN** 只在实际保存成功后确认新设置；新组合不可注册或保存失败时保持或恢复旧绑定并显示真实失败。非空新组合在成功保存后启用；清空成功后取消注册且保存为空，正常重启仍保持关闭，不自动恢复默认或换成其它组合。

### Requirement: 原生注册资源与实际状态

快捷键 SHALL 区分已保存偏好与实际注册结果，冲突时保留修正入口，不把注册成功等同于焦点已取得。实例结束、正常退出及应用替换时释放所属注册和回调。原生窗口显示继续避免合成 Alt、抢夺后台 CLI 焦点或要求默认管理员及输入监视权限。

#### Scenario: 启动冲突与退出释放
- **WHEN** 启动时组合已被占用，或本实例退出
- **THEN** 前者显示不可用且不偷换组合，后者释放注册使同一组合能由另一个实例登记；未运行时该注册不负责启动应用。
