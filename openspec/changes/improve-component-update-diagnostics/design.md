# Design

## Context

见 proposal.md。RuntimeUpdateSnapshot 已保留更新对象及目标/实际版本；UpstreamError 有 HTTP 数值但更新 trust 层将其降为通用字符串。复制准备诊断缺少组件身份和 upstream 检查结果。

## Goals / Non-Goals

提供可定位且安全的组件诊断，不改变当前 UI 布局、复制入口、选择持久化、可信验证或切换门。推荐版本维护不覆盖用户已选意图，不修改其他组件版本或已发布资产。

## Decisions

- 为快照增加可选失败对象，阶段/服务/类别采用闭集枚举，状态和重试时间采用数值。旧反序列化使用默认空值；不用未经筛选的错误文字携带网络上下文。
- 网络边界记录真实请求服务及响应状态，只导出数值重试时间；合法 HTTP-date 用已锁定的 chrono 转为 Unix 秒，不新增包。验证及本地启用阶段清空前一请求的 HTTP 上下文，避免把成功下载状态误归到本地失败。
- trust 在正在处理的组件上保留上下文，准备失败通过队列原有 owner 返回路径传入快照；失败对象独立携带实际组件及其目标/已验证版本，downloader 保留操作对象。失败不改变当前选择，保留具体缓存错误。
- 现有 UI 复制出口合并 upstream 检查与队列安全诊断，两个组件各占独立行，整体仍限 4096 ASCII 字节。
- 检查按组件维护并持久化代际，选择/恢复按协调器 owner 维护代际。受理接口在原有状态锁内返回代际与时间；检查合并复用同一代际，旧结果另外保留结果代际。最近状态被后续操作替代时，消费方据代际识别未知或替代，不增加后端操作历史账本。CLI 负责操作 ID 与回执绑定。
- 清单使用正式资产实际 bytes/hash，并对 Mac wheel 派生入口及本地 EJS 依赖一起核对。Deno 兼容由上游声明与真实解析证据支撑。

## Risks / Trade-offs

- HTTP 重试头可能不可解析：保留可解析的秒数或日期，其余未知，不复制任意头值。
- 用户真实授权不可用于本轮隔离测试：匿名结果与真实授权、Mac 原生结果分开报告。
- 短诊断有整体上限：先输出组件与更新信息，再附已有有界准备历史。
