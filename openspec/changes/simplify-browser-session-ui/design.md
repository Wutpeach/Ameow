# Design

## Context

基线是 PR76 的6f9e7820；上一轮真实原生展示、连续鼠标和入口焦点已有证据。用户实际 Gallery 复看提出五点精简，取代 connect-v8 的常驻共享详情、两步配置和观看控件。动机见 proposal；当前正式browser-sessions四条呈现要求据此修订，旧归档保持历史。

## Goals / Non-Goals

**Goals:** 以已授权站点为默认任务，状态通过清楚分层角标/提示表达；操作和诊断按需，配置一击进入实际路径与自动演示。

**Non-Goals:** 不扩展到其他设置/下载，不改后台认证、协议、Store、队列或发行。本轮PR76/77/78的合并及清理仍暂停，新版实际产品等待本人复看。

## Decisions

- 徽章点击只打开局部站点操作，移除与诊断由既有命令/安全投影承担；删除默认共享详情和状态文字行，不改授权事实。
- 复用原生控件、Palette、锚定tooltip与焦点链。角标用实心底与必要描边留白，站点glyph、角标、选择环分别绘制，完整提示也可由键盘取得。
- 点击配置入口立即发InstallBrowserBridge并进入单页；保留DownloadUi专属回执，真实extension_directory定位成功后才可复制。复用上轮焦点修复并清理退役两步状态，不引入新服务。
- 复用原九秒测量锚点和双色canvas鼠标，将演示简化为通用浏览器图形；移除浏览器选择/手动播放状态，系统Reduced静态完整步骤，可见性继续管唤醒。
- Popup和原生诊断只序列化既有安全投影，不包含原始Cookie/异常/页面URL；正文采用用户语义，计数/分区/时间/来源ID只在折叠文本区。
- 旧冻结EXE与手动Gallery不覆盖不操作。所有新构建在当前树专用target，先完成无需占桌面的代码、headless和相关回归；准确新候选再由来源协调本人查看。

## Risks / Trade-offs

- [删常驻文字后状态难发现] → 非颜色角标、整badge鼠标/键盘同等提示、明确按需诊断。
- [单页配置异步回执与退出竞态] → 复用专属pending/result，进入/回退后检查当前页和请求，不让旧回执冒充本次成功或抢焦点。
- [旧资料被误当新候选] → 全部资产分记真实head/hash，新源稳定后一次交原README与文档任务；旧包与旧用户窗口保留。
