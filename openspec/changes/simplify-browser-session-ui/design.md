# Design

## Context

基线是 PR76 的6f9e7820；上一轮真实原生展示、连续鼠标和入口焦点已有证据。用户实际 Gallery 复看提出五点精简，取代 connect-v8 的常驻共享详情、两步配置和观看控件。动机见 proposal；当前正式browser-sessions四条呈现要求据此修订，旧归档保持历史。

## Goals / Non-Goals

**Goals:** 以已授权站点为默认任务，状态通过清楚分层角标/提示表达；操作和诊断按需，配置一击进入实际路径与自动演示。

**Non-Goals:** 不扩展到其他设置/下载，不改后台认证、协议、Store、队列或发行。本轮PR76/77/78的合并及清理仍暂停，新版实际产品等待本人复看。

## Decisions

- 徽章点击只打开局部站点操作，移除与诊断由既有命令/安全投影承担；删除默认共享详情和状态文字行，不改授权事实。
- 复用原生控件、Palette、锚定tooltip与焦点链。角标用实心底与必要描边留白，站点glyph、角标、选择环分别绘制，完整提示也可由键盘取得。
- 点击配置入口立即发InstallBrowserBridge并进入单页；保留DownloadUi专属回执，真实extension_directory定位成功后才可复制。复用上轮焦点修复并清理退役两步状态，不引入新服务。
- 复用原测量锚点和双色canvas鼠标，通用四步改为约五秒且进入即看见动作，缩短末尾等待；可见失焦继续，按真实可见性而非输入active决定播放，隐藏/最小化/离开可视区及Reduced停。Gallery只列一个配置路径+演示场景，保留旧内部地址兼容。
- 主圆形品牌图标与站名共用中心，角标/菜单独立absolute定位；交互底色沿项目圆角矩形并在实际绘制/裁剪保持，不能只圆边框。
- Popup和原生诊断只序列化既有安全投影，不包含原始Cookie/异常/页面URL；原生按需展开，Popup仅提供诊断行与复制图标，不显示日志正文。
- 旧冻结EXE与手动Gallery不覆盖不操作。所有新构建在当前树专用target，先完成无需占桌面的代码、headless和相关回归；准确新候选再由来源协调本人查看。

- 页面工具新安装对www.youtube.com/www.bilibili.com默认开启，使用正常安装期站点权限与真实注册/现页注入；Popup一个简洁开关保存用户关闭选择，刷新/重启/升级不强开。权限contains真值决定实际可用，不把临时缺权写false，不自动循环request；grants独立，关闭工具不撤销登录态、撤销登录态不误停仍启用工具，显示不自动发Native/下载。新增必选权限的浏览器安装/升级提示如实记录，无新授权向导。

- Popup经本人接受独立评估建议后，按站点→页面工具→登录态同步→诊断重排，局部标签说明授权对象；正常状态紧凑、错误保留安全原因/恢复，普通ON往返不追加位置说明。按钮文字使用可读主题成对颜色，开关视觉小巧/命中32px，长域鼠标/键盘可取全文。只改Popup呈现与显式恢复，不改会话后台或页面工具默认/偏好契约；同一58043预览在候选稳定后才更新，不自动刷新在看页面。

- 2026-11-22本人已验收独立紧凑Popup并要求直接用于正式扩展，替代上一条320px排版的具体呈现：宽240px、内边距12px、正文13px、品牌13px/600、站点15px/600，常态内容高约217px。未授权显示授权按钮；已授权同一操作显示已授权，hover/focus显示同步，真实受理期间禁用、成功原位短反馈；移除放站点菜单。其他来源归入本浏览器的授权入口，后台仍明确authorize及replaces代次，不伪造sync。
- 连接用就绪/未连接/未知短标签及语义色点，完整扩展连接事实保留aria名称与按需提示，不表示桌面在线。安全失败与恢复使用可点击/键盘可达的局部提示。诊断行只复制安全报告，成功换勾约2秒，无日志展开。长域键盘全文使用不改布局的提示，避免失焦吞第一次点击；内部页面直接显示请在网站打开。
- 首屏在初始查询完成后一次揭示，先计算最终布局再启用普通控件过渡，避免未知连接、临时授权按钮及OFF到ON动画闪现。不缓存旧连接成功冒充当前；读取页面工具和会话状态独立收敛，错误也必须揭示可恢复界面。打开Popup只读状态，不刷新网页或自动申请授权。

## Risks / Trade-offs

- [删常驻文字后状态难发现] → 非颜色角标、整badge鼠标/键盘同等提示、明确按需诊断。
- [单页配置异步回执与退出竞态] → 复用专属pending/result，进入/回退后检查当前页和请求，不让旧回执冒充本次成功或抢焦点。
- [旧资料被误当新候选] → 全部资产分记真实head/hash，新源稳定后一次交原README与文档任务；旧包与旧用户窗口保留。
