# Spec Delta

## MODIFIED Requirements

### Requirement: 页面工具独立启用并准确绑定作品

扩展 SHALL 将页面工具启用与 Cookie 授权分开，匿名页面可用。新安装 SHALL 在https://www.youtube.com/*及https://www.bilibili.com/*两个既有支持源默认开启页面工具，正常浏览器页面权限及注册/注入满足后，合格点播播放器就绪即显示胶囊，无需先打开Popup。Popup SHALL 保留一个简洁页面工具开关；用户主动关闭的对应站点选择 SHALL 在刷新、重启及正常升级后保留，已有明确关闭记录不被强开，再次打开可恢复已打开视频页。权限暂不可用/被浏览器撤销与用户主动关闭 SHALL 分开，不将临时权限失败写成关闭偏好，不假称已启用、不自动循环申请或绕过权限。默认必选站点访问仅这两个支持源，MUST NOT 扩成全站点；显示或开关本身不自动建立Cookie同步授权或提交下载/Native登录数据。工具绑定当前播放器及准确作品/分P；广告、直播、无法映射的iframe、多播放器歧义 SHALL 明确不可用，不猜首项、封面或整帖。

#### Scenario: 仅启用工具
- **WHEN** 新安装或用户打开页面工具，且没有Cookie同步授权
- **THEN** 正常页面权限满足时合格播放器自动显示胶囊，工具可显式提交匿名任务；显示/开关不自动建立Cookie同步授权或采集登录数据。

#### Scenario: 撤销会话与撤销站点权限
- **WHEN** 用户关闭页面工具、撤销Cookie授权，或浏览器限制站点访问
- **THEN** 关闭工具只保存站点工具选择并撤下工具，不撤销独立grants；撤销Cookie授权停止采集/同步并撤销桌面grant，保留仍启用工具必需的现有页面访问；浏览器移除访问时工具失效，界面与注册反映实际权限，但不将该暂时状态存成用户关闭或偷偷重新申请。

#### Scenario: 播放目标变化
- **WHEN** SPA换视频、换分P或播放器身份不再匹配
- **THEN** 撤下旧绑定并清除旧作品草稿，可靠确认新作品后重新提供工具。

#### Scenario: 冷安装及已打开页面
- **WHEN** 新安装获准两个支持源所需页面访问，包含已经打开的支持站点标签页
- **THEN** 注册未来页面脚本，并让现有页面在播放器可靠就绪后自动显示胶囊；非视频或不支持页面不误挂载。重复初始化或注入保持单实例，不累积工具条/监听器。

#### Scenario: 主动关闭记忆与恢复
- **WHEN** 用户关闭某个站点工具后刷新、重启或升级，随后再次主动打开
- **THEN** 关闭选择持续保留，其他站点和登录态grants独立；再次打开且实际权限满足后恢复当前已打开视频页的工具。新增页面权限遵循正常浏览器安装/升级确认，不增自制授权向导或全站必选访问。
