# Proposal

## Why

用户在实际 Gallery 中指出，默认站点管理被重复状态、时间和连接选项淹没。2026-11-21 的五项反馈取代旧 connect-v8 呈现：打开设置只需识别已授权站点，排查时才查看诊断。随后手动复看再指出重复Gallery入口、演示失焦暂停/节奏过慢、徽章中心及交互圆角问题，沿本change继续修正。

## What Changes

- 默认桌面只显示实际授权站点的品牌徽章与站名；状态通过独立实心角标及鼠标/键盘提示表达，移除和诊断按需提供。
- 单一“配置扩展”入口立即执行既有配置并在同页显示真实路径/复制与演示，删除中间配置页和页码。
- 演示采用通用浏览器流程，进入即有动作、自动约五秒易读循环，可见失焦继续播放；隐藏/最小化/离屏暂停，保留Reduced完整静态。Gallery合并重复可见项，旧内部地址兼容。徽章主圆形与站名居中，角标独立，交互底色实际圆角。
- 桌面和 Popup 的技术字段收进折叠诊断文本框与安全报告复制，默认保留当前站点、必要授权范围、有用动作及简短恢复提示。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `browser-sessions`: 精简默认展示、单页扩展配置、自动演示和按需安全诊断。

## Impact

影响原生浏览器会话设置、Popup、必要 Gallery 场景、设计参考与相应正式规范。保持现有会话协议、认证、存储、下载/队列及配置命令；README 与 site 由原协作任务在新产品素材稳定后更新。PR76/77/78 合并及回收继续暂停，等待新版实际产品复看。
