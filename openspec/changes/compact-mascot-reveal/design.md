# Design

## Context

动机见 proposal.md。起点 PR40 `3df49ae5`；共享 main/mascot 绘制底座由 B630c4272 独占稳定化，待其准确提交后再接线。本分支先写独立角色时间线、局部分层和离线预览。现有 Figma 导出已含 head、perch-a 和爪子路径，无需改路径或新建造型。

## Goals / Non-Goals

**Goals:** 单一角色进度沿同轨迹连续正反向，窗口主要收起在先，角色在末段一次性启动；最后一帧精确原构图。

**Non-Goals:** 不引入动画引擎、依赖或整套未来动作系统；不写窗口 Model/fullness/anchor/native apply、Converged/B 或 hover；不改变基础 idle 的设计。

## Decisions

- 采用约 720ms 正向、160ms 完整反向的单标量进度。局部动作按该进度取样，不使用重播式关键帧；反向只走已可见的路程。
- 初值以真实 fullness<=0.04（约65.6px surface）作为收起末段触发并锁存；这是实现初选而非用户指定参数，不要求弹簧完全静止。前段角色隐藏，触发前反向直接取消。
- 台面 0–230ms 上浮；头部约140ms 后探出，约350–410ms 轻停，再抬起、落定；爪子在靠近落点时出现。所有位移在60px源坐标内；前景遮挡头部，爪子从沿口接触线上方出现。最终所有位移归零。
- 隐藏暂停，恢复首帧不追赶墙钟。Reduced Motion 使用原有正确终态，不增加空间动作。入场完成后恢复已冻结的 idle 姿态，局部 idle 采用入场末尾权重平滑衔接。
- 原 SVG 路径/配色/defs 保留，仅拆头部、台面和爪子供缓存图层合成；局部平移不逐帧重解析整 SVG。共同 carrier/最终对齐沿 B 的准确修复 5143eb4e；局部素材输入为已准备的 Arc<RenderImage>，缓存失效时统一转换为 Pixmap，显式叠入圆底/边框之后、共同 AA mask 之前，不使用绘制回调。静止复用原整图。源裁掉透明边缘并保留原60px域的offset与密度，采样比例仍约0.5。
- 退场局部边长为 min(60,surface)，原点为 (native-surface)/2，保持旧 Compact 的屏幕锚点，避免随展开中心漂移。surface>60 时局部圆形范围继续保留，不能暴露台面的矩形底部。
- 先完成头/台面/爪子的遮挡，再将角色整体透明度合成至底座；淡化使用有整数目标偏移的小临时图，局部分数位移仍在原变换中采样，不为整张展开窗口另建角色缓冲。这样不会在淡出台面时透出后方猫咪。
- Gallery 增加入场/退场场景，可重复选中并结合原有动态开关预览；离线预览包含窗口先行及正常入场/加速退场，明确不等于原生验收。

## Risks / Trade-offs

- [快速展开遮住退场] → 与原 alpha 协调并保留独立的小角色 rect，绝不延迟窗口；完整轨迹在离线/Gallery 中可审阅。
- [素材拆层改变休止画面] → 真实渲染器对比两主题休止像素与原姿态，遮挡仅作用于动态局部。
- [新合成成本] → 复用现有渲染与有界缓存，只对当前需要的层操作，记录定向成本。
- [原生两端体验] → 工程检查和离线节奏与用户原生体验分开报告；不启动自动点击、录屏或全量场景矩阵。
