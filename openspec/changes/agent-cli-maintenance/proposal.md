# Proposal

## Why

本地 Agent 已可提交和观察桌面下载，但正式 CLI 尚不能查询媒体、选择精确切片或完成已有的日常维护。缺少完整帮助和中英文操作示例也使调用方难以判断哪些操作已完成。

## What Changes

- 通过同一桌面队列开放正式媒体查询及精确切片，保留身份、取消和资源结算边界。
- 提供已有偏好的读写，以及下载组件检查、更新、恢复和 Ameow 本体维护的操作与状态；复用原业务 owner、安全保护和实际结果。
- 更新能力发现、帮助、机器结果、命令参考与中英文 Agent 指南。
- 不增加独立下载后端、服务、凭据导出或尚未确定的格式、音轨和转码策略。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `desktop-control`: 正式媒体查询、精确切片、偏好和维护操作及可观察结果。
- `developer-execution`: 调整开发只解析与正式查询的关系，保留开发有限运行的隔离。

## Impact

本机控制协议、CLI、桌面队列与应用/组件现有 owner 的接线、CLI 帮助和用户/开发文档受影响。Windows 和 Mac 沿各自现有停止及更新事务；测试 fixture 不使用生产签发材料。来源：GitHub #95 及 2026-11-27 用户确认的开发范围。
