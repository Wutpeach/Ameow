# Proposal

## Why

#93 已确认 0.5.2 将工程审计资料和重复许可正文放入发行包，根与版本槽各有一套约 3.2 MB 的许可资料。0.5.3 需要减少实际下载与安装占用，同时保留适用版权、许可和 NOTICE。

## What Changes

- 从发行物料中移除仅用于工程审计的完整 inventory、编译器和标准库来源报告；原始资料保留在准确源码版本。
- 以可复现的纯文本整理重复条款，保留组件映射、全部适用版权和不同的许可正文；离线设置页与包内文字采用同一材料。
- 完整更新保留 0.5.2 消费者要求的根镜像和版本槽成员；不为去重破坏已发布消费者。
- 分别报告 ZIP 压缩数据、安装器、逻辑字节和磁盘分配大小，未知项不推算。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `release-integrity`：增加精简许可物料、来源追溯、兼容和占用核验要求。

## Impact

影响 distribution/notices、物料清单、离线许可组装、Windows 打包和相关检查。保留原始 0.5.2 包、生产签发和用户安装。
