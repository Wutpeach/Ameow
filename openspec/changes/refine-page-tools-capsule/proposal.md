# Proposal

## Why

现有播放器胶囊收起尺寸和闲置透明度偏低，且用户观察到两站原生反馈入口与胶囊接近。#84 已确认统一位置、增强辨识度、准确且可恢复地处理反馈按钮，并补齐 Popup 名称与按需说明；2026-11-23 已授权实施。

## What Changes

- 保留播放器右上角 top/right 10px，收起约32px、品牌图标约16px、闲置整体不透明度约60%，hover/focus恢复100%，协调向左展开布局。
- 仅在胶囊实际显示时隐藏当前绑定播放器内经过真实 DOM 确认的两站反馈按钮，隐藏/解绑/关闭时恢复；无法准确确认则不处理。
- Popup 使用“切片/下载 工具条”和按需 info“在支持的视频页面显示下载与切片入口。”，保持英文语义一致及键盘操作。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `page-video-tools`：胶囊视觉/位置、局部原生反馈入口生命周期及 Popup 工具开关说明。

## Impact

涉及扩展页面工具与 Popup 的现有源文件、受影响的设计参考和定向浏览器检查。不改后台连接、host 协议、页面白屏或其他站点适配；最终 UX 待用户验收。主规范由整合者统一同步。
