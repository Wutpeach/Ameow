# Design

## Context

动机见 proposal.md。当前 browser_guide 用独立 pending 行和默认不可用文案，真实回执由既有 owner 提供。常规和下载页也会因保存过程插入 notice；许可子页已只有返回。

## Goals / Non-Goals

固定配置路径行的尺寸，将真实失败的摘要、可访问详情和重试复用在该行；保留完整路径的复制和提示。沿用现有渲染、回执、焦点与动画，不改设置架构或真实系统配置。

## Decisions

- pending 使用中性占位而非失败，不保留上次路径冒充本次成功；成功后才允许复制。路径单行省略，全文由既有提示读取，避免长短路径改变演示位置。
- 重开时接续 owner 中尚未完成的配置；离页回执不写当前引导。无固定延时。
- 常规启动读取和常规/下载保存只保留禁用/确认值；主动更新、错误、权限和复制反馈保留。
- Gallery 增加隔离 pending、失败、复制失败投影以验证连续状态，绝不调用真实注册。

## Risks / Trade-offs

- 路径单行显示会省略长值 → 保留全文提示与精确复制。
- Gallery 不证明真实浏览器注册和原生日常输入 → 仅合成渲染与状态回归，交本人最终 UX 验收。
