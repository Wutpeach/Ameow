# Design

## Context

检查服务把安装契约置于版本比较之前；组件设置版本下拉同时承载检查和升级，配置动画仍在下载页。现有独立UpstreamChecker、安全切换owner、BrowserUi与控件焦点足以承接本次精简。

## Goals / Non-Goals

Goals：可信无新版时静默；组件页集中动作；复用配置动画并正确返回/暂停/焦点。
Non-Goals：旧布局安装桥接、任意版本、额外连接状态或更新owner、发行。

## Decisions

- Trust分离签名/身份认证与完整安装验证，服务只在认证后判版本；新候选继续完整验证。NoUpdate重查保留已验证Ready和原授权错误。
- 页顶检查逐项请求两个既有checker，用按下载器分开的反馈保留独立状态。版本文本与更多按钮分开，行内唯一升级操作，更多只恢复。
- 配置页属于Components；BrowserUi沿原步骤、动画与减少动态路径，返回/ESC/延迟焦点/可见性与Gallery一并更新。Download只留站点授权与同步。
- info默认透明沿伙伴修复；中英文复用当前样式和字体。

## Risks / Trade-offs

最易遗漏的是Ready原安装反馈、单项冷却时另一项检查、离开/隐藏动画暂停与延迟焦点。用定向回归及有限原生浅深/中英/演示查图覆盖；真实键鼠、Mac原生和本人UX保留实测边界。
