# Design

## Context

动机见 proposal。现有 Peek 的输入编辑、轨道映射和聚焦都在 page.mjs，保留原播放器和独立播放位置滑杆。

## Decisions

- 移除输入节点及其同步逻辑，草稿由既有 I/O、Marker、端帽和选区平移统一更新。
- 聚焦提取共用方法，F 使用既有 Peek 捕获/释放边界，忽略文本、组合输入和修饰键。无标记时隔离站点 F 但不聚焦。
- 标记位于轨道上方，播放头命中位于轨道中央，平移位于下方；贯穿细线不接收事件，重合仍可分别命中。现有原生 range 保留键盘与可访问语义。

## Risks / Trade-offs

- 扩大命中可能挡住端帽 → 三条垂直操作区，指针重合回归。
- 页面集成测试仍引用输入 → 调整所有对应调用，用实际 I/O 替代；证据区分合成绑定与真实站点。
