# Design

## Context

动机见 proposal.md。目录已有 Scalar 入退场，下载 Success 由 Model 计时；前台投影在 retention 到点可先撤下状态。Mascot 已有可见时间时钟和分层变换，禁止另建动画框架。

## Goals / Non-Goals

Goals：局部可调、可移除；成功画面在业务 owner 交接前可完成短退场。
Non-Goals：不重调窗口形变或角色抓沿入场，不改队列、保存 ACK、设置或下载权限。

## Decisions

- 选择 180ms，成功与目录 Saved 共用时长。目录 Receiving 继续 110ms 现有取消退场，Saved 淡出固定位置。
- Model 保留当前反馈自己的截止，淡出不另起异步计时器；新状态替换时旧截止自然消失。Full 只乘当前成功透明度，不加遮罩或命中控件。
- 前台投影仍按原规则选择新任务；无新选择时仅让已显示成功完成退场，不延迟新任务。
- 现有 Mascot 的姿态采样和旋转支点局部调整，保留低频时序、固定爪和前沿；眨眼错开关键动作，不增加动作种类。
- Gallery 复用同一状态和绘制，动态重播生命周期，减少动态固定预览留作主题比对。

## Risks / Trade-offs

- 旧截止误清新反馈 → 定向替换/反向/截止跳跃测试。
- GPUI 透明度不代表命中清理 → 终点退休真实内容，不添加透明控件。
- 放大图误判动作 → 60px 原生短片和原尺寸连续帧，用户保留最终效果判断。
- 隐藏或减少动态追赶旧动作 → 复用可见时间时钟并验证暂停/静止。

## Open Questions

耳动/偏头的主观效果待本人从根 main cargo run 试用；本轮不预先移除这两个动作。最终主规范 sync/archive 由 main 整合者在真实实现后完成。
