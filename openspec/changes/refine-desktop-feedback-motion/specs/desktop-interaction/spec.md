# Spec Delta

## MODIFIED Requirements

### Requirement: 设置与目录输入遵守确认权威

设置 SHALL 使用实际持久化 owner，在 SettingsSaved 后才更新已确认值；pending save 的按下和松开均不得打开陈旧目录。不可见 Badge 不消费背景 hit testing。文件/多目录/不存在或不可写目录不产生错误成功确认。目录打开证据 SHALL 验证实际 Explorer 目标，真实设置验证不得用拒绝写入的 preview 模式替代。

#### Scenario: 保存目录等待回执时双击背景

- **WHEN** 新目录尚未确认
- **THEN** 不打开旧 acknowledged 目录；成功或失败后按当前权限恢复正常入口。

#### Scenario: 文件夹拖入 Full

- **WHEN** 单个现有文件夹拖入 Full，且当前目录设置可操作
- **THEN** 复用 Full 原状态槽与信息胶囊，以浅灰文件夹图标及柔和光晕提示“松开设为目录”，悬浮态不加圆环，并给出轻量表面高亮；候选检查只供展示，实际可写校验、接受和持久化仍交原设置 owner。只有该次拖入收到 SettingsSaved 后才以成功语义色文件夹、成功圆环及光晕短暂显示“目录已更新”；主体仍为文件夹，不冒充下载完成或百分比，失败沿原设置错误路径处理。

#### Scenario: 拖离或取消目录拖入

- **WHEN** 拖拽离开窗口、Esc、取消、结束或放下
- **THEN** 清理候选、高亮和原 drop 锁，悬浮表现按原普通 UI 退出收尾；异步候选检查不得恢复已清理的拖入态，取消不得进入成功停留。目录表现不新增全局交互锁、窗口动画或底部 toast。

#### Scenario: 目录 ACK 后立即移出 Full

- **WHEN** 该次 SettingsSaved 已触发目录成功表现，指针随后离开
- **THEN** 使用与下载 Success 相同的补环、转色、标签与图形收尾时钟及 1500ms retention；反馈播放与停留期间由现有 Model 保持 Full，到期以约 150–200ms 纯淡出撤下目录表现，不增加位移或缩放，然后按原 80ms 离开宽限和其他 owner 决定自动收起。目录事件不得把下载业务状态伪改为 Success；新反馈替换旧时钟，新业务阶段或主动隐藏/Compact 清理旧表现，旧截止不能清理新状态或强制收起。Reduced 直接呈现终态，生产停留不跳过，到期直接撤下。

#### Scenario: Gallery 查看目录反馈

- **WHEN** 选择 full.directory-hover 或 full.directory-saved
- **THEN** 使用与真实 Full 相同的绘制和动画生命周期，支持主题与语言；Reduced 稳定保留终态，动态预览重播真实入场、成功停留、纯淡出及自动收起，再次选择重播。仅投影视觉，不读候选目录、不触发保存、不写用户设置或连接生产服务，不能将预览投影当作 SettingsSaved，生产使用现有 Success retention，不再使用目录旧版独立 2000ms。

### Requirement: Compact 基础猫咪待机

Compact SHALL 在实际 60px 圆窗内使用 Light 黑猫、Night 白猫，随现有主题切换。Light 配色/渐变来自指定 Figma「Ameow · B · 雾白黑猫」，背景使用现有 Compact 主题色，不引入应用图标底板或底托；保留已认可的构图、分层和圆形裁剪。爪子和前景下沿保持稳定。待机以低频眨眼为主，偶尔眼先动、停顿、头部轻微倾斜跟随并短停回正，以及单侧可辨转动、另一侧轻微错时跟随的耳动；不持续整图浮动或缩放，不显示下载信息，也不追踪鼠标。

#### Scenario: 主题切换

- **WHEN** 现有主题机制选择 Light 或 Night
- **THEN** 分别显示黑猫或白猫，使用该主题 Compact 背景；动作节奏与 60px 构图保持一致。

#### Scenario: 猫咪安静待机

- **WHEN** Compact 持续可见
- **THEN** 眨眼闭合与重开连贯，眼窝、瞳孔和高光协调；观察与耳动之间保留安静停顿，眨眼不遮蔽观察或耳动的关键姿态；耳动和偏头在实际 60px 下可辨，不靠增加次数吸引注意，支点稳定且部件不越界。

#### Scenario: 猫咪趴在圆润小窗沿

- **WHEN** Compact 显示猫咪待机或基础动作
- **THEN** 前景使用已选 A 方案的圆弧沿口、轻微厚度、上缘高光与爪下浅阴影；沿口及爪子支点固定，不增加装饰、控件或新动作。

## ADDED Requirements

### Requirement: 成功提示先淡出再交回窗口收起

下载成功与目录保存成功提示 SHALL 保留约 1500ms 成功停留，然后以约 150–200ms 纯透明度淡出撤下；提示退出完成后再按既有指针、锁和离开宽限决定窗口收起。成功退场不改变业务状态或保存确认，不增加交互锁。Reduced Motion 保留生产停留，到期直接撤下；错误和取消不使用该成功退场。

#### Scenario: 成功停留到期

- **WHEN** 成功反馈到期，且没有新任务或新提示替换
- **THEN** 环、图形、光晕和标签同步在原位淡出；不增加位移或缩放，退出后撤下反馈且不残留透明交互层，窗口随后按原 owner 决定收起。

#### Scenario: 新状态打断成功退场

- **WHEN** 成功淡出期间出现新下载、新提示、主动隐藏或 Compact
- **THEN** 新状态立即按既有规则接管，不等待旧淡出；旧计时不能撤下新反馈或强制收起，隐藏不留下持续动画唤醒。

#### Scenario: 减少动态或非成功终态

- **WHEN** 减少动态在停留或淡出中生效，或出现错误/取消反馈
- **THEN** 减少动态直接采用当前正确终态，已到期成功反馈直接撤下；错误、部分完成与取消沿各自既有生命周期。
