# Proposal

## Why

0.5.2 安装器会拦截仍含 0.5.1 状态的原目录，卸载也没有自有用户数据清理选项。#99 已批准在 0.5.3 完成连续升级、安全卸载及真实数据位置说明。

## What Changes

- 安装前识别旧布局，保留可恢复原件后转换安装状态，继续原目录安装；相同布局升级与可信同版修复沿用完整版本登记。
- 安装/卸载只处理可证明属于本安装的文件、版本槽及系统接线；无法确认的文件和其他副本保持，失败报告具体剩余项。
- 独立卸载增加默认关闭的用户数据删除选择，升级保持数据。明确共享数据、多副本和重解析点边界。
- 双语安装、升级、卸载文档说明安装域、用户数据域及下载临时工作区；不新增缓存位置或数据迁移。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `release-integrity`：稳定入口的旧布局转换、原目录升级/修复与有归属的卸载清理。

## Impact

`distribution/ameow.iss`、`scripts/package_windows.ps1`、启动器维护入口和安装维护模块，以及相关双语手册。保持生产签名、序列、不可变已发布资产及正式更新校验边界；受控 fixture 仅证明隔离流程。
