## 去哪里安装？

在[下载页面](../downloads/)选择 Windows x64 安装版、便携版或 macOS Apple Silicon 版本。使用应用不需要 Rust 或 Python。

## 支持哪些链接？

支持公开单视频、部分图片和图集入口，也可尝试其他公开媒体链接。不接入浏览器扩展或导入登录态，具体范围见[支持站点](../extension/supported-sites/)。

## Mac 上找不到 Dock 图标？

Ameow 默认在菜单栏运行。点击猫咪图标选择打开或设置。Mac 要求 macOS 13 或更新系统，实测为 26.3 arm64，见[macOS 首次启动](../troubleshooting/macos-first-run/)。

## 隐藏后任务会停止吗？

不会。隐藏后下载继续；退出会停止任务并等待安全清理。见[悬浮窗口](../desktop/floating-window/)。

## 猫咪会显示下载进度吗？

猫咪在 Compact 安静待机，进度和队列显示在 Full。浅色主题是黑猫，深色主题是白猫，减少动态时保持静止。

## 质量和保存目录什么时候生效？

任务提交时固定两者。切换默认值只影响新任务；失败重试沿用原设置。见[质量与格式](../advanced/quality-and-formats/)和[输出目录](../desktop/output-folder/)。

## 应用更新和组件更新有什么区别？

关于页更新 Ameow，安装后需要重启应用；组件管理更新下载工具。见[设置](../desktop/settings/)和[下载组件](../advanced/download-dependencies/)。

## 可以离线使用组件吗？

健康且保有签名证明的缓存可离线恢复；缺少证明的缓存需要联网准备。见[下载组件](../advanced/download-dependencies/)。

## 下载失败怎么办？

先核对链接、任务提示和原输出目录，再查看[下载失败](../troubleshooting/download-failures/)。反馈时不要公开登录信息或私有链接。
