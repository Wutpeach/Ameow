## 有 Rust 安装包吗？

Rust 尚未正式公开发行；安装版与便携版的发行流程已准备。[Electron v0.3.1](https://github.com/Wutpeach/Ameow/releases/tag/v0.3.1) 已废弃且不再支持。见[下载](../downloads/)。

## 支持什么？

当前源码支持公开单视频和部分图片链接，也可尝试有限的通用链接；不支持旧扩展或登录态导入。见[链接与队列](../desktop/links-and-queue/)。macOS 原生运行未验证。

## 隐藏后任务会停止吗？

不会；退出时若有活动任务会要求确认。文件保存在提交任务时的目录，见[找不到文件](../troubleshooting/missing-files/)。

## 质量和保存目录什么时候生效？

任务提交时固定两者；更改默认值影响后续任务。失败任务的重试沿用原值。详情见[质量与格式](../advanced/quality-and-formats/)和[输出目录](../desktop/output-folder/)。

## 可以离线使用组件吗？

健康且保有签名证明的缓存可离线恢复；缺少证明的旧缓存需要联网引导。见[下载组件](../advanced/download-dependencies/)。

## 下载失败怎么办？

先核对公开媒体链接、任务提示和原输出目录，再查看[下载失败](../troubleshooting/download-failures/)。不要公开登录信息或私有链接。
