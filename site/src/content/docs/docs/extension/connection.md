---
title: 连接桌面端
description: 旧扩展连接不适用于当前 Rust。
---

当前 Rust / GPUI 应用不提供旧浏览器扩展连接。旧扩展显示断开时，重启 Rust 应用或调整网络设置不会建立该连接。

可直接粘贴 [支持站点](../supported-sites/) 的公开单个视频链接。历史 Electron 与扩展的连接实现可查看 [v0.3.1 源码](https://github.com/Wutpeach/Ameow/tree/v0.3.1)；公开资产见 [发行页](https://github.com/Wutpeach/Ameow/releases/tag/v0.3.1)。
