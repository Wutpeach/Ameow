---
title: 连接桌面端
description: 让浏览器扩展连接正在运行的 Ameow 桌面端，并理解 Connected 与 Disconnected 状态。
---

浏览器扩展必须连接 Ameow 桌面端后才能发送下载任务。连接状态显示在扩展弹窗里，最重要的两个状态是 `Connected` 和 `Disconnected`。

[截图：扩展弹窗从 Disconnected 变为 Connected 的状态对比]

## 最短连接步骤

1. 启动 Ameow 桌面应用。
2. 确认桌面边缘能看到 Ameow 悬浮窗口。
3. 打开浏览器扩展弹窗。
4. 等待几秒，确认状态显示 `Connected`。
5. 打开支持站点页面，再尝试发送下载任务。

成功状态：扩展弹窗显示 `Connected`，桌面端仍在运行。此时网页侧发送的任务应该能进入 Ameow 下载流程。

## 状态说明

| 状态 | 含义 | 你应该做什么 |
| --- | --- | --- |
| `Connected` | 扩展已经连上本机 Ameow 桌面端 | 可以从网页发送任务 |
| `Disconnected` | 扩展没有连上桌面端 | 启动或重启 Ameow，重新打开扩展弹窗 |
| 无状态或弹窗异常 | 扩展可能没有正确加载 | 回到扩展管理页重新加载扩展 |

扩展默认连接本机地址 `127.0.0.1:39527`。这是本地通信地址，用来让浏览器扩展和桌面应用互相发现。

## 如果一直是 Disconnected

按下面顺序排查：

1. 确认 Ameow 桌面端已经启动，而不是只安装了应用。
2. 确认桌面悬浮窗口可见。
3. 关闭扩展弹窗，再重新打开。
4. 在浏览器扩展管理页点击重新加载 Ameow 扩展。
5. 退出并重新启动 Ameow 桌面端。
6. 检查防火墙、安全软件或浏览器管理策略是否阻止本地连接。

处理后你应该看到扩展弹窗变为 `Connected`。如果状态改变了，但网页发送任务仍失败，就继续按下载失败排查，而不是反复安装扩展。

## 连接成功但任务没有进入桌面端

这通常不是“连接”问题，而是页面或任务本身的问题。请检查：

- 当前网页是否在支持范围内。
- 当前内容是否需要登录、会员、地区权限或年龄验证。
- 页面是否已经加载完成。
- 你是否在正确的视频、图片或内容页面上触发下载。

如果页面需要登录态，保持浏览器登录后再发送任务。相关说明见 [Cookies 与登录态](../cookies-and-login/)。
