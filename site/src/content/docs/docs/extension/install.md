---
title: 安装扩展
description: 当前 Rust 与历史浏览器扩展的区别。
---

当前 Rust / GPUI 应用不连接旧浏览器扩展，也没有适用于 Rust 的扩展安装步骤。请直接在应用中粘贴支持的公开单个视频链接，参见[支持站点](../supported-sites/)。

历史扩展与 Electron 版相关；需要查找旧发行资产或使用说明，请访问 [v0.3.1 发行页](https://github.com/Wutpeach/Ameow/releases/tag/v0.3.1)和[该版本源码](https://github.com/Wutpeach/Ameow/tree/v0.3.1)。历史资产及站点行为不代表当前 Rust 支持。
