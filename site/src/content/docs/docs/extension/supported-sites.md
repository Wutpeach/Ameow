---
title: 支持站点
description: 区分当前 Rust 下载范围与历史扩展。
---

当前 Rust / GPUI 源码支持 YouTube 和 Bilibili 的公开单视频，以及明确的 Imgur 单图/相册和 Bluesky 单帖图片入口。通用公开 HTTP(S) 链接也可尝试，但仅在下载器能确认单视频或单图身份及结果时交付，不保证任意链接成功。Imgur 相册真实网络下载尚未验证。页面变化、地区或权限限制仍可能导致失败。当前 Rust 不接入浏览器扩展，也不提供 Cookies 或浏览器登录态导入。

通用入口不等于支持任意网站、混合帖子、大型播放列表或网页资源采集。查看 [Electron v0.3.1 发行说明](https://github.com/Wutpeach/Ameow/releases/tag/v0.3.1)和[对应源码](https://github.com/Wutpeach/Ameow/tree/v0.3.1)了解历史范围；站点可能已经变化。
