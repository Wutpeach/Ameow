---
title: 支持站点
description: 区分当前 Rust 下载范围与历史扩展。
---

当前 Rust / GPUI 源码支持粘贴 YouTube 和 Bilibili 的公开单个视频链接。页面变化、地区或权限限制仍可能导致下载失败；不保证所有内容可用。当前 Rust 不接入浏览器扩展，也不提供 Cookies 或浏览器登录态导入。

其他站点及网页资源采集属于历史 Electron / 扩展能力，不能据此推断 Rust 支持。查看 [Electron v0.3.1 发行说明](https://github.com/Wutpeach/Ameow/releases/tag/v0.3.1)和[对应源码](https://github.com/Wutpeach/Ameow/tree/v0.3.1)了解当时范围；站点可能已经变化。
