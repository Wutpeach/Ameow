---
title: 支持站点
description: 了解 Ameow 当前重点支持的网页站点，以及站点支持失败时应如何判断。
---

Ameow 会持续扩展网页媒体下载能力，但不承诺所有站点、所有页面形态都能下载。第三方站点会频繁调整页面结构、播放接口、登录策略和限制规则，因此“支持站点”也需要结合具体页面判断。

判断时先看具体页面，不要只看站点名字。最稳的测试对象是公开、能正常播放或显示、没有会员和地区限制的具体内容页。

## 当前重点站点

当前公开文档重点列出的站点包括：

- YouTube
- Bilibili
- X / Twitter
- Douyin
- Xiaohongshu

部分版本还可能包含 Pinterest、Instagram、知乎等相关下载能力或页面入口改进。具体变化以 [Release Notes](../../releases/) 为准。

## 同一个站点为什么有时成功、有时失败？

即使站点在支持范围内，下面情况仍可能失败：

- 内容需要登录后才能访问。
- 内容有会员、年龄、地区或隐私限制。
- 页面链接已经失效。
- 网站刚刚改版，当前版本还没适配。
- 浏览器扩展没有连接桌面端。
- 你停留在列表页、首页、推荐页或跳转页，而不是具体内容页。

## 判断一个页面是否适合下载

按顺序确认：

1. 页面能在浏览器里正常打开。
2. 内容能播放或显示完整。
3. 如果需要登录，你已经在浏览器中登录。
4. 扩展弹窗显示 `Connected`。
5. 你发送的是具体内容页，而不是搜索结果页、主页、推荐流或合集页。

如果这些条件都满足但仍失败，再考虑站点改版或当前版本不支持该页面类型。

## 抖音页面和链接形态

抖音视频下载现在使用通用的 `yt-dlp` 下载路径。常见可用输入包括：

- `https://v.douyin.com/...`
- `https://www.douyin.com/video/{id}`
- `https://www.iesdouyin.com/share/video/{id}/`
- `https://www.douyin.com/jingxuan?modal_id={id}`

抖音图文、笔记和相册页不是当前公开支持目标。即使抖音在重点站点列表里，非视频页面也可能暂不支持。

## 优先在具体内容页使用扩展和弹窗

无论是页面内下载入口，还是扩展弹窗里的“当前页面资源”，都更适合在具体内容页使用：

- YouTube：具体视频页，而不是首页、搜索结果或订阅流。
- Bilibili：具体视频页、番剧播放页，而不是分区页、搜索页或 UP 主页。
- X / Twitter：具体帖子详情，而不是混合时间线。
- Pinterest、Instagram 等瀑布流站点：具体 Pin / Post / Reel 详情，而不是首页瀑布流。

原因是列表页和推荐页通常会同时出现多个媒体请求、预览资源、封面图和旁路推荐。你看到的是“当前页面”，不代表页面里只有“当前这一个目标资源”。

如果弹窗资源列表看起来不准确，第一步不是反复刷新，而是先进入具体内容页再试。列表页里出现多个候选资源时，扩展无法替你判断哪一个才是你真正想要的内容。

## 失败时怎么换入口？

可以依次尝试：

1. 复制页面 URL 粘贴到 Ameow。
2. 使用浏览器扩展从页面内发送。
3. 重新打开页面后再发送。
4. 使用更稳的下载质量偏好。
5. 升级到最新稳定版。

如果内容需要登录态，优先使用浏览器扩展，而不是只复制链接。
