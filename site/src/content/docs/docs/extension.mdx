<span id="connection"></span>

## 安装与连接

<Steps>
1. 在桌面端「设置 → 下载 → 浏览器会话」选择「配置扩展」，完成后复制显示的扩展路径。
2. 在要使用的 Edge 或 Chrome 中打开扩展管理页，开启开发者模式，选择「加载解压缩的扩展」，粘贴路径并选择该文件夹。
3. 在普通网站打开 Ameow 扩展，按需启用页面工具或授权当前站点。
</Steps>

配置页的演示可帮助你完成加载；请使用当前桌面版本配套的扩展。


<span id="permissions"></span>

## 页面工具与站点授权

**页面工具**默认开启；允许网页访问后，播放器显示下载与切片入口。你可以在扩展中关闭它，选择会按站点记住。登录态同步需另行授权当前站点，并确认扩展显示的站点范围。

<ExtensionDemo />

<span id="sessions"></span>

## 同步已有登录态

在已登录目标站点的浏览器中授权，之后自动同步；Ameow 不会替你登录。网站与下载器决定可下载内容和画质。

桌面端以徽章和站名显示已授权站点，悬停或用键盘聚焦站点查看状态。扩展只显示当前网页的站点；需要更换浏览器来源时，在目标浏览器的扩展中按提示操作。

移除授权时，在该站点打开扩展并选择移除。它只删除 Ameow 保存的会话，不会退出网站。

<details>
<summary>需要排查同步问题时</summary>

先在来源浏览器确认本站仍已登录。需要反馈问题时，展开诊断并复制诊断报告。

</details>

<span id="page-tools"></span>

## 在页面下载整段视频

在 Bilibili 或 YouTube 的单个点播页面，将鼠标移到播放器右上角的 Ameow 图标，选择「下载」或「切片」。若没有看到图标，请在扩展中检查页面工具和网页访问权限。

<span id="clips"></span>

## 选择一个片段

移动播放头并点 Marker 打点，拖动标记左右两侧设置入点和出点；已有标记或范围时，再点 Marker 清空草稿。

<ClipDemo />

确认范围后选择「下载片段」。每次提交一个作品中的一个范围；快速粗切的实际边界可能落在关键帧附近。

<details>
<summary>更多操作</summary>

I／O 在当前播放位置设置对应端点，时间输入可选择和编辑；展示用文字不可选择。「聚焦选区」放大可见时间窗口，回到全片不改变范围。同一作品关闭再打开 Peek 保留草稿，换视频清空；Esc 关闭预览并恢复原页。清空草稿不取消已提交任务。长视频短片段的取数和等待时间取决于来源。

</details>
