<span id="connection"></span>

## 安装与连接

<Steps>
1. 在桌面端「设置 → 组件与诊断」点击浏览器扩展行的「配置扩展」扳手图标，完成后复制显示的扩展路径。
2. 在要使用的 Edge 或 Chrome 中打开扩展管理页，开启开发者模式，选择「加载解压缩的扩展」，粘贴路径并选择该文件夹。
3. 在普通网站打开 Ameow 扩展，按需启用页面工具或授权当前站点。
</Steps>

配置页的演示可帮助你完成加载；请使用当前桌面版本配套的扩展。

Windows 从旧版升级到 0.5.2，请按[下载与安装](../downloads/#升级)完整重新安装；Mac 继续更新完整 App。0.5.2 起的后续 Windows 应用内更新会更新整套配套文件。更新后在组件页配置扩展，使用显示的当前路径在浏览器扩展管理页重载 Ameow，并刷新正在使用的网页；桌面文件更新不会自动重载浏览器里的代码。


<span id="permissions"></span>

## 页面工具与站点授权

**切片/下载 工具条**默认开启；允许网页访问后，播放器显示下载与切片入口。你可以在扩展中关闭它，选择会按站点记住。登录态同步需另行授权当前站点，并确认扩展显示的站点范围。

小红书的网页访问按需申请：在视频笔记页打开扩展，开启工具条并允许访问当前站点。此操作只启用页面工具，登录态同步仍需另行授权。

## 同步已有登录态

在已登录目标站点的浏览器中授权，之后自动同步；Ameow 不会替你登录。网站与下载器决定可下载内容和画质。

桌面端以徽章和站名显示已授权站点，悬停或用键盘聚焦站点查看状态。扩展只显示当前网页的站点；需要更换浏览器来源时，在目标浏览器的扩展中按提示操作。

移除授权时，在该站点打开扩展并选择移除。它只删除 Ameow 保存的会话，不会退出网站。

<details>
<summary>需要排查同步问题时</summary>

先在来源浏览器确认本站仍已登录。需要反馈问题时，点击诊断旁的复制图标，复制诊断报告。

</details>

<span id="page-tools"></span>

## 在页面下载整段视频

在 Bilibili、YouTube 的单个点播页面，或小红书的单视频笔记中，将鼠标移到播放器右上角的 Ameow 图标，选择「下载」或「切片」。若没有看到图标，请在扩展中检查页面工具和网页访问权限。

小红书请保留完整分享链接及其参数。图文笔记、多个播放器或无法确认当前作品时不显示工具；关闭帖子后入口撤下，换笔记时清空原选区。

<span id="clips"></span>

## 选择一个片段

移动播放头并点 Marker 打点，拖动标记左右两侧设置入点和出点；已有标记或范围时，再点 Marker 清空草稿。

<ClipDemo />

确认范围后点击右下角的「下载」按钮。每次提交一个作品中的一个范围；默认快速粗切，实际边界可能落在关键帧附近。开启「精确」会重新编码，耗时更长；同一作品重新打开 Peek 时保留选择，换作品后重置为关闭。

<details>
<summary>更多操作</summary>

点击左下键盘图标查看快捷键；Esc 先关闭帮助，再按关闭预览。在时间刻度区单击或按住拖动可调整播放位置，不改变选区。I／O 在当前播放位置设置对应端点，拖动标记或用方向键微调；展示用文字不可选择。按 F 或点击聚焦按钮：单标记聚焦附近，完整范围聚焦选区，再按返回完整时间轴；没有标记时不可用，聚焦不改变范围或播放位置。同一作品关闭再打开 Peek 保留草稿，换视频清空；Esc 关闭预览并恢复原页。清空草稿不取消已提交任务。长视频短片段的取数和等待时间取决于来源。

</details>
