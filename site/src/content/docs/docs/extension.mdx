在支持的视频页面下载整段或选择片段，也可主动授权同步已有的站点登录态。此功能需要支持浏览器扩展的版本；0.5.0 不提供。请使用匹配的扩展与桌面版本。

<span id="connection"></span>

## 安装与连接

在桌面端「设置 → 下载 → 浏览器会话」选择「安装浏览器连接」。从旁边的文件夹入口找到配套扩展，在 Edge 或 Chrome 的扩展管理页开启开发者模式，选择「加载解压缩的扩展」。在普通网页打开扩展，确认连接状态。

完整包携带配套扩展；源码构建目录为 <code>browser-extension/dist</code>。请使用同一版本的应用、连接程序和扩展，勿单独移动已注册的连接程序。目前支持 Chromium 浏览器，Firefox 尚未接入。

<span id="permissions"></span>

## 页面工具与站点授权

启用**页面工具**并允许网页访问，才能在播放器显示工具条。若要同步登录态，另在扩展中选择「授权此站点」，核对站点及子域范围并确认浏览器权限。未授权站点仍以匿名方式尝试。

<span id="sessions"></span>

## 同步已有登录态

在已登录目标站点的浏览器中授权，扩展会同步已有会话；它不会替你登录。会话变化、浏览器启动或重新连接后会继续更新。可下载性和可见格式仍由下载器及站点决定。

在「设置 → 下载 → 浏览器会话」查看站点的浏览器来源和最近同步结果；切换来源需选择「改用此浏览器」。移除会删除 Ameow 保存的该站点会话，不会退出网站。

<details>
<summary>缓存与同步结果</summary>

桌面端未运行时，连接程序仍可保存当前用户受保护的缓存。上次成功缓存可能早于最近一次失败，读取旧缓存不是新的同步成功；恢复连接后需新的成功回执。缓存也不保证网站仍接受登录态或提供会员画质。

</details>

<span id="page-tools"></span>

## 在页面下载整段视频

在 Bilibili 或 YouTube 的单个点播页面启用页面工具，将鼠标移到播放器右上角的 Ameow 图标，选择「下载」或「切片」。页面工具不自动授权登录态；目标无法准确对应时，请返回具体视频页面。

<span id="clips"></span>

## 选择一个片段

移动播放头并点 Marker 打点，拖动标记左右两侧设置入点和出点；已有标记或范围时，再点 Marker 清空草稿。

<ClipDemo />

确认范围后选择「下载片段」。每次提交一个作品中的一个范围；快速粗切的实际边界可能落在关键帧附近。

<details>
<summary>更多操作</summary>

I／O 在当前播放位置设置对应端点，时间输入可选择和编辑；展示用文字不可选择。「聚焦选区」放大可见时间窗口，回到全片不改变范围。同一作品关闭再打开 Peek 保留草稿，换视频清空；Esc 关闭预览并恢复原页。清空草稿不取消已提交任务。长视频短片段的取数和等待时间取决于来源。

</details>
