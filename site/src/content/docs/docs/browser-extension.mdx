---
title: 浏览器扩展
description: 当前 Rust 与历史 Electron 扩展。
---

当前 Rust / GPUI 应用不接入旧浏览器扩展。请在应用中粘贴 YouTube 或 Bilibili 公开单个视频链接；当前不支持通过扩展采集网页资源或导入 Cookies。详见[支持站点](../extension/supported-sites/)。

[Electron v0.3.1](https://github.com/Wutpeach/Ameow/releases/tag/v0.3.1) 及其扩展已废弃且不再支持，仅作为历史记录。查阅当时的功能与资产可使用 [v0.3.1 源码](https://github.com/Wutpeach/Ameow/tree/v0.3.1)和发行页；这些功能不代表 Rust 已支持。
