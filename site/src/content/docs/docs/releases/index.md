这里整理 Ameow / FlowSelect 历史版本的用户可见变化。稳定版适合普通用户参考；预发布记录主要用于了解测试版本验证过哪些打包、平台和下载链路问题。

## 稳定版

### v0.3.1

#### 亮点

- 紧凑窗口和主窗口动效继续打磨，展开、悬停、边缘光效和单任务下载状态更稳定；只有多个任务需要关注时才显示队列角标。
- 抖音下载链路统一收敛到 `yt-dlp`，改进分享链接、弹窗来源、详情页登录态恢复和相关文档说明，减少需要手动重试的下载失败。
- 站点登录会话支持后台定期刷新，配合扩展端登录同步，让需要登录态的网站下载更少遇到会话过期问题。

#### 修复

- 修复浏览器扩展悬浮入口、同步状态提示和工具提示的多个视觉问题，减少页面内按钮闪烁、重叠或显得过度突出的情况。
- 修复兼容 HEVC 输出仍进入不必要转码的问题，已经可直接使用的视频会跳过多余处理。
- 修复高级质量选择取消后出现误导性提示、单个下载任务时 full 窗口左上角仍显示队列角标等桌面反馈问题。
- 处理依赖安全提醒，并整理下载错误文档，让常见失败原因更容易定位。

#### 说明

- `0.3.1` 是基于 `0.3.0` 的稳定性和体验修复版本，不需要手动迁移配置。
- 浏览器扩展版本会随应用版本同步到 `0.3.1`，正式版不需要额外的 `version_name`。

Full Changelog: https://github.com/Wutpeach/Ameow/compare/v0.3.0...v0.3.1

### v0.3.0

#### 亮点

- 桌面端切换到 Electron 运行时与发布链路，带来新的原生应用外壳、由 Node 托管的下载运行时、随版本发布的浏览器扩展资产，以及开发环境和打包产物之间更一致的启动表现。
- 网页视频采集覆盖范围显著扩展，更多站点接入下载路由，下载提供方支持也得到增强。
- 紧凑桌面 UI 经过较大规模打磨，包括更顺滑的图标模式切换、更稳定的拖拽与悬停行为、更清晰的队列与状态反馈。
- macOS 打包与启动流程重点优化，包括紧凑模式一致性、打包后启动恢复、自定义 DMG 布局，以及多项首启和运行时稳定性改进。

#### 修复

- 补上 Electron 版下载完成后的后续转码链路，最高质量但仍需转码的视频会继续进入转码流程。
- 优化 Bilibili 预览视频在兼容格式下的处理方式，避免可直接使用的素材被重复转码。
- 修复下载或转码完成后的紧凑窗口状态竞态，完成勾号会稳定显示在主窗口里。
- 提升下载链路稳定性，包括资源命名、粘贴链接后的标题恢复、直连下载跟随系统代理、任务清理逻辑、活动文案本地化，以及 Pinterest 等站点处理。
- 修复多项浏览器扩展与桌面端联动问题，包括应用重启后的 WebSocket 重连、首次点击下载触发不稳定和内部视频选择事件安全性。
- 强化转码反馈与取消行为，加入更清晰的进度与 ETA 展示，优化最高质量 FFmpeg 参数，并在取消转码后避免后续状态异常。
- 解决 Windows 开机自启恢复、打包后渲染器加载、拖入文件夹后的输出路径处理、设置窗口更快显示等跨平台桌面壳层问题。
- 收紧 macOS 特有行为，包括紧凑窗口切换、托盘定位、输出目录交互、启动冻结与启动门控逻辑。

#### 说明

- `0.3.0` 是基于 `0.2.9` 的一次重大桌面平台与下载能力更新；无需手动迁移。
- 带标签的正式发布应包含浏览器扩展产物 `Ameow_0.3.0_browser_extension.zip`。

Full Changelog: https://github.com/Wutpeach/FlowSelect/compare/v0.2.9...v0.3.0

- `0.2.8` 把 `0.2.7` 预发布中的更新器和打包工作合入稳定线。

Full Changelog: https://github.com/Wutpeach/FlowSelect/compare/v0.2.7...v0.2.8

### v0.2.7

#### 亮点

- 增加更清晰的下载依赖流程，让主窗口和设置页能展示下载器/运行时准备状态，并在组件需要注意时提供更好的指引。
- 改进打包运行时交付流程，推进 Pinterest sidecar、Deno 等托管工具的引导流程，减少不同机器上的配置漂移。
- macOS 现在以 unsigned 开源 DMG 形式发布，包含标准拖拽到 `Applications` 的布局，以及带可复制首次启动修复命令的安装指南。

#### 修复

- 改进 `Highest` 下载的重试预检和成功状态处理，减少运行时或网络中断后进入误导状态的情况。
- 从普通应用表面隐藏底层取消进程命令，并强化 macOS 上 yt-dlp/运行时检查，让打包行为更可预测。

#### 说明

- macOS DMG 是 unsigned 开源构建，不需要 Apple Developer Program 签名。用户应先把 `FlowSelect.app` 拖入 `Applications`，再使用 Finder 的“打开”、`隐私与安全性 > 仍要打开`，或文档中的 `xattr -dr com.apple.quarantine "/Applications/FlowSelect.app"` 修复命令处理 Gatekeeper 首次拦截。
- 此版本也增加了运行时 sidecar 发布链路，用于让打包下载资产与应用预期保持一致。

Full Changelog: https://github.com/Wutpeach/FlowSelect/compare/v0.2.6...v0.2.7

### v0.2.6

#### 亮点

- 增加桌面主窗口中的两阶段队列，将下载和转码分开展示，在队列角标中显示任务类型，并允许失败转码直接重试或移除。
- 简化浏览器扩展弹窗，移除独立的 `AE Format` 开关，只保留 `Highest / Balanced / Saver` 下载选择，并在 `Highest` 可能触发自动转码时显示上下文提示。
- 增加主窗口双击快捷方式，用于打开当前输出目录，同时保留已有右键菜单目录操作。

#### 修复

- 恢复下载质量选择，让 `Highest`、`Balanced` 和 `Saver` 更可靠地映射到预期下载行为。
- 修复 YouTube `Highest` 下载可能回落到较低 HLS 选择的问题，改进基于 Cookies 会话的格式探测与重试。
- 修复 AE 安全媒体探测改用应用托管的 `ffprobe` 运行时，避免本来兼容的下载因为宿主机器缺少全局 `ffprobe` 而进入转码队列。

#### 说明

- 此版本聚焦让新的“下载到转码”流程更容易理解，同时稳定队列重设计后的第一波回归问题。
- 比较链接使用 `v0.2.2...v0.2.6`，因为仓库当前没有 `v0.2.3`、`v0.2.4` 或 `v0.2.5` 标签。

Full Changelog: https://github.com/Wutpeach/FlowSelect/compare/v0.2.2...v0.2.6

### v0.2.5

#### 亮点

- 桌面窗口、浏览器扩展弹窗和原生托盘/菜单表面加入中文优先本地化。
- 改进便携版 Bilibili 和其他 yt-dlp 下载，让打包下载在不同 Windows 机器上表现更一致。

#### 修复

- 强化运行时语言切换日志和本地化集成，让翻译界面更可靠地保持一致。

#### 说明

- 此版本聚焦交付新的本地化基础，以及打包版本中的便携下载可靠性修复。
- 比较链接使用 `v0.2.2...v0.2.5`，因为仓库当前没有 `v0.2.3` 或 `v0.2.4` 标签。

Full Changelog: https://github.com/Wutpeach/FlowSelect/compare/v0.2.2...v0.2.5

### v0.3.0-rc7

#### 亮点

- `0.3.0` 正式发布前的第七个测试打包版本，重点验证设置页的新信息架构：一级导航更清楚，下载相关设置从通用项里独立出来，插件页也具备后续扩展用的列表骨架。

- 新增接收预发布更新的开关，方便在正式版之外继续测试 beta / rc 版本。

#### 说明

- 此预发布用于验证设置页在小窗口里的层级清晰度、分类收纳是否更顺手，以及插件页骨架是否足以支撑后续插件系统扩展。
- 如果准备继续参与测试，可以在设置页中开启预发布更新开关，以便后续直接收到新的 beta / rc 版本。
