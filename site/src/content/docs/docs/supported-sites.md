## 可以粘贴哪些链接

| 来源 | 支持的入口 |
| --- | --- |
| YouTube | 公开单视频：watch、youtu.be、shorts、embed、live。 |
| Bilibili | 公开单视频：BV、av、b23.tv，可指定单个分 P。 |
| Imgur | 单图或相册入口。 |
| Bluesky | 单帖中的图片。 |
| 其他公开 HTTP(S) 链接 | 可尝试；下载器须能确认单视频或单图并交付结果，不保证任意网页可下载。 |

YouTube 和 Bilibili 的播放列表或系列参数会被拒绝，请复制具体视频地址。需要登录、会员或地区权限的内容可能不可用；应用不导入浏览器登录态。网页或权限变化也可能影响下载，见[下载失败](../troubleshooting/#downloads)。

## 选择画质

提交前在 Full 右键菜单选择：

| 选择 | 视频高度上限 |
| --- | --- |
| 最高 | 无上限 |
| 均衡（默认） | 1080p |
| 省流量 | 480p |

实际分辨率和文件格式取决于站点提供的媒体；上限不保证达到该分辨率，也不会缩放图片。每个任务固定提交时的画质，失败重试沿用原设置。
