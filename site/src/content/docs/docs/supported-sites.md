## 可以粘贴哪些链接

| 来源 | 支持的入口 |
| --- | --- |
| YouTube | 公开单视频：watch、youtu.be、shorts、embed、live。 |
| Bilibili | 公开单视频：BV、av、b23.tv，可指定单个分 P。 |
| Imgur | 单图或相册入口。 |
| Bluesky | 单帖中的图片。 |
| 其他公开 HTTP(S) 链接 | 可尝试；下载器须能确认单视频或单图并交付结果，不保证任意网页可下载。 |

YouTube 和 Bilibili 的播放列表或系列参数会被拒绝，请复制具体视频地址。未授权时匿名尝试；也可[主动授权站点会话](../extension/)。登录、会员、地区及站点变化可能影响下载，见[下载失败](../troubleshooting/#downloads)。

## 选择画质

提交前在 Full 右键菜单选择：

| 选择 | 视频高度上限 |
| --- | --- |
| 最高 | 无上限 |
| 均衡（默认） | 1080p |
| 省流量 | 480p |

实际分辨率和格式取决于站点，上限不会缩放图片。任务和重试沿用提交时的画质。保存成功后菜单保持打开；保存期间暂不可选，失败保留原值并提示。

## 文件格式

使用 yt-dlp 的视频下载以 MKV 合并或重封装，并保留原音频编码。容器扩展名和音视频编码是不同概念；画质选择不保证特定编码或编辑器兼容性。图片下载使用不同的处理路径。如果[导入编辑器后没有声音](../troubleshooting/#editor-audio)，先核对文件格式和编辑器支持情况。
