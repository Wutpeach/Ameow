## 可以粘贴哪些链接

| 来源 | 支持的入口 |
| --- | --- |
| YouTube | 公开单视频：watch、youtu.be、shorts、embed、live。 |
| Bilibili | 公开单视频：BV、av、b23.tv，可指定单个分 P。 |
| 小红书 | 单视频笔记；保留完整分享链接及其参数。 |
| Imgur | 单图或相册入口。 |
| Bluesky | 单帖中的图片。 |
| 其他公开 HTTP(S) 链接 | 可尝试；下载器须能确认单视频或单图并交付结果，不保证任意网页可下载。 |

YouTube 和 Bilibili 的播放列表或系列参数会被拒绝，请复制具体视频地址。未授权时匿名尝试；也可[主动授权站点会话](../extension/)。登录、会员、地区及站点变化可能影响下载，见[下载失败](../troubleshooting/#downloads)。

## 选择画质

提交前在 Full 右键菜单选择：

| 选择 | 视频高度上限 |
| --- | --- |
| 最高 | 无上限 |
| 均衡（默认） | 1080p |
| 省流量 | 480p |

实际分辨率和格式取决于站点，上限不会缩放图片。任务和重试沿用提交时的画质。保存成功后菜单保持打开；保存期间暂不可选，失败保留原值并提示。

如果站点没有符合当前上限的视频格式，任务会显示「画质不可用」。例如，省流量不会把仅有的 1080p 视频缩小到 480p。更换画质后请重新提交链接；重试原任务仍会使用原画质。

## 文件格式

使用 yt-dlp 的普通 SDR 视频默认保存为 MP4，采用常规 8-bit H.264 视频与 AAC 音频，保留所选分辨率和帧率；原本无声的视频保持无声。普通下载和可复制的快速片段会复制已有兼容轨道，仅转换不兼容轨道。必要转换会增加处理时间，也可能带来编码损失和文件大小变化。

快速片段仍按关键帧边界截取；精确片段为准确的时间边界重新编码，尽量在这次处理中直接输出兼容 MP4。传输结束后若仍需处理或核验，任务会继续显示处理状态。

HDR 沿用现有处理和输出，不自动转换为 SDR，也不保证所有 HDR 素材都能直接在剪辑软件中使用。图片下载使用不同路径。如果[导入编辑器后没有声音](../troubleshooting/#editor-audio)，请保留原件并核对文件和编辑器支持情况。
