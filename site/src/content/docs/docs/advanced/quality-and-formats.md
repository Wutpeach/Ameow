提交前可选最高（不设高度上限）、均衡（至多 1080p）或省流量（至多 480p）。默认均衡；实际可用格式取决于站点和视频，上限不保证达到该分辨率。接受的任务固定质量，重试沿用原质量。

当前不提供旧版 AE 兼容开关；请在目标软件验证最终文件。

## 选择建议

| 选择 | 高度上限 | 适用情况 |
| --- | --- | --- |
| 最高 | 无上限 | 需要可获得的最高画质，文件可能更大。 |
| 均衡 | 1080p | 日常下载的默认选择。 |
| 省流量 | 480p | 希望降低数据和存储占用。 |

实际结果取决于站点提供的媒体，不能保证精确分辨率、容器或特定 AE 导入兼容性。任务进入队列后修改质量不会改变该任务；失败重试也沿用原质量。
