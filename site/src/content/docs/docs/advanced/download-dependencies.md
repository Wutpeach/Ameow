首次准备受管理组件可能需要网络。组件管理可手动查询 PyPI 稳定 yt-dlp 版本；查询不会自动切换，用户确认后才开始选择。

应用校验官方签名、哈希和实际版本，通过验证且安全时才激活；仍被任务使用的健康旧版本保留至安全切换。失败保留原选择，未验证组件不会被视为可用。

离线恢复需要健康且保有签名证明的缓存；缺少证明的旧缓存需要联网引导。失败时根据提示明确重试或恢复推荐版本，见[下载失败](../../troubleshooting/download-failures/)。组件更新不等于应用自动更新。

## 组件作用

| 组件 | 用途 |
| --- | --- |
| yt-dlp | 解析支持的视频并下载媒体。 |
| Deno | 为下载器需要的 JavaScript 处理提供运行环境。 |
| FFmpeg | 处理或合并媒体。 |
| ffprobe | 检查输出媒体。 |

## 查询、选择与恢复

1. 在组件管理中手动检查可用稳定版本，查看结果后明确确认选择。
2. 应用验证官方签名、哈希及实际版本；通过后等待正在使用旧版本的任务释放，安全时激活。
3. 若查询、验证或准备失败，保留当前选择并查看提示。可明确重试，或按界面提示确认恢复推荐版本；健康且带签名证明的缓存可以离线恢复。
4. 缺少证明的旧缓存需要联网引导。不要自行用任意 EXE 覆盖缓存，也不要为排障删除已有应用数据。

选择或恢复尚未完成前，原来的健康版本继续受到保护。网络恢复不等于自动完成切换，仍须按界面确认。
