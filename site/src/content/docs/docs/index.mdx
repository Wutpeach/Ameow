Ameow 0.5.0 是 Windows 和 Apple Silicon Mac 上的悬浮下载应用。先[下载并安装](./downloads/)，Windows 从开始菜单或 `AmeowLauncher.exe` 启动，Mac 从 Finder 打开 `Ameow.app`。

<ManualFigure kind="start" />

1. 从 Full 右键菜单或托盘／Mac 菜单栏打开设置，选择保存文件夹。
2. 复制公开媒体链接，在 Ameow 按图示快捷键粘贴。首次使用可能先联网准备组件。
3. 等待下载和后处理完成，双击 Full 空白背景打开保存位置。
