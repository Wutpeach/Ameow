## 从这里开始

1. 查看[下载页面](./downloads/)，了解公开 Electron 发行与尚未公开发行的 Rust 源码。
2. 在已验证的 Windows x64 环境从源码运行，打开设置并选择保存目录。
3. 粘贴支持的公开单个视频链接，等待队列显示完成，再打开结果。

当前 Rust 不接入旧浏览器扩展、登录态或本地文件收集；网页选择属于未来研究范围。了解[下载组件](./advanced/download-dependencies/)和[常见问题](./faq/)。
