Ameow 0.5.0 是 Windows 和 Apple Silicon Mac 上的悬浮下载应用。复制公开媒体链接，粘贴到应用，即可查看下载进度并保存文件。具体范围见[支持站点](./extension/supported-sites/)。

![Ameow 常规设置：开机启动、主题和语言](/Ameow/images/docs/rust-settings-zh-general.png)

在常规设置中选择主题、界面语言和开机启动选项。

## 从这里开始

1. 在[下载页面](./downloads/)选择你的平台并安装。
2. 按[快速上手](./getting-started/)启动，打开设置并选择保存目录。
3. 粘贴支持的公开单个视频链接，等待队列显示完成，再打开结果。

需要调整画质、管理组件或解决问题时，查看[下载组件](./advanced/download-dependencies/)和[常见问题](./faq/)。
