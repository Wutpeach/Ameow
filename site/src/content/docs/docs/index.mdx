Ameow 是一个常驻桌面边缘的下载与收集入口。你可以把本地文件、文件夹、网页链接和浏览器里的内容交给它，再由桌面端统一处理输出目录、下载队列和常用偏好。

如果你是第一次使用，建议按“下载 Ameow → 基础概念 → 快速上手”的顺序阅读。遇到问题时先看 FAQ；如果已经知道具体故障，再进入故障排查专题。

## 按任务阅读

### 整理本地文件

先看 [悬浮窗口](./desktop/floating-window/) 和 [输出目录](./desktop/output-folder/)。你需要记住：拖入文件会复制文件，拖入文件夹会切换输出目录。

### 下载网页内容

先看 [链接与下载队列](./desktop/links-and-queue/)。如果网页需要登录态、Cookies 或页面上下文，再看 [浏览器扩展](./browser-extension/)。

### 安装和连接扩展

从 [浏览器扩展](./browser-extension/) 获取完整流程；需要逐步安装时看 [安装扩展](./extension/install/)，连接失败时看 [连接桌面端](./extension/connection/)。

### 调整下载结果

如果你关心画质、体积和稳定性，看 [质量偏好与格式](./advanced/quality-and-formats/)。如果素材要进入 After Effects，看 [AE 兼容格式](./advanced/ae-compatibility/)。

### 排查问题

不确定问题类型时先看 [FAQ](./faq/)。已经知道具体症状时直接进入 [故障排查](./troubleshooting/)。
