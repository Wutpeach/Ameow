Ameow 是 Windows 和 Apple Silicon Mac 上的悬浮下载应用。先[下载并安装](./downloads/)，Windows 从开始菜单或 `AmeowLauncher.exe` 启动，Mac 从 Finder 打开 `Ameow.app`。

<ManualFigure kind="start" />

<Steps>
1. 在设置中选择保存文件夹，复制公开媒体链接。
2. 靠近小猫展开 Full，按 `Ctrl+V` 或 `⌘V` 粘贴；也可按 `Ctrl+Shift+F` 在鼠标处呼出。
3. 等待下载和后处理完成，双击 Full 空白背景打开保存位置。
</Steps>

首次使用时，Ameow 可能需要联网准备下载组件。
