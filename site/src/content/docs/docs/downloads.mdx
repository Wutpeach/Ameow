Mac 要求 macOS 13 或更新系统，实测为 macOS 26.3 arm64。Intel Mac、Universal 和 Linux 不在此版本范围内；最低版本声明不代表较旧系统均已验证。

## Windows

<Steps>
1. 运行安装程序并完成向导，随后从开始菜单打开 Ameow。使用便携版时，先完整解压，再运行 `AmeowLauncher.exe`。
2. 按[快速上手](../)选择保存位置并提交链接。首次需要的下载组件由应用联网准备。
</Steps>

便携版请保持目录完整。移动前先退出，之后核对快捷方式和开机启动。卸载默认保留用户数据。

## Mac

1. 下载并解压 Mac ZIP，将 `Ameow.app` 放入 `/Applications` 或 `~/Applications`，从 Finder 打开。无需另行安装 Homebrew 或 Python。
2. 从菜单栏猫咪图标选择打开或设置。默认不显示 Dock 图标；入口与启动问题见[Mac 帮助](../troubleshooting/#mac)。

## 升级

Rust 版在[设置的关于页](../desktop/settings/)检查应用更新，按提示下载并重启。下载组件在组件与诊断页单独管理。

从旧 Electron 版转用时，请按本页的平台入口安装 Rust 版，再重新选择保存位置和偏好。两版数据隔离，不自动迁移旧配置、缓存或历史，也不承诺旧 Electron 自动升级到 Rust 版。
