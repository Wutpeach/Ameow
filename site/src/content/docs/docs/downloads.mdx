Mac 需要 Apple Silicon 和 macOS 13 或更新系统；不支持 Intel Mac、Universal 或 Linux。

## Windows

<Steps>
1. 运行安装程序并完成向导，随后从开始菜单打开 Ameow。使用便携版时，先完整解压，再运行 `Ameow.exe`。
2. 按[快速上手](../)选择保存位置并提交链接。首次需要的下载组件由应用联网准备。
</Steps>

安装程序根据 Windows 显示语言选择中文或 English，其他语言使用 English；[应用内语言](../desktop/settings/)单独设置。

<Aside title="移动便携目录">
先退出 Ameow，移动完整目录后核对快捷方式和开机启动。程序目录与用户数据目录相互独立。
</Aside>

## Mac

<Steps>
1. 下载并解压 Mac ZIP，将 `Ameow.app` 放入 `/Applications` 或 `~/Applications`，从 Finder 打开。
2. 从菜单栏猫咪图标选择打开或设置。默认不显示 Dock 图标；入口与启动问题见[Mac 帮助](../troubleshooting/#mac)。
</Steps>

## 升级

在[设置的关于页](../desktop/settings/)检查应用更新，按提示下载并重启。下载组件在组件与诊断页单独管理。

**Windows 从旧版升级到 0.5.2，请完整重新安装。** 退出 Ameow，卸载旧版并清理旧程序文件夹，或选择新的空文件夹安装；便携版也请完整解压到新空文件夹，并更新旧快捷方式。设置、组件缓存和下载文件不需要清空。旧版 Windows 应用内更新不能完成本次目录布局调整。Mac 继续按提示更新完整 App，无需按 Windows 的步骤清理旧程序目录。

<Aside title="0.5.3 安装器">
0.5.3 尚未发布，上方下载仍为 0.5.2。0.5.3 安装器支持识别旧布局后在原目录升级，也支持 0.5.2 起的完整布局升级和同版修复：先正常退出 Ameow，再运行新安装程序并选择原目录。安装器保留用户数据和无关文件；遇到文件占用、权限或无法确认归属的内容时，会说明未完成的项目，请保留原目录并按提示重试。此流程不改变旧版应用内更新的兼容范围。
</Aside>

从 0.5.2 起，Windows 完整安装版和便携版均包含主程序、CLI、浏览器连接组件与扩展；后续应用内更新更新整套文件。完整便携 ZIP 同时用于应用内更新，不再另发单程序更新 ZIP。Mac 继续更新完整 App。两平台的签名更新 JSON 供自动更新使用，无需手动下载。

更新后在组件页配置扩展，按当前路径在浏览器扩展管理页重载 Ameow，再刷新正在使用的网页；详见[扩展安装与连接](../extension/#connection)。

## Windows 存储与卸载

| 位置 | 内容 |
| --- | --- |
| 实际安装目录，默认 `%LOCALAPPDATA%\Programs\Ameow` | 程序、完整版本槽、浏览器扩展和应用更新暂存 |
| `%LOCALAPPDATA%\Ameow` | 设置、已授权会话、浏览器连接、下载组件及归档缓存、组件检查、诊断与 `jobs` 任务工作区 |
| 自选保存目录 | 下载成品 |

`LOCALAPPDATA` 由 Windows 的当前用户位置决定。改变程序安装目录不会移动用户数据；即使把成品保存到其他磁盘，下载和切片的中间媒体仍可能暂占用户数据所在磁盘。本版没有缓存位置选择、随安装目录存放或已有数据迁移选项。

卸载默认保留用户数据。从 0.5.3 安装器开始，可以主动勾选 **同时删除用户数据**，清除设置、已授权的浏览器会话、下载组件缓存、诊断记录和自有任务临时数据。**已下载的文件始终保留，包括默认、自选及以前使用过的保存目录；浏览器本身的账号和 Cookie 也会保留。** 无需为保留成品特意更改默认下载位置。重新安装后需要重新配置并授权；升级过程不会启用此清理。

检测到其他 Ameow 副本仍使用共享数据或连接时，卸载会保留相应内容。无法安全删除、被占用或权限不足的项目会列出，请关闭占用程序后重试。清理范围是 Ameow 自己管理的文件和接线，不包括 Windows 维护的运行历史。
