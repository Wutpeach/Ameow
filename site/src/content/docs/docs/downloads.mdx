Rust / GPUI 是唯一产品主线，尚未正式公开发行。Windows x64 安装版与便携 ZIP 的发行流程已准备，但当前没有正式公开的 Rust 下载包。[Electron v0.3.1](https://github.com/Wutpeach/Ameow/releases/tag/v0.3.1) 已废弃、停止支持，仅保留历史记录。

<Steps>
1. 当前可按以下步骤从 Rust 源码运行；请勿把历史 Electron 包当作当前版本。
2. 如运行 Rust 源码，在 Windows x64 安装 Rust 1.98.1、Visual Studio C++ Build Tools 和 Windows SDK。
3. 仓库根目录执行 `cargo build --locked`，然后运行 `./target/debug/ameow.exe`。
</Steps>

源码构建不等于公开发行。macOS 和 Linux 原生运行未验证。见[开发指南](../developer/)。

正式发行后，安装版将创建开始菜单入口并提供 Windows 卸载入口，可选择桌面快捷方式；便携版需完整解压并运行 `AmeowLauncher.exe`。两者共用应用与安全更新机制，卸载默认保留 `%LOCALAPPDATA%\Ameow` 用户数据。

## 运行前后

源码运行需要 Windows x64 / MSVC 工具链；应用本身不需要 Node、Python 或 Electron。准备组件可能需要网络，输出目录应存在且可写。完成构建后可按[快速上手](../getting-started/)提交公开单个视频链接。

旧发行页的资产和旧扩展对应历史 Electron 版，不表示 Rust 功能或平台支持；历史变化见[发行记录](../releases/)。
