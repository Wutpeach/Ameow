选择适合自己电脑的文件：

| 平台 | 选择的文件 |
| --- | --- |
| Windows x64 安装版 | [安装程序](https://github.com/Wutpeach/Ameow/releases/download/v0.5.0/Ameow_0.5.0_windows_x64_installer.exe) |
| Windows x64 便携版 | [便携 ZIP](https://github.com/Wutpeach/Ameow/releases/download/v0.5.0/Ameow_0.5.0_windows_x64_portable.zip) |
| macOS Apple Silicon | [Mac ZIP](https://github.com/Wutpeach/Ameow/releases/download/v0.5.0/Ameow-0.5.0-macos-arm64.zip) |

Mac 需要 Apple Silicon 和 macOS 13 或更新系统；不支持 Intel Mac、Universal 或 Linux。

## Windows

<Steps>
1. 运行安装程序并完成向导，随后从开始菜单打开 Ameow。使用便携版时，先完整解压，再运行 `AmeowLauncher.exe`。
2. 按[快速上手](../)选择保存位置并提交链接。首次需要的下载组件由应用联网准备。
</Steps>

安装程序根据 Windows 显示语言选择中文或 English，其他语言使用 English；[应用内语言](../desktop/settings/)单独设置。

<Aside title="移动便携目录">
先退出 Ameow，移动完整目录后核对快捷方式和开机启动。卸载默认保留用户数据。
</Aside>

## Mac

<Steps>
1. 下载并解压 Mac ZIP，将 `Ameow.app` 放入 `/Applications` 或 `~/Applications`，从 Finder 打开。
2. 从菜单栏猫咪图标选择打开或设置。默认不显示 Dock 图标；入口与启动问题见[Mac 帮助](../troubleshooting/#mac)。
</Steps>

## 升级

在[设置的关于页](../desktop/settings/)检查应用更新，按提示下载并重启。下载组件在组件与诊断页单独管理。
