Mac 需要 Apple Silicon 和 macOS 13 或更新系统；不支持 Intel Mac、Universal 或 Linux。

## Windows

<Steps>
1. 运行安装程序并完成向导，随后从开始菜单打开 Ameow。使用便携版时，先完整解压，再运行 `Ameow.exe`。
2. 按[快速上手](../)选择保存位置并提交链接。首次需要的下载组件由应用联网准备。
</Steps>

安装程序根据 Windows 显示语言选择中文或 English，其他语言使用 English；[应用内语言](../desktop/settings/)单独设置。

<Aside title="移动便携目录">
先退出 Ameow，移动完整目录后核对快捷方式和开机启动。卸载默认保留用户数据。
</Aside>

## Mac

<Steps>
1. 下载并解压 Mac ZIP，将 `Ameow.app` 放入 `/Applications` 或 `~/Applications`，从 Finder 打开。
2. 从菜单栏猫咪图标选择打开或设置。默认不显示 Dock 图标；入口与启动问题见[Mac 帮助](../troubleshooting/#mac)。
</Steps>

## 升级

在[设置的关于页](../desktop/settings/)检查应用更新，按提示下载并重启。下载组件在组件与诊断页单独管理。

**Windows 从旧版升级到 0.5.2，请完整重新安装。** 退出 Ameow，卸载旧版并清理旧程序文件夹，或选择新的空文件夹安装；便携版也请完整解压到新空文件夹，并更新旧快捷方式。设置、组件缓存和下载文件不需要清空。旧版 Windows 应用内更新不能完成本次目录布局调整。Mac 继续按提示更新完整 App，无需按 Windows 的步骤清理旧程序目录。

从 0.5.2 起，Windows 完整安装版和便携版均包含主程序、CLI、浏览器连接组件与扩展；后续应用内更新更新整套文件。完整便携 ZIP 同时用于应用内更新，不再另发单程序更新 ZIP。Mac 继续更新完整 App。两平台的签名更新 JSON 供自动更新使用，无需手动下载。

更新后在组件页配置扩展，按当前路径在浏览器扩展管理页重载 Ameow，再刷新正在使用的网页；详见[扩展安装与连接](../extension/#connection)。
