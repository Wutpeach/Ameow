在设置的下载页选择存在且可写的文件夹，也可打开目录或复制路径。

<ManualFigure kind="settings-download" />

## 拖入文件夹

一次把一个可写文件夹拖到 Full，按图示反馈确认切换。

<ManualFigure kind="folder" />

- **成功后才生效。** 没有成功反馈时在设置中核对路径。文件、多目录、无效或不可写目录不会切换成功。
- **只影响新任务。** 已排队任务和失败重试仍使用提交时的目录。
- **不移动文件。** 拖入目录仅改变保存位置，不会收集或移动目录内容。

## 打开下载结果

双击 Full 空白背景，或在设置中打开当前已确认的目录。保存变更期间不会打开旧目录。若[找不到文件](../../troubleshooting/#files)，先确认任务完成，再检查提交时的位置；应用不会悄悄切换到其他目录。
