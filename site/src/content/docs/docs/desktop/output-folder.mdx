在设置的下载页面查看、打开、更改或复制输出目录。选择存在且可写的文件夹。

![Windows 下载设置中的输出目录](/Ameow/images/docs/rust-settings-zh-download.png)

## 拖入文件夹切换目录

把一个可写文件夹拖到 Full，出现浅灰文件夹和光晕后松开。保存成功时，彩色文件夹、圆环和短信息胶囊确认目录已更新，约两秒后恢复。这个操作只更改下载位置，不会移动或收集文件夹里的内容。

<ManualFigure kind="folder" />

一次只拖入一个文件夹；文件、多目录、无效或不可写目录不会成功切换。没有成功反馈时，在设置中核对当前路径与错误提示。

## 打开与查找

双击 Full 的空白背景可在 Windows 资源管理器或 Mac Finder 打开当前已确认的目录，也可在设置中选择打开。目录还在保存时，该操作不会打开旧目录。

每个任务固定提交时的目录。切换位置只影响新任务，已排队任务和失败重试仍使用原目录。若找不到文件，先确认任务完成，再检查它提交时的位置，见[找不到文件](../../troubleshooting/missing-files/)。

图中个人路径已遮盖。目录被移动、权限改变或空间不足时，应用不会悄悄切换目录；解决提示中的问题后再提交任务。
