从 Full 右键菜单、Windows 托盘或 Mac 菜单栏打开设置。关闭设置窗口不会退出应用。

在常规页选择主题、语言和托盘图标。画质在 [Full 右键菜单](../../supported-sites/#quality)选择；下载页管理[保存位置](../output-folder/)。

## 呼出快捷键

此快捷键需要支持它的版本，0.5.0 不提供。在常规页录入「呼出／隐藏 Ameow」，默认为 `Ctrl+Shift+F`。

<ManualFigure kind="shortcut" />

失焦或按 Tab 保存，Esc 取消录入，X 清空并关闭快捷键。Mac 默认显示为 `⌃⇧F`。

<details>
<summary>快捷键冲突或保存失败</summary>

组合被占用或保存失败时保留原设置；如果原快捷键也不可用，字段附近会提示。新组合仅在保存成功后生效。

</details>

<span id="browser-sessions"></span>

## 浏览器会话

在下载页选择「连接浏览器」，按[安装与连接](../../extension/#connection)配置本机连接并加载配套扩展，然后在浏览器中授权目标站点。

已授权站点以站点徽章列出。点选一个，在下方查看来源和最近同步结果，或移除 Ameow 保存的会话。同步使用浏览器中已有的登录态，详见[登录态同步](../../extension/#sessions)。

## 更新应用

在关于页检查更新，按提示下载并重启。可启用自动检查、后台下载和任务结束后自动重启更新；任务会先安全结束。

<details>
<summary>更新与恢复详情</summary>

Windows 通过 Launcher 启动新版本；Mac 更新完整的 `Ameow.app`，目录权限需要时请求系统授权。取消授权或校验失败不会安装；替换或启动失败时按提示恢复，用户数据保留。

</details>

<span id="components"></span>

## 管理下载组件

首次使用由 Ameow 准备组件。在组件与诊断页可检查 yt-dlp 稳定版本，确认选择后下载、验证并切换；查询本身不会更换版本。

<details>
<summary>组件准备与恢复</summary>

健康缓存的启动自检保持安静。准备失败时按提示重试或确认恢复推荐版本；健康且带签名证明的缓存可离线恢复，缺少证明时需要联网，失败保留原选择。不要手动替换缓存程序或清空应用数据。

</details>

<details>
<summary>各组件的用途</summary>

| 组件 | 用途 |
| --- | --- |
| yt-dlp | 解析与下载视频。 |
| gallery-dl | 下载图片与图集。 |
| Deno | 提供下载器所需的 JavaScript 环境。 |
| FFmpeg / ffprobe | 处理、合并与检查媒体。 |

</details>

<details>
<summary>开机启动、移动应用与数据位置</summary>

Windows 开机启动指向 `AmeowLauncher.exe`，移动便携目录后需核对快捷方式和启动设置。Mac 从安装好的 `Ameow.app` 管理系统登录项，如需批准，按提示在系统设置完成；移动应用后重新核对。

| 平台 | 用户数据目录（非下载目录） |
| --- | --- |
| Windows | `%LOCALAPPDATA%\Ameow` |
| macOS | `~/Library/Application Support/AmeowNative` |

设置与组件缓存保存在这里，普通排障无需清空。

</details>
