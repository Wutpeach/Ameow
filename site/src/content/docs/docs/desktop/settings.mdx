## 更新应用

在关于页检查更新，按提示下载并重启。可启用自动检查、后台下载和任务结束后自动重启更新；任务会先安全结束。

<ManualFigure kind="updates" />

Windows 通过 Launcher 启动新版本；Mac 更新完整的 `Ameow.app`，仅在目录权限需要时请求系统授权。取消授权或校验失败不会安装更新；替换或启动失败时按提示恢复，用户数据保留。

## 管理下载组件

首次使用由 Ameow 准备所需组件，已有健康缓存时正常启动自检保持安静。在组件与诊断页手动检查 yt-dlp 稳定版本，确认选择后才下载、验证并安全切换；查询本身不会更换版本。

准备失败时查看该页提示，可明确重试或确认恢复推荐版本。健康且带签名证明的缓存可离线恢复，缺少证明时需要联网；失败保留原选择。不要手动替换缓存程序或清空应用数据。

<details>
<summary>各组件的用途</summary>

| 组件 | 用途 |
| --- | --- |
| yt-dlp | 解析与下载视频。 |
| gallery-dl | 下载图片与图集。 |
| Deno | 提供下载器所需的 JavaScript 环境。 |
| FFmpeg / ffprobe | 处理、合并与检查媒体。 |

</details>

<details>
<summary>开机启动、移动应用与数据位置</summary>

Windows 开机启动指向 `AmeowLauncher.exe`，移动便携目录后需核对快捷方式和启动设置。Mac 从安装好的 `Ameow.app` 管理系统登录项，如需批准，按提示在系统设置完成；移动应用后重新核对。

| 平台 | 用户数据目录（非下载目录） |
| --- | --- |
| Windows | `%LOCALAPPDATA%\Ameow` |
| macOS | `~/Library/Application Support/AmeowNative` |

设置与组件缓存保存在这里，普通排障无需清空。

</details>
