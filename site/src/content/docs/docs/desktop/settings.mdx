从 Full 右键菜单、Windows 托盘或 Mac 菜单栏打开设置。关闭设置窗口不会退出应用。

在常规页选择主题、语言和托盘图标。画质在 [Full 右键菜单](../../supported-sites/#quality)选择；下载页管理[保存位置](../output-folder/)。

<span id="shortcut"></span>

## 呼出快捷键

在常规页录入「呼出／隐藏 Ameow」，默认为 `Ctrl+Shift+F`。

<ManualFigure kind="shortcut" />

失焦或按 Tab 保存，Esc 取消录入，X 清空并关闭快捷键。Mac 默认显示为 `⌃⇧F`。

<details>
<summary>快捷键冲突或保存失败</summary>

组合被占用或保存失败时保留原设置；如果原快捷键也不可用，字段附近会提示。新组合仅在保存成功后生效。

</details>

<span id="browser-sessions"></span>

## 浏览器会话

在组件与诊断页的浏览器扩展首行点击「配置扩展」扳手图标，复制显示的扩展路径，按[安装与连接](../../extension/#connection)在浏览器加载扩展。

已授权站点在下载页以徽章和站名显示，悬停或用键盘聚焦查看状态。需要排查同步问题时，展开诊断并复制报告。授权与移除操作见[登录态同步](../../extension/#sessions)。


## 更新应用

在关于页检查更新，按提示下载并重启。「自动更新」开启时会后台下载，在任务结束、资源释放后的合适空闲时机重启安装；关闭后仍检查，由你决定下载和安装。「更新提醒」单独控制 Full 左下角的应用更新提示，不改变自动更新策略。也可在该浮窗直接下载或重启更新。

<details>
<summary>更新与恢复详情</summary>

Windows 0.5.2 起通过根目录 `Ameow.exe` 启动完整的新版本；旧用户先按[安装说明](../../downloads/#升级)完整重新安装；Mac 更新完整的 `Ameow.app`，目录权限需要时请求系统授权。取消授权或校验失败不会安装；替换或启动失败时按提示恢复，用户数据保留。

</details>

<span id="components"></span>

## 管理下载组件

首次使用由 Ameow 准备组件。组件与诊断页顶部的检查更新图标同时检查 yt-dlp 和 gallery-dl；可安装新版时，点击对应行的更新箭头下载、验证并切换，悬停可查看目标版本。各自的更多菜单可恢复 Ameow 推荐版本。检查和打开页面本身不会安装更新。

导航橙点表示尚未查看的新版本，看过后消除；组件行的橙点表示仍有可更新版本。可选下载器更新只在设置页提醒，其他运行组件随 Ameow 更新。浏览器扩展位于首行，文件更新后按提示在浏览器重载扩展并刷新网页；Full 的扩展条目可直接打开这一行。

<details>
<summary>组件准备与恢复</summary>

健康缓存的启动自检保持安静。准备失败时按提示重试或确认恢复推荐版本；健康且带签名证明的缓存可离线恢复，缺少证明时需要联网，失败保留原选择。不要手动替换缓存程序或清空应用数据。

</details>

<details>
<summary>各组件的用途</summary>

| 组件 | 用途 |
| --- | --- |
| yt-dlp | 解析与下载视频。 |
| gallery-dl | 下载图片与图集。 |
| Deno | 提供下载器所需的 JavaScript 环境。 |
| FFmpeg / ffprobe | 处理、合并与检查媒体。 |

</details>

<details>
<summary>开机启动、移动应用与数据位置</summary>

Windows 开机启动指向 `Ameow.exe`，移动便携目录后需核对快捷方式和启动设置。Mac 从安装好的 `Ameow.app` 管理系统登录项，如需批准，按提示在系统设置完成；移动应用后重新核对。

| 平台 | 用户数据目录（非下载目录） |
| --- | --- |
| Windows | `%LOCALAPPDATA%\Ameow` |
| macOS | `~/Library/Application Support/AmeowNative` |

设置与组件缓存保存在这里，普通排障无需清空。

</details>
