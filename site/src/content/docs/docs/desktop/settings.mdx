## 可以调整什么

- **常规：** 选择系统、浅色或深色主题，系统、中文或英文界面，以及托盘图标和开机启动。
- **下载：** 查看、打开、更改或复制[输出目录](../output-folder/)。画质在 Full 右键菜单中选择。
- **组件管理：** 查看下载工具状态、检查可信版本，并确认要使用的版本。
- **关于：** 查看应用版本、检查应用更新和阅读第三方许可。

## 应用更新

在关于页检查更新，按提示下载并重启 Ameow。可设置自动检查、后台下载及任务结束后自动重启更新；运行中的任务会先安全结束。Full 信息入口及托盘／菜单栏也会在适用时提供更新操作。

<ManualFigure kind="updates" />

组件管理更新的是 yt-dlp 等下载工具，不等于升级 Ameow。组件版本的选择与恢复见[下载组件](../../advanced/download-dependencies/)。

Windows 使用 Launcher 启动更新后的版本。Mac 更新完整的 `Ameow.app`；只有目录权限需要时才请求系统授权。取消授权或候选校验失败时不会安装更新。替换或新版本启动失败时按提示恢复，用户数据继续保留。

## 开机启动与移动应用

Windows 开机启动指向稳定的 `AmeowLauncher.exe`。移动便携目录前先退出应用，再核对快捷方式和开机启动。

Mac 通过系统登录项管理开机启动，需要从安装好的 `Ameow.app` 调整。若系统要求批准，按提示在系统设置中允许；移动应用后重新核对登录项。

## 数据保存位置

| 平台 | 用户数据目录 |
| --- | --- |
| Windows | `%LOCALAPPDATA%\Ameow` |
| macOS | `~/Library/Application Support/AmeowNative` |

设置、组件缓存等用户数据与应用分离，不自动导入旧 Electron 配置。普通排障不需要清空这些目录。
