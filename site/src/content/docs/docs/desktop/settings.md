从 Full 右键菜单或系统托盘／Mac 菜单栏打开设置。设置包括常规、下载、组件管理和关于；关闭设置窗口不会退出应用。

![Windows 常规设置](/Ameow/images/docs/rust-settings-zh-general.png)

在常规页面调整主题、语言和开机启动选项。[输出目录](../output-folder/)展示下载设置；[下载组件](../../advanced/download-dependencies/)说明版本选择。

## 可以调整什么

- **常规：** 主题可跟随系统、浅色或深色；语言可跟随系统、中文或英文，并可选择托盘图标和开机启动。
- **下载：** 查看、打开、更改或复制输出目录。质量在 Full 右键菜单选择，见[质量与格式](../../advanced/quality-and-formats/)。
- **组件管理：** 查看组件状态、查询可信版本，并在确认后执行选择；见[下载组件](../../advanced/download-dependencies/)。
- **关于：** 查看应用版本、检查应用更新及阅读内嵌第三方许可，可配置自动检查、后台下载及任务结束后自动重启更新。

当前没有全局快捷键编辑器、手动代理或 AE 兼容设置。

## 开机启动与移动应用

Windows 发行布局使用稳定的 `AmeowLauncher.exe` 启动，设置中的开机启动也指向该入口。移动目录前先正常退出，再重建外部快捷方式并核对开机启动；实际重新登录启动仍未验收。

macOS 开机启动通过系统登录项管理，需要从已安装的 `Ameow.app` 调整。若系统要求批准，按提示在系统设置中允许；直接运行源码可执行文件不具备这一应用包入口。移动应用后重新核对登录项。

## 应用更新

应用更新与下载组件更新相互独立。应用已配置生产公钥和对应平台的更新地址，但 Rust 0.5.0 尚未正式公开发行，公开签名更新源也尚未发布。当前检查失败不代表需要重装下载组件；没有可用公开更新时，可继续使用当前构建并查看错误详情。

有可用更新时，在关于页检查并按提示下载、重启更新；Full 信息入口及托盘／菜单栏也会在适用时提供更新操作。有任务运行时，更新会等待任务安全结束后再安装。

Windows 发行布局通过 Launcher 启动更新后的版本。macOS 更新会替换完整的 `Ameow.app`，支持 `/Applications` 和 `~/Applications`；仅在实际目录权限需要时请求系统授权。取消授权或候选校验失败时不会安装候选；替换或新版本启动失败时按提示恢复，保留用户数据。

## 数据保存位置

| 平台 | Rust 用户数据目录 |
| --- | --- |
| Windows | `%LOCALAPPDATA%\Ameow` |
| macOS | `~/Library/Application Support/AmeowNative` |

设置、运行时选择和缓存保存在当前用户目录，与程序分离。Rust 不自动导入旧 Electron 配置；普通排障不需要清空这些数据。
