设置包括常规、下载、组件管理和关于。常规提供开机启动、主题和语言；下载页面可查看、打开、更改或复制输出目录。

![常规设置](/Ameow/images/docs/rust-settings-zh-general.png)

在常规页面调整主题、语言和开机启动选项。[输出目录](../output-folder/)展示下载设置；[下载组件](../../advanced/download-dependencies/)说明版本选择。

发行布局使用稳定的 `AmeowLauncher.exe` 启动，设置中的开机启动也指向该入口。移动目录前先正常退出，再重建外部快捷方式并核对开机启动；实际重新登录启动仍未验收。当前没有全局快捷键编辑器、手动代理或 AE 兼容设置。

## 可以调整什么

- **常规：** 主题可跟随系统、浅色或深色；语言可跟随系统、中文或英文，并可选择托盘图标和开机启动。
- **下载：** 查看、打开、更改或复制输出目录。质量在下载界面选择，见[质量与格式](../../advanced/quality-and-formats/)。
- **组件管理：** 查看组件状态、查询可信版本，并在确认后执行选择；见[下载组件](../../advanced/download-dependencies/)。
- **关于：** 查看应用版本、应用更新状态和内嵌第三方许可。可配置自动检查、后台下载及任务结束后自动重启更新；生产签名尚未配置时更新不可用。下载组件更新仍在组件管理中独立处理。

设置、运行时选择和缓存保存在 Windows 的 `%LOCALAPPDATA%\Ameow`；当前应用不会导入旧 Electron 配置。保留该目录可继续使用已有 Rust 数据，不要为普通排障清空它。
