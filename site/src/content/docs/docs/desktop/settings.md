设置包括常规、下载、组件管理和关于。常规提供开机启动、主题和语言；下载页面可查看、打开、更改或复制输出目录。

![常规设置](/Ameow/images/docs/rust-settings-zh-general.png)

复用 #15 已接受的历史截图，并非本次新截图。[输出目录](../output-folder/)展示下载设置；[下载组件](../../advanced/download-dependencies/)说明版本选择。

更名或移动 EXE 后先退出旧版，再启动新版并重建快捷方式或任务栏固定项。曾启用开机启动时在新版设置中重新开启并核对；实际重新登录启动未验证。当前没有应用自动更新、全局快捷键编辑器、手动代理或 AE 兼容设置。

## 可以调整什么

- **常规：** 主题可跟随系统、浅色或深色；语言可跟随系统、中文或英文，并可选择托盘图标和开机启动。
- **下载：** 查看、打开、更改或复制输出目录。质量在下载界面选择，见[质量与格式](../../advanced/quality-and-formats/)。
- **组件管理：** 查看组件状态、查询可信版本，并在确认后执行选择；见[下载组件](../../advanced/download-dependencies/)。
- **关于：** 查看应用相关信息。

设置、运行时选择和缓存保存在 Windows 的 `%LOCALAPPDATA%\AmeowNext\stage-a`；当前应用不会导入旧 Electron 配置。保留该目录可继续使用已有 Rust 数据，不要为普通排障清空它。
