设置页用于把 Ameow 调整成适合你工作流的状态。第一次使用不需要改完所有设置，建议先完成一次拖拽和一次下载，再根据实际需求调整。

最先值得确认的只有三项：输出目录是否正确，快捷键是否顺手，下载质量是否保持在稳定的默认偏好。其他选项可以等你遇到具体需求再改。

[截图：Ameow 设置页中输出目录、快捷键、下载质量和 AE 兼容相关设置区域]

## 输出目录

输出目录决定文件和下载结果保存到哪里。你可以在设置中确认当前目录，也可以通过拖入文件夹快速切换。

建议：

- 项目制工作流：为每个项目切换独立输出目录。
- 临时收集：使用默认 `Desktop/Ameow_Received`。
- 找不到文件时：先从设置或悬浮窗口打开当前输出目录。

## 全局快捷键

全局快捷键用于快速唤起 Ameow。适合你经常在浏览器、资源管理器、剪辑软件之间切换的场景。

设置后请实际测试一次：

1. 切到其他应用。
2. 按下快捷键。
3. 确认 Ameow 出现在预期位置。

如果快捷键和其他软件冲突，换一个不常用的组合。

## 开机启动

如果你希望 Ameow 始终作为桌面收集入口，可以开启开机启动。开启后，登录系统时 Ameow 会自动准备好悬浮窗口。

如果你只偶尔下载或整理素材，可以保持关闭，手动启动即可。

## 鼠标跟随晃动

开启后，鼠标在主窗口上移动时，窗口会朝指针方向轻微位移，形成一个轻微晃动效果。

如果你觉得这个效果晃眼、或让点击位置不够稳定，保持关闭即可，主窗口会完全静止。

Ameow 默认开启这个效果；如果不需要，在这里关闭即可，主窗口会改为完全静止。

## 应用更新

Ameow 会在启动后一段时间自动检查应用更新，并在持续运行时定期后台检查。发现新版本后，悬浮窗口和设置页会显示更新入口。

后台检查只负责提示，不会自动下载、安装、退出或重启应用。你也可以在设置页手动点击检查更新。

如果你开启“接收预发布版本”，后续自动检查和手动检查都会优先查看测试版 / RC 版本；关闭后回到稳定版更新通道。

## 重命名规则

重命名规则用于让保存后的文件更容易整理。适合按项目、日期、来源站点或素材类型管理文件的用户。

调整后建议用一个测试链接验证结果，确认文件名符合预期，再用于大量下载。

## 下载质量偏好

下载质量偏好影响网页媒体下载时更偏向画质、体积还是稳定性。

- 最高质量：文件可能更大，可能需要转换。
- 均衡：适合日常保存和复用。
- 省流量：适合网络或存储空间有限的场景。

如果某个站点最高质量持续失败，先用均衡模式验证链接是否可下载。

## AE 兼容格式

如果你经常把视频素材放进 After Effects，关注 AE 兼容格式。这个选项的目标是减少“下载成功但剪辑软件不易处理”的情况。

使用建议：

- 只是保存参考素材：优先均衡。
- 要进入剪辑流程：优先考虑兼容性。
- 要归档最高质量素材：接受更大的文件和更长处理时间。

## 网络代理

网络代理设置位于"系统与支持 → 网络代理"。它控制 Ameow 下载内容时走哪条网络路径。

两种模式：

- 系统代理：沿用操作系统的代理设置。大多数用户保持这个模式即可。
- 手动代理：自定义代理地址和端口。适合你的代理工具没有接管系统代理、或你想让 Ameow 走单独网络路径的场景。

<Aside type="caution" title="什么时候需要手动代理？">
	如果你在浏览器里能播放 YouTube，但 Ameow 下载失败，通常是因为浏览器走了代理但 Ameow 没有。这时可以切换为手动代理，填入你的代理地址。详见 [下载失败](../troubleshooting/download-failures/)。
</Aside>

## 本地代理

本地代理是"让别的程序走 Ameow"的反向用法：Ameow 在本机回环地址上开一个端口，你把浏览器或其他客户端的代理指向它，出网流量就由 Ameow 接管。

设置位于"系统与支持 → 本地代理"，默认关闭，默认端口 `21080`。

- HTTP 代理与 SOCKS5 代理共用同一个端口，客户端按自己支持的方式填即可。
- 只监听 `127.0.0.1`，同一局域网的其他设备访问不到。
- 出口方向沿用上面的"网络代理"设置：手动代理 > 系统代理 > 环境变量 > 直连。本地代理本身不决定走哪条线路。
- 不要把本地代理自己的地址填进「网络代理」：那会绕回自己。Ameow 会拒绝这种自环路由并在日志里说明，而不是反复连接。

<Aside type="note" title="和「网络代理」的区别">
	「网络代理」决定 Ameow 自己出网怎么走；「本地代理」决定别的程序能不能借用 Ameow 的线路。两者共用同一套出口设置。
</Aside>

典型用法：

- 浏览器里把 HTTP 代理设为 `127.0.0.1:21080`，让浏览器和 Ameow 走完全相同的网络路径。
- 只认 SOCKS5 的工具，填 `socks5://127.0.0.1:21080`。

如果端口已被占用，状态栏会提示启动失败，换一个 1024-65535 之间的端口即可。
