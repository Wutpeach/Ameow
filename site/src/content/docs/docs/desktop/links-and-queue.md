title: 链接与下载队列
description: 粘贴网页链接后，理解 Ameow 下载队列的状态、并发、转换和失败处理。
---

当你粘贴网页链接，或通过浏览器扩展发送任务时，Ameow 会把可处理的任务放入下载队列。队列负责排队、下载、转换和完成后的保存。

看队列不是为了盯进度条，而是为了决定下一步：没有任务先查输入和扩展连接，一直准备中先查网络和登录态，完成后先打开输出目录。

[截图：下载队列显示等待、下载中、转换中、完成几种状态]

## 创建下载任务

1. 复制一个图片链接、视频链接或支持站点页面链接。
2. 回到 Ameow 悬浮窗口。
3. 按 `Ctrl+V`；macOS 使用 `Cmd+V`。
4. 查看窗口里是否出现任务状态。

如果链接来自需要登录态的网站，优先通过浏览器扩展发送，而不是只复制 URL。

## 队列状态说明

| 状态 | 表示什么 | 你可以做什么 |
| --- | --- | --- |
| 等待 | 任务已加入队列，等待下载槽 | 通常不用处理 |
| 准备中 | 正在解析链接、检查格式或准备依赖 | 等待；如果长期不动再排查网络和登录态 |
| 下载中 | 正在下载文件 | 保持网络稳定，不要移动输出目录 |
| 转换中 | 正在合并或转换为更兼容的格式 | 等待完成，文件可能还没最终出现 |
| 完成 | 文件已写入输出目录 | 打开输出目录查看 |
| 失败 | 任务没有完成 | 按失败原因排查 |

## 并发下载

Ameow 会限制同时下载的任务数量，避免一次性占满网络和系统资源。多个链接可以连续发送，队列会按可用下载槽逐步处理。

如果你发现任务在等待，先确认是否已有其他任务正在下载或转换。

## 转换中为什么还不能用文件？

网页平台常把音频、视频或高质量格式拆开提供。Ameow 下载后可能需要合并或转换。转换完成前，输出目录里的临时文件不一定是最终结果。

成功状态：任务显示完成后，再打开输出目录使用最终文件。

## 失败后先看哪儿？

先判断失败属于哪类：

- 任务没有出现：可能链接没有被识别或扩展未连接。
- 一直准备中：可能网络、站点规则、登录态或依赖准备有问题。
- 明确失败：检查链接、站点支持、输出目录权限和登录态。
- 显示完成但找不到：按输出目录排查。

完整排查路径见 [下载失败](../../troubleshooting/download-failures/)。
