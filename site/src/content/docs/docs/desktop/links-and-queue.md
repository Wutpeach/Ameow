粘贴公开单个视频链接：YouTube 支持 watch、youtu.be、shorts、embed、live；Bilibili 支持 BV、av、b23.tv，可指定单个分 P。这些视频网站的播放列表和系列参数会被拒绝。也可尝试公开图片和有限的通用链接，范围与限制见[支持站点](../../extension/supported-sites/)。

最多三个任务占用执行槽位，其余等待。任务固定提交时的质量和目录；可取消，失败或部分完成时可按界面提示重试。内部恢复仍属于同一任务。队列不会在重启后恢复；失败时可复制诊断。当前不支持旧扩展、Cookies 或浏览器登录态导入。见[下载失败](../../troubleshooting/download-failures/)。

## 队列状态

| 状态 | 含义与操作 |
| --- | --- |
| 排队 | 等待可用执行槽位；可以取消。 |
| 准备中 | 准备所需组件；等待结果或查看提示。 |
| 下载中 | 获取媒体；进度可能因数据不可用而不显示百分比。 |
| 后处理 | 处理下载结果；等待完成后再打开文件。 |
| 完成 | 已完成保存，可打开任务提交时的目录。 |
| 部分完成 | 部分文件已保存，但仍有未完成内容；可重试。 |
| 失败 | 查看提示并复制诊断；可手动重试。 |
| 已取消 | 任务已取消；需要时重新提交。 |

重复提交同一尚未完成的视频会被拒绝，不会改变已有任务。清除历史记录不会删除已保存文件；队列历史仅属于当前会话。Imgur 和 Bluesky 图片任务失败或部分完成时，重试沿用原任务；图集保留已验证文件，在原作品目录尝试剩余内容。其他链接的重试创建新任务，沿用原链接、质量和目录。
