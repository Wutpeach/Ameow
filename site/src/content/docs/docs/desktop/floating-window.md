指针移近紧凑窗口时会展开完整窗口，可查看任务和队列。

![紧凑窗口主题](/Ameow/images/docs/rust-compact-themes.png)

此图复用 #18 已接受的历史截图，不是本次新截图。托盘菜单提供打开、设置和退出；隐藏窗口后下载继续。活动任务存在时退出会要求确认，停止并退出会等待任务清理。

## 展开后的操作

完整窗口提供链接输入、当前任务状态和队列入口。主菜单可选择质量、打开设置或输出文件夹；队列用于查看等待、执行和失败的任务，以及取消或重试适用任务。质量和目录在任务提交时固定。

## 隐藏与退出

隐藏后从托盘选择打开即可恢复；托盘也提供设置和退出。活动任务存在时，退出确认允许继续使用或停止任务并退出。等待清理完成后才算退出，不要把窗口隐藏当作任务结束。

上图仅展示 Compact 主题，不展示 Full 窗口或托盘菜单；画面也不证明其他平台或所有 DPI 条件。
