复制[支持的媒体链接](../../supported-sites/)，在 Ameow 粘贴。点 Full 右下角的数字查看队列，最多三个任务同时占用执行槽位，其余等待。

<ManualFigure kind="queue" />

| 阶段 | 可以做什么 |
| --- | --- |
| 排队、准备中 | 等待执行或组件准备；可取消任务。 |
| 下载、后处理 | 等待保存完成；缺少进度数据时可能没有百分比。 |
| 完成 | 打开任务提交时的保存目录。 |
| 失败、部分完成 | 阅读提示，复制诊断或按界面重试。 |
| 已取消 | 需要时重新提交。 |

同一未完成视频不能重复提交。任务沿用提交时的画质和目录；清除记录不会删除文件，队列在退出后不保留。

<details>
<summary>重试图集或短链接</summary>

- 从 Imgur 单图／相册或 Bluesky 单帖入口创建的图片任务在原任务中重试，保留已验证文件，并在原作品目录尝试剩余内容。
- 视频和其他通用入口的手动重试会创建新任务，沿用原链接、画质和目录；同站点直接图片链接也可能走通用入口。
- Bilibili 短链接尚未识别目标时不能重试，请重新提交对应的 BV 或 av 视频链接。

</details>

## 窗口与猫咪

猫咪在 Compact 待机，下载信息显示在 Full。浅色主题是黑猫，深色主题是白猫；系统开启减少动态时保持静止。

| 操作 | 结果 |
| --- | --- |
| Full 右键 | 选择[画质](../../supported-sites/#quality)、打开设置、隐藏或退出。 |
| 双击 Full 空白背景 | 打开[已确认的保存目录](../output-folder/)。 |
| 隐藏 | 下载继续；从托盘／Mac 菜单栏选择打开即可恢复。 |
| 退出 | 停止任务并等待安全清理；仅清理异常时显示恢复操作。收起或按 Esc 不会撤销退出。 |

下载或保存遇到问题时，查看[排查方法](../../troubleshooting/)。
