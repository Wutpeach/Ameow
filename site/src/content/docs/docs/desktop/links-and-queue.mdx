复制[支持的媒体链接](../../supported-sites/)，在 Ameow 粘贴。点 Full 左上角的数量查看队列，最多三个任务同时占用执行槽位，其余等待。

<ManualFigure kind="queue" />

未完成任务可按界面取消，并等待停止与清理确认。正常下载需等后处理和保存完成，缺少进度数据时可能没有百分比。完成后可打开提交时的目录；失败或部分完成时查看提示、复制诊断或按界面重试，确认取消后可重新提交。

同一未完成视频不能重复提交。任务沿用提交时的画质和目录；清除记录不会删除文件，队列在退出后不保留。

- 从 Imgur 单图／相册或 Bluesky 单帖入口创建的图片任务在原任务中重试，保留已验证文件，并在原作品目录尝试剩余内容。
- 视频和其他通用入口的手动重试会创建新任务，沿用原链接、画质和目录；同站点直接图片链接也可能走通用入口。
- Bilibili 短链接尚未识别目标时不能重试，请重新提交对应的 BV 或 av 视频链接。

## 窗口与猫咪

猫咪在 Compact 待机，下载信息显示在 Full。浅色主题是黑猫，深色主题是白猫；系统开启减少动态时保持静止。

运行时按默认 `Ctrl+Shift+F` 在鼠标处呼出 Full；Full 已获得键盘焦点时再按隐藏，下载继续。右键 Full 可选择[画质](../../supported-sites/#quality)、打开设置、隐藏或退出；双击空白背景打开[已确认的保存目录](../output-folder/)。隐藏后可从托盘／Mac 菜单栏恢复。退出会停止任务并等待安全清理，异常时显示恢复操作；收起或按 Esc 不会撤销退出。

呼出本身不会读取剪贴板或提交任务。展开完成后，鼠标移开会恢复普通收起规则；下载、菜单等状态仍按各自规则保持。快捷键可在[常规设置](../settings/#shortcut)修改或清空；被占用或清空时，可从托盘／Mac 菜单栏打开。应用未运行时先启动 Ameow。

下载或保存遇到问题时，查看[排查方法](../../troubleshooting/)。
