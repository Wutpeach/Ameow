---
title: 文件与文件夹
description: 使用 Ameow 收集本地文件，理解拖入文件和拖入文件夹的不同结果。
---

Ameow 可以接收本地文件和文件夹，但这两个动作的含义不同：拖入文件是收集文件，拖入文件夹是切换输出目录。

[示意图：拖入文件会复制到输出目录，拖入文件夹会切换输出目录]

## 拖入文件：复制到输出目录

适合收集截图、图片、视频、文本、项目素材等文件。

操作步骤：

1. 选中一个或多个本地文件。
2. 拖到 Ameow 悬浮窗口。
3. 松开鼠标。
4. 打开当前输出目录确认文件出现。

成功状态：文件出现在当前输出目录，原位置仍保留原文件。

## 拖入文件夹：切换输出目录

适合你想把后续素材统一保存到某个项目文件夹。

操作步骤：

1. 找到目标文件夹。
2. 把文件夹拖到 Ameow 悬浮窗口。
3. 后续拖入文件、粘贴链接和网页下载都会进入这个文件夹。
4. 打开当前输出目录确认位置已经切换。

成功状态：当前输出目录变成你拖入的文件夹。Ameow 不会把整个文件夹复制一份。

## Windows 剪贴板文件

在 Windows 上，你可以先在资源管理器复制文件，再粘贴给 Ameow：

1. 在资源管理器选中文件。
2. 按 `Ctrl+C`。
3. 让 Ameow 可接收输入。
4. 按 `Ctrl+V`。

适合窗口不方便拖拽，或已经在文件管理器里选中文件的场景。

## 哪些情况容易误会？

- 想复制文件夹内容，却拖入了文件夹本身：这会切换输出目录。
- 找不到文件：很可能当前输出目录已经被你切换过。
- 复制大文件后没有立刻看到结果：等待文件复制完成，再打开输出目录确认。

如果你不确定当前保存位置，从 Ameow 打开当前输出目录是最快的确认方式。
