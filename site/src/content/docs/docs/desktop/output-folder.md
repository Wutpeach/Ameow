在设置的下载页面查看、打开、更改或复制输出目录。选择存在且可写的文件夹。

![下载设置的输出目录](/Ameow/images/docs/rust-settings-zh-download.png)

复用 #15 已接受的历史截图，路径已遮盖，并非本次新截图。任务固定提交时的目录；后续更改只影响新任务。原目录不可用时任务可能失败，不会悄悄切换目录。见[找不到文件](../../troubleshooting/missing-files/)。

## 更改与查找

1. 在设置的下载页面查看当前路径，使用打开操作确认文件夹。
2. 需要切换时选择另一个存在且可写的目录；复制操作可将路径用于文件管理器。
3. 新任务使用新目录，之前的任务仍使用提交时的目录。等待完成后检查对应位置。

如果目录被移动、权限改变或空间不足，先处理提示中的问题。若需要新目录，请提交新任务；失败任务的重试仍使用原目录。不要通过删除应用数据来查找文件。
