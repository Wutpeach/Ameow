在 Windows x64 安装 Rust 1.98.1、Visual Studio C++ Build Tools 和 Windows SDK，然后在仓库根目录运行：

```powershell
cargo build --locked
./target/debug/ameow.exe
```

Rust 尚无公开安装包。完整前置条件见[本地开发](../developer/local-development/)。

将指针移近紧凑窗口展开主窗口，检查设置中的输出目录，粘贴 YouTube 或 Bilibili 公开单个视频链接。查看队列，完成后打开输出目录。首次运行可能需要联网准备组件。见[链接与队列](../desktop/links-and-queue/)和[排查指南](../troubleshooting/)。

## 第一次下载

1. 在设置的下载页面确认输出文件夹存在且可写；需要时更改并打开它确认位置。
2. 在浏览器复制支持的公开视频地址，在 Ameow 输入入口按 `Ctrl+V` 提交。
3. 等待组件准备和队列处理。若提示组件问题，打开组件管理查看状态，按提示操作。
4. 任务显示完成后，在提交时选定的输出目录打开文件。

指针移近紧凑窗口可展开操作界面；隐藏后下载继续，可通过托盘恢复。退出时若仍有活动任务，选择继续或停止并退出；后者等待清理。详见[悬浮窗口](../desktop/floating-window/)和[下载组件](../advanced/download-dependencies/)。
