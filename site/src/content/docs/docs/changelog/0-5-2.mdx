2026-11-24 · [GitHub Release](https://github.com/Wutpeach/Ameow/releases/tag/v0.5.2)


这次更新减少了下载开始前的重复等待，补齐两个下载器的手动更新，并让应用更新、扩展重载和桌面提示更清楚。

### 下载与升级

| 你的电脑 | 下载文件 |
| --- | --- |
| Windows x64 | [完整安装版](https://github.com/Wutpeach/Ameow/releases/download/v0.5.2/Ameow_0.5.2_windows_x64_installer.exe)，推荐大多数用户选择 |
| Windows x64，便携使用 | [完整便携 ZIP](https://github.com/Wutpeach/Ameow/releases/download/v0.5.2/Ameow-0.5.2-windows-x64-portable.zip)，完整解压后运行根目录的 `Ameow.exe` |
| Apple Silicon Mac | [Mac ZIP](https://github.com/Wutpeach/Ameow/releases/download/v0.5.2/Ameow-0.5.2-macos-arm64.zip)，解压后将 `Ameow.app` 放入 `/Applications` 或 `~/Applications` |

**Windows 旧用户请完整重新安装 0.5.2。** 退出 Ameow，卸载旧版并清理旧程序文件夹，或选择一个新的空文件夹安装。使用便携版时，也请解压到新空文件夹，并更新指向旧程序的快捷方式。设置、组件缓存和已下载文件不需要清空；清理的是旧程序文件夹。旧版本的应用内更新不能完成本次目录布局调整。

安装版和便携版都包含完整功能及配套 CLI、浏览器连接组件和扩展。从 0.5.2 起，Windows 后续应用内更新会更新整套文件；完整便携 ZIP 也用于应用内更新，不再另发单程序更新 ZIP。Mac 继续使用完整 App 更新。两个 `ameow-update-*.json` 文件供自动更新使用，无需手动下载。

**使用扩展的用户还需要：** 打开「设置 → 组件与诊断」，点击浏览器扩展行的「配置扩展」扳手图标；按显示的路径配置或加载扩展，在浏览器扩展管理页重新加载 Ameow，再刷新正在使用的网页。桌面端更新文件后，浏览器不会自动重载扩展。

### 下载与组件

- 精简下载启动和组件准备时的重复检查，减少等待；同一次匿名视频下载复用已取得的解析结果。实际耗时仍取决于站点、网络和媒体内容。
- yt-dlp 和 gallery-dl 都可在「组件与诊断」中检查并手动更新，也可从各自的更多菜单恢复 Ameow 推荐版本。检查不会自行安装；两个下载器的更新和恢复分别管理。
- 组件页用小橙点提示新版本；导航提示看过后消除，仍可更新的组件继续保留提示。需要更新 Ameow 才能使用的下载器版本会明确说明。
- 改进下载组件准备和失败后的重试，复用仍可信的已取得文件，减少重复准备；失败诊断更便于定位问题。

### 应用与扩展

- 应用更新设置简化为「自动更新」和「更新提醒」。自动更新开启时，会后台下载，并在任务结束、资源释放后的合适空闲时机重启安装；关闭后仍检查，由你决定下载和安装。「更新提醒」单独控制 Full 左下角的应用更新提示。
- Full 左下角浮窗可直接下载或重启更新；扩展待重载提醒可直接打开组件页。关于页仍可手动检查更新。
- 浏览器扩展集中显示在组件列表首行，提供版本、配置入口和必要的重载说明。配置路径与诊断报告使用复制图标，成功后原位显示勾选；设置页减少不必要的过程提示。
- 扩展弹窗先显示界面，随后分别加载页面工具和站点登录态；未确认时显示读取中，无响应时提供重试。改进后台连接，减少重复打开时的等待。
- 播放器上的切片/下载工具条更大、更清楚；Bilibili 中准确识别到的重叠反馈按钮会在工具条显示期间临时隐藏。扩展开关旁增加用途说明。

### 桌面体验与修复

- 下载完成和目录设置成功的提示以短淡出收尾；调整小猫的耳动和观察偏头表现，并尊重减少动态设置。
- 修复 Windows 新安装后的快捷方式图标，统一从带正式图标的根目录 `Ameow.exe` 启动。
- 修复 Mac 在链接解析阶段取消任务后，任务无法结束并阻塞退出的问题。
- 修复已是最新版本时仍误报更新未通过安全验证的问题。
