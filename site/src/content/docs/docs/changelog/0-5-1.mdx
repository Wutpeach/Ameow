## 准备中的更新

- 全局快捷键呼出或隐藏 Ameow。
- 浏览器页面工具、紧凑扩展界面、站点会话授权与单区间切片；可选精确切分（重新编码）。
- 下载显示网络速率，媒体处理阶段显示处理倍率；失败时可复制诊断。
- 命令行改进，以及跟随 Windows 显示语言的安装向导。
- 优化 YouTube 区间下载的取数，以及精确切分的编码速度；精确模式仍重新编码并校验成品边界。

更新扩展和连接组件请使用完整安装包或便携包，重新配置并重载扩展，再刷新视频页面。Windows 应用内更新只替换主程序。

已发行版本仍为 [v0.5.0](../0-5-0/)。
