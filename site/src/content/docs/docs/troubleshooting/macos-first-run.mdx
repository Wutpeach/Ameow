从[下载页面](../../downloads/)获取 Apple Silicon 版本，将 `Ameow.app` 放入 `/Applications` 或 `~/Applications`，再从 Finder 打开。

Mac 要求 macOS 13 或更新系统；实测为 macOS 26.3 arm64，不代表较旧系统均已验证。Intel 和 Universal 不在 0.5.0 的平台范围内。

## 从菜单栏打开

点击菜单栏猫咪图标，选择打开 Ameow、设置或退出。默认不显示 Dock 图标；关闭设置窗口后应用仍在运行，可从菜单栏再次打开设置。

<ManualFigure kind="mac" />

在 Ameow 按 `Command+V` 粘贴公开媒体链接。首次使用可能先联网准备组件，不需要自行安装 Homebrew 或 Python。下载完成后，双击 Full 空白背景可在 Finder 打开当前输出目录。

## 看不到悬浮窗口

先从菜单栏选择打开。Compact 跟随普通 Spaces，但不会覆盖其他应用的全屏空间；切回普通桌面后再检查。Full 和设置窗口的 Spaces 行为不同，见[悬浮窗口](../../desktop/floating-window/)。

## 启动、登录项与更新

若系统阻止打开，先核对下载来源和系统版本，再按该版本的发行说明处理；反馈时附上完整系统提示。

开机启动需要安装好的应用包。如系统要求批准登录项，按提示在系统设置中完成。更新时只有目录权限不足才请求系统授权，取消后不会安装候选。应用更新与下载组件更新的入口见[设置](../../desktop/settings/)。

用户数据保存在 `~/Library/Application Support/AmeowNative`，与旧版 Electron 隔离。排障时保留此目录；复制失败任务或组件管理中的诊断，并记录系统版本和操作步骤。
