链接无效或无法确认目标媒体时，换成[支持范围](../../extension/supported-sites/)内的公开链接。组件准备或验证失败时检查网络并按组件管理提示恢复；保存失败时检查任务原目录及空间。

HTTP 403 表示请求被拒绝，429 表示限流；不能仅凭状态码确定具体原因。复制任务诊断并记录操作和提示，可在 [Issues](https://github.com/Wutpeach/Ameow/issues) 查询或反馈；不要公开私有链接、Cookies 或令牌。清理尚未确认时遵循应用提示等待或重试清理。

## 反馈前检查

记录发生在哪个阶段、操作步骤、任务提示和大致时间。最终失败时可使用任务的复制诊断操作；如果复制失败，不要假设已复制成功。

组件错误先查看组件管理和[恢复说明](../../advanced/download-dependencies/)；目录错误见[找不到文件](../missing-files/)。不要删除应用数据、公开私有路径或包含凭据的链接。
