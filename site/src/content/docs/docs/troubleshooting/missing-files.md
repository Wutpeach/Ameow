---
title: 找不到文件
description: 找不到文件
---

确认任务已完成，而非仍在下载或处理。打开设置中的输出目录；提交后若更改过目录，请检查提交时的旧目录。

目录移动、权限改变或空间不足可能导致失败；检查队列提示和诊断。应用不会悄悄改用其他目录。解决后可调整目录并提交新任务；失败任务的手动重试仍使用原目录。当前 Rust 不提供旧版本地文件收集。

## 核对步骤

1. 查看队列，等待下载和后处理完成；失败或取消不代表文件已保存。
2. 从设置打开输出目录，并检查任务提交后是否换过目录。
3. 在文件管理器查看提交时的目录；确认它仍存在且当前账户可访问。
4. 查看失败提示和可用空间。如需不同目录，先在设置中更改，再提交新任务。

不要清空 `%LOCALAPPDATA%\Ameow` 来寻找文件；它保存设置和运行时数据。
