## 下载失败

先看队列提示，按发生阶段处理：

| 现象 | 处理方法 |
| --- | --- |
| 链接被拒绝 | 使用[支持的公开媒体入口](../supported-sites/)，移除视频播放列表或系列参数。 |
| 组件准备失败 | 打开[组件与诊断](../desktop/settings/#components)，按提示重试或恢复推荐版本。 |
| 请求被拒绝或限流（403 / 429） | 等待后重试。状态码不能单独确定原因；站点、权限或网络变化都可能影响结果。 |
| 保存失败 | 检查任务提交时的目录是否存在、可写且空间足够。更改目录后需要提交新任务。 |
| 退出时清理异常 | 按应用提示等待或重试清理；收起界面不会撤销退出。 |

最终失败或部分完成的任务可按界面重试；原画质和目录保留。需要登录或地区权限的内容即使能在浏览器播放，也可能无法下载。

<span id="files"></span>

## 找不到文件

1. 确认队列显示完成，后处理结束前继续等待。
2. 打开[保存目录](../desktop/output-folder/)。提交后若切换过目录，查看任务原来的位置；重试也沿用原目录。
3. 若任务失败，解决目录权限或空间问题后重新提交。用户数据目录不是下载文件的替代位置。

## Mac 入口与启动

Mac 默认在菜单栏运行，没有 Dock 图标。关闭设置窗口不会退出应用，可从菜单栏再次打开。

<ManualFigure kind="mac" />

看不到悬浮窗口时先选择打开，或切回普通桌面：Compact 跟随普通 Spaces，不覆盖其他应用的全屏空间。此行为不适用于 Full 或设置窗口。

系统阻止启动时，核对[安装版本与来源](../downloads/)，保留完整系统提示再反馈。开机启动或更新的授权按系统提示处理，见[设置与更新](../desktop/settings/)。

## 反馈问题

从失败任务或组件与诊断页复制诊断，附上系统／应用版本、发生时间和可复现步骤，在 [GitHub Issues](https://github.com/Wutpeach/Ameow/issues) 查询或反馈。发送前检查内容，隐藏私人路径、私有链接和登录信息；不要为排障清空应用数据。
