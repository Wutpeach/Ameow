---
title: macOS 首次启动
description: 当前 Rust 平台范围及历史 macOS 发行。
---

当前 Rust / GPUI 只在 Windows x64 / MSVC 上验证，macOS 原生运行未验证，也没有公开的 Rust 安装包。

公开的历史版本是 [Electron v0.3.1](https://github.com/Wutpeach/Ameow/releases/tag/v0.3.1)。如需了解该版本的 macOS 资产和说明，请查看发行页及[对应源码](https://github.com/Wutpeach/Ameow/tree/v0.3.1)；旧版本的启动说明不能证明当前 Rust 支持 macOS。
