---
title: 扩展未连接
description: 当前 Rust 不接入旧扩展。
---

当前 Rust / GPUI 不提供旧浏览器扩展连接，因此旧扩展的 `Disconnected` 状态不会通过重启 Rust 应用恢复。可直接粘贴 [支持站点](../../extension/supported-sites/) 的公开单个视频链接。

如在使用历史 Electron 版本，请核对所安装的版本，并查阅 [v0.3.1 发行页](https://github.com/Wutpeach/Ameow/releases/tag/v0.3.1)及[源码](https://github.com/Wutpeach/Ameow/tree/v0.3.1)中的历史资料。
