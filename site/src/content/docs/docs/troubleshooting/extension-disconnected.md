---
title: 扩展未连接
description: 排查 Ameow 浏览器扩展显示 Disconnected、无法发送任务或网页入口无响应的问题。
---

扩展显示 `Disconnected` 表示浏览器扩展没有连上本机 Ameow 桌面端。最常见原因是桌面端没有启动、扩展需要重新加载，或本地连接被系统策略拦截。

这页只处理连接问题。连接恢复为 `Connected` 后，如果下载仍失败，就转到 [下载失败](../download-failures/)，不要继续反复重装扩展。

[截图：扩展弹窗显示 Disconnected，并提示桌面端未连接]

## 先做快速判断

先回答：

- 桌面上能看到 Ameow 悬浮窗口吗？
- 扩展弹窗是否能正常打开？
- 扩展是否刚刚安装或更新过？
- 电脑上是否有防火墙、安全软件或企业浏览器策略？

## 分支 A：桌面端没有启动

1. 启动 Ameow 桌面应用。
2. 确认悬浮窗口可见。
3. 重新打开扩展弹窗。
4. 等待状态变为 `Connected`。

成功状态：扩展弹窗显示 `Connected`。

## 分支 B：桌面端已启动，但仍 Disconnected

按顺序处理：

1. 关闭扩展弹窗后重新打开。
2. 在浏览器扩展管理页点击重新加载 Ameow 扩展。
3. 退出并重新启动 Ameow。
4. 再打开扩展弹窗。

如果刚刚更新过扩展或桌面端，重载扩展和重启桌面端通常能恢复连接。

## 分支 C：扩展弹窗异常或不显示

这通常是扩展加载问题：

1. 打开 `chrome://extensions` 或 `edge://extensions`。
2. 确认 Ameow 扩展已启用。
3. 如果浏览器提示 manifest 或目录错误，重新加载解压后的扩展目录。
4. 不要选择 zip 文件本身。

## 分支 D：本地连接被拦截

扩展默认连接本机地址 `127.0.0.1:39527`。如果安全软件、防火墙或企业策略阻止本地连接，扩展可能一直无法连接。

你可以：

- 临时关闭相关拦截规则后测试。
- 将 Ameow 加入允许列表。
- 在公司或受管设备上确认浏览器是否允许本地扩展连接。

## 连接恢复后仍无法下载

如果扩展已经 `Connected`，但网页任务仍失败，问题通常不再是连接本身。继续检查站点支持、登录态、链接有效性和输出目录。
