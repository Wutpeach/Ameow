确认链接指向公开媒体；YouTube 或 Bilibili 链接应指向单个视频并移除播放列表或系列参数。通用链接不保证成功，见[支持站点](../../extension/supported-sites/)。需要登录、会员或地区权限的内容可能不可用；当前不导入浏览器登录态。

查看任务提示和组件管理，组件未准备时恢复网络并按提示重试；离线恢复需要健康且保有签名证明的缓存。检查任务提交时的目录仍存在、可写且空间足够。站点限流、网络或内容变化也可能导致失败。条件改善后可手动重试最终失败任务，沿用原质量和目录。

仍失败时复制诊断并记录可公开步骤，不要提交 Cookies、令牌或私有链接。当前没有手动代理设置；单个 HTTP 错误不能确定具体原因。

## 按现象处理

- **链接被拒绝：** 打开具体媒体并确认公开；视频链接移除播放列表或系列参数。
- **组件准备失败：** 查看组件管理。健康且带签名证明的缓存可以离线恢复；缺少证明的旧缓存需要联网引导。按界面明确重试或确认恢复推荐版本。
- **保存失败：** 核对任务原目录、权限和空间；需要改变目录时提交新任务。
- **站点拒绝或限流：** 等待后重试，但不要仅凭 HTTP 状态推断账号或代理原因。

清理尚未确认时遵循应用提示等待或重试清理。不要删除应用数据或替换缓存中的程序来强行恢复；失败任务的诊断可用于反馈。
