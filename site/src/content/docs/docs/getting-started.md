这篇文档带你跑通 Ameow 的最短路径：下载应用、启动悬浮窗口、拖入一个文件、粘贴一个链接、找到输出目录。完成后，你就知道 Ameow 的核心工作方式。

## 开始前准备

你需要：

- 一台 Windows 电脑，或一台 Apple Silicon Mac。
- 一个可以测试拖拽的本地文件，例如桌面上的图片或文本文件。
- 一个可以测试的网页链接。第一次测试建议用公开页面链接，不要先用需要会员、地区限制或登录权限的内容。

如果还没有安装包，先打开 [下载 Ameow](../downloads/) 按平台选择文件。

## 1. 安装并启动 Ameow

### Windows

1. 下载 Installer EXE 后双击运行，按安装向导完成安装。
2. 如果下载的是 Portable ZIP，先完整解压，再运行解压目录里的 Ameow。
3. 启动后，桌面边缘会出现一个小型悬浮窗口。

后续更新时，安装版会继续打开安装器完成升级；便携版会优先下载新的 Portable ZIP，并在重启后替换当前便携版目录。如果便携版目录不可写或更新元数据不完整，请从发布页重新下载 Portable ZIP 手动替换。

### macOS

1. 打开 DMG。
2. 把 `Ameow.app` 拖到 `Applications`。
3. 从 `Applications` 启动 Ameow。
4. 如果系统提示无法验证开发者，右键 `Ameow.app`，选择“打开”。

[截图：Ameow 主悬浮窗口首次启动后的空闲状态，窗口停靠在桌面边缘]

成功状态：你应该能看到一个常驻桌面边缘的小窗口。它不是普通的大型主窗口，而是用来接收文件、文件夹和链接的入口。

## 2. 拖入一个本地文件

1. 在桌面或资源管理器里选中一个测试文件。
2. 把文件拖到 Ameow 悬浮窗口上。
3. 松开鼠标。

[截图：把一个本地文件拖入 Ameow 悬浮窗口时的接收状态]

成功状态：

- Ameow 会接收这个文件。
- 文件会被复制到当前输出目录。
- 原文件仍留在原来的位置，不会被移动或删除。

如果你拖入的是文件夹，含义不同：Ameow 会把这个文件夹设为新的输出目录，而不是复制整个文件夹。这个差异在日常使用里很重要。

## 3. 粘贴一个链接

1. 在浏览器里复制一个图片链接、视频链接或支持站点页面链接。
2. 回到 Ameow 悬浮窗口。
3. 按 `Ctrl+V`；macOS 使用 `Cmd+V`。
4. 观察窗口中的状态反馈。

成功状态：

- 如果链接可处理，任务会进入下载或准备流程。
- 如果需要解析网页媒体，可能先显示准备中。
- 如果链接不支持或失效，任务可能失败，需要换链接或使用浏览器扩展。

第一次测试时，不建议直接使用需要登录、会员或地区限制的内容。先用公开链接确认基础流程能跑通。

## 4. 打开输出目录

默认输出目录是：

```text
Desktop/Ameow_Received
```

你也可以直接从 Ameow 打开当前输出目录：

1. 双击悬浮窗口空白区域，或右键悬浮窗口。
2. 选择打开当前输出目录。
3. 找到刚才拖入或下载得到的文件。

[截图：Ameow 输出目录中出现刚刚收集的文件]

成功状态：输出目录里应该能看到刚才的测试文件。如果你刚刚拖入过一个文件夹，当前输出目录可能已经切换到那个文件夹，请优先打开“当前输出目录”，不要只看默认目录。

## 5. 安装浏览器扩展

桌面端可以独立使用。浏览器扩展是可选增强，用来把网页里的下载任务、页面上下文和登录态发送给桌面端。

建议在这些情况下安装扩展：

- 你主要下载网页视频。
- 某些站点需要登录态或 Cookies。
- 你想在网页里直接点击入口发送到 Ameow。

最短步骤：

1. 下载同版本的 `Ameow_<version>_browser_extension.zip`。
2. 解压 zip。
3. 在 Chrome 或 Edge 的扩展管理页开启开发者模式。
4. 点击 `Load unpacked`，选择解压后的扩展目录。
5. 启动 Ameow 桌面端，再打开扩展弹窗，确认显示 `Connected`。

## 常见第一次失败

### 看不到悬浮窗口

先确认 Ameow 已经启动。Windows 可以从开始菜单重新打开；macOS 请确认应用已经拖入 `Applications`。如果 macOS 阻止启动，按“右键打开”或系统设置放行。

### 拖入文件后找不到结果

打开当前输出目录。不要只看默认目录，因为拖入文件夹会切换输出目录。

### 粘贴链接没有反应

先确认链接本身可以在浏览器中打开。需要登录态的内容建议通过浏览器扩展发送。仍失败时按 [下载失败](../troubleshooting/download-failures/) 的排查树处理。
