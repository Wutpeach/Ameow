title: 浏览器扩展

Ameow 浏览器扩展用于把网页里的下载任务、页面上下文、Cookies 和部分下载偏好发送给桌面端。它不是独立下载器，必须配合正在运行的 Ameow 桌面应用使用。

[示意图：网页页面、浏览器扩展、本地 Ameow 桌面端之间的连接关系]

## 什么时候需要扩展？

你可以先只使用桌面端。下面这些情况再安装扩展：

- 你希望在网页页面内直接发送视频下载任务。
- 站点需要登录态或 Cookies。
- 复制链接后下载失败，但浏览器里能正常播放。
- 你想同步网页侧的质量偏好或 AE 兼容格式偏好。

如果你只是拖拽本地文件、整理输出目录或下载公开直链，扩展不是必需的。

## 最短使用路径

1. 安装并启动 Ameow 桌面端。
2. 从 GitHub Release 下载同版本的 `Ameow_<version>_browser_extension.zip`。
3. 解压扩展 zip。
4. 在 Chrome 或 Edge 的扩展管理页开启开发者模式。
5. 点击 `Load unpacked`，选择解压后的扩展目录。
6. 打开扩展弹窗，确认状态为 `Connected`。
7. 打开支持站点页面，通过扩展或页面内入口发送下载任务。

[截图：浏览器扩展弹窗显示 Connected 状态，并展示下载质量选项]

成功状态：扩展弹窗显示 `Connected`，Ameow 桌面端正在运行，网页发送任务后桌面端能看到下载状态或队列变化。

## Connected 和 Disconnected 是什么意思？

- `Connected`：扩展已经连上本机 Ameow 桌面端，可以发送任务。
- `Disconnected`：扩展没有连上桌面端。最常见原因是桌面端没启动，或者扩展需要重新加载。

扩展默认通过本机地址 `127.0.0.1:39527` 与桌面端通信。这个连接只发生在你的电脑本地，不是把 Cookies 发到第三方服务器。

## 从网页发送任务时会发生什么？

当你在支持站点页面上使用扩展入口时，扩展会把当前页面相关信息发送给 Ameow。桌面端负责创建下载任务、显示进度、写入输出目录，并根据你的下载质量偏好处理格式。

你应该看到：

- 扩展侧保持 `Connected`。
- 桌面端出现任务状态，例如准备中、下载中、转换中、完成或失败。
- 完成后文件进入当前输出目录。

如果网页内容需要登录态，请先确认你在浏览器里已经登录该站点，再从扩展发送任务。

## 扩展弹窗里的“当前页面资源”应该怎么用？

扩展弹窗扫描的是“当前活动标签页里已经打开的页面资源”。它最适合这些场景：

- 你已经打开了具体视频页、帖子页、作品页或图片详情页。
- 页面里的目标内容已经加载完成，并且你能在浏览器里正常播放或查看。
- 你想从当前内容页里挑一个更准确的媒体资源发送到 Ameow。

不建议在这些页面上直接依赖“当前页面资源”结果：

- 首页、推荐流、搜索结果页。
- 作者主页、合集页、频道页。
- 还没有进入具体内容的列表页或中转页。

原因很简单：这些页面往往同时挂着当前卡片、旁路推荐、预加载封面和其他媒体请求。弹窗能看到的不一定只有你眼前想要的那个资源。

更稳的做法是：先点进具体内容页，再打开扩展弹窗或页面内入口发送任务。

## 支持哪些浏览器？

当前扩展面向 Chromium 内核浏览器，例如 Chrome 和 Edge。安装方式使用开发者模式下的 `Load unpacked`。如果你的浏览器不支持加载 Manifest V3 扩展，可能无法使用。

## 常见问题

### 我把 zip 直接选进浏览器了，为什么失败？

浏览器需要选择解压后的扩展目录，而不是 zip 文件本身。先解压，再选择包含扩展 manifest 的文件夹。

### 扩展装好了但显示 Disconnected

先启动 Ameow 桌面端，再重新打开扩展弹窗。如果仍未连接，重新加载扩展并重启 Ameow。防火墙或安全软件也可能阻止本地连接。

### 网页里没有下载入口

确认当前站点和页面类型在支持范围内。优先在具体内容页上尝试，不要先在首页、推荐流、搜索结果页或合集页判断“扩展没反应”。站点支持会随版本变化，页面改版、登录限制、会员限制、地区限制都可能影响结果。
