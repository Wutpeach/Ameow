Download a whole video or select a clip on supported pages, and optionally authorize an existing site session. Browser extension support requires 0.5.1 or later. Use the extension and desktop app from the same version.

<span id="connection"></span>

## Install and connect

1. In the desktop app, open Settings → Download → Browser sessions, choose Connect browser, then Set up this computer and Copy path.
2. In the Edge or Chrome browser you want to use, open extension management, enable Developer mode, choose Load unpacked, paste the path, and select that folder.
3. Open the Ameow extension on an ordinary page and check the connection status. Follow the next section to enable page tools or authorize the current site.

After setting up this computer, load the extension in that same browser. Complete packages include the matching extension; source builds place it in <code>browser-extension/dist</code>. Chromium browsers are supported; Firefox is not yet available.

<span id="permissions"></span>

## Page tools and site authorization

Enable **page tools** and allow page access to show the toolbar in the player. To sync a session, separately choose Authorize this site (授权此站点), check the site and subdomain scope, and confirm the browser permission. Unauthorized sites continue with anonymous attempts.

<span id="sessions"></span>

## Sync an existing browser session

Authorize the site in a browser where you are already signed in. The extension syncs the existing session; it does not sign in for you. It continues updating after session changes, browser startup, or reconnection. The downloader and site determine downloadability and visible formats.

In Settings → Download → Browser sessions, select a site badge to check its browser source and latest sync result. The extension shows only the current page's site. To replace the source, choose Use this browser (改用此浏览器) in the browser you want to use. Remove deletes Ameow's saved session for that site without signing you out.

<details>
<summary>Cache and sync results</summary>

The latest sync result and last successful cache time appear separately. An older cache may remain after a failed sync; finding no cookies does not confirm that you are signed in. The actual result determines whether the site still accepts the session and which quality levels it offers.

</details>

<span id="page-tools"></span>

## Download a whole video from the page

On a single on-demand Bilibili or YouTube video, enable page tools and hover over the Ameow icon at the top-right of the player. Choose Download (下载) or Clip (切片). Page tools do not automatically authorize a session; return to the specific video page if the target cannot be matched.

<span id="clips"></span>

## Select one clip

Move the playhead and press Marker to add a point. Drag either side to set the in and out boundaries; pressing Marker again clears an existing point or range.

<ClipDemo lang="en" />

Check the range and choose Download clip (下载片段). Each submission contains one range from one work; fast cutting may place actual boundaries near keyframes.

<details>
<summary>More controls</summary>

I and O set the respective boundary at the current playback position. Time inputs can be selected and edited; display-only text cannot. Focus selection (聚焦选区) enlarges the visible window without changing the range when returning to the whole video. Reopening Peek on the same work retains the draft; changing videos clears it. Esc closes Peek and restores the page. Clearing a draft does not cancel a submitted task. Data usage and waiting time depend on the source.

</details>
