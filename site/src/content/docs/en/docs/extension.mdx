## Install and connect

<Steps>
1. In the desktop app, open Settings → Components and select the Set up extension wrench on the browser extension row. When setup finishes, copy the displayed extension path.
2. In the Edge or Chrome browser you want to use, open extension management, enable Developer mode, choose Load unpacked, paste the path, and select that folder.
3. Open the Ameow extension on a regular website to enable page tools or authorize the current site.
</Steps>

The demo on the setup page shows how to load it. Use the extension supplied with your desktop app version.

Windows users upgrading from an older version to 0.5.2 should [fully reinstall](../downloads/#upgrade); Mac continues to update the complete App. Future Windows in-app updates from 0.5.2 update the complete set of files. After updating, set up the extension from Components, reload Ameow at the displayed current path in browser extension management, and refresh the pages you are using. Updating desktop files does not reload browser code.


<span id="permissions"></span>

## Page tools and site authorization

The **Clip/download toolbar** is on by default. Allow page access to show download and clip actions in the player. You can turn them off in the extension; your choice is remembered per site. Session sync needs separate authorization for the current site, so check the scope shown by the extension before confirming.

Xiaohongshu page access is requested when needed. Open the extension on a video note, turn on the toolbar, and allow access to the current site. This enables page tools; session sync still needs separate authorization.

## Sync an existing browser session

Authorize the site in a browser where you are already signed in to keep the session in sync. Ameow does not sign in for you. The site and downloader determine available content and quality.

Authorized sites appear as badges and names in the desktop app. Hover or focus a site to see its status. The extension shows only the current page's site; to switch browser sources, follow its prompts in the browser you want to use.

To remove authorization, open the extension on that site and choose Remove. This deletes Ameow's saved session without signing you out of the website.

<details>
<summary>Troubleshoot a sync problem</summary>

First check that you are still signed in to the site in the source browser. To report a problem, select the copy icon next to Diagnostics to copy the report.

</details>

<span id="page-tools"></span>

## Download a whole video from the page

On a single on-demand Bilibili or YouTube video, or a Xiaohongshu video note, hover over the Ameow icon at the top-right of the player. Choose Download or Clip. If the icon is missing, check page tools and page access in the extension.

Keep the complete Xiaohongshu share link, including its query parameters. Image notes, ambiguous multiple players, or an unconfirmed current work do not show the toolbar. Closing the note removes the actions; changing notes clears the previous selection.

<span id="clips"></span>

## Select one clip

Move the playhead and press Marker to add a point. Drag either side to set the in and out boundaries; pressing Marker again clears an existing point or range.

<ClipDemo lang="en" />

Check the range and select Download at the lower-right. Each submission contains one range from one work; fast cutting is the default and may place actual boundaries near keyframes. Enable Precise to re-encode, which takes longer. Reopening Peek on the same work retains the choice; changing works resets it to off.

<details>
<summary>More controls</summary>

Click the keyboard icon at the lower left to see the shortcuts. Esc closes help first; press it again to close Peek. Click or drag on the time ruler to seek without changing the selection. I and O set the respective boundary at the current playback position. Drag a marker or use the arrow keys to adjust it; display-only text cannot be selected. Press F or select the focus button to focus near one marker or on the full selection. Press again to return to the full timeline. Focus is unavailable without a marker and preserves the range and playback position. Reopening Peek on the same work retains the draft; changing videos clears it. Esc closes Peek and restores the page. Clearing a draft does not cancel a submitted task. Data usage and waiting time depend on the source.

</details>
