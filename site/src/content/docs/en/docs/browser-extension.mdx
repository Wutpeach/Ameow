title: Browser extension
description: Current Rust and the historical Electron extension.
---

The current Rust / GPUI application does not connect to the old browser extension. Paste a public single-video YouTube or Bilibili link into the app; web resource collection and cookie import through the extension are unavailable. See [supported sites](../extension/supported-sites/).

[Electron v0.3.1](https://github.com/Wutpeach/Ameow/releases/tag/v0.3.1) and its extension are discontinued and unsupported, retained only as history. Consult the [v0.3.1 source](https://github.com/Wutpeach/Ameow/tree/v0.3.1) and release page for its features and assets; those features do not imply Rust support.
