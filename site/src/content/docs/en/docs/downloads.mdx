Mac requires Apple Silicon and macOS 13 or later. Intel Macs, Universal, and Linux are not supported.

## Windows

<Steps>
1. Run the installer, finish the wizard, and open Ameow from the Start menu. For the portable version, extract the whole archive and run `Ameow.exe`.
2. Follow the [quick start](../) to choose a destination and submit a link. Ameow prepares the required download components over the network on first use.
</Steps>

The installer follows the Windows display language for Chinese or English and uses English for other languages. Set the [app language](../desktop/settings/) separately.

<Aside title="Moving the portable folder">
Exit Ameow first, move the complete folder, then check shortcuts and login startup. Uninstall keeps user data by default.
</Aside>

## Mac

<Steps>
1. Download and extract the Mac ZIP, place `Ameow.app` in `/Applications` or `~/Applications`, and open it from Finder.
2. Choose Open or Settings from the cat in the menu bar. No Dock icon appears by default; see [Mac help](../troubleshooting/#mac) for entry points and launch problems.
</Steps>

## Upgrade

Check for application updates in [Settings → About](../desktop/settings/), then follow the download and restart prompts. Download components are managed separately in Components.

**Windows users should fully reinstall when upgrading from an older version to 0.5.2.** Exit Ameow, uninstall the old version and clear its old program folder, or install into a new empty folder. Extract the portable version into a new empty folder too, and update old shortcuts. Keep your settings, component cache and downloaded files. Older Windows in-app updates cannot perform this directory layout change. Mac continues to update the complete App as prompted and does not need the Windows program-folder cleanup.

Starting with 0.5.2, both complete Windows packages include the app, CLI, browser connection component and extension; future in-app updates replace the complete set. The complete portable ZIP also serves in-app updates, with no separate single-program update ZIP. Mac continues to update the full App. The two signed update JSON files are for automatic updates and need no manual download.

After updating, set up the extension from Components, reload Ameow at the current path in browser extension management, then refresh the pages you are using. See [extension setup](../extension/#connection).
