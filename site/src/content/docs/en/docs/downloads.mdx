Mac requires Apple Silicon and macOS 13 or later. Intel Macs, Universal, and Linux are not supported.

## Windows

<Steps>
1. Run the installer, finish the wizard, and open Ameow from the Start menu. For the portable version, extract the whole archive and run `AmeowLauncher.exe`.
2. Follow the [quick start](../) to choose a destination and submit a link. Ameow prepares the required download components over the network on first use.
</Steps>

The installer follows the Windows display language for Chinese or English and uses English for other languages. Set the [app language](../desktop/settings/) separately.

<Aside title="Moving the portable folder">
Exit Ameow first, move the complete folder, then check shortcuts and login startup. Uninstall keeps user data by default.
</Aside>

## Mac

<Steps>
1. Download and extract the Mac ZIP, place `Ameow.app` in `/Applications` or `~/Applications`, and open it from Finder.
2. Choose Open or Settings from the cat in the menu bar. No Dock icon appears by default; see [Mac help](../troubleshooting/#mac) for entry points and launch problems.
</Steps>

## Upgrade

Check for application updates in [Settings → About](../desktop/settings/), then follow the download and restart prompts. Download components are managed separately in Components.

Windows in-app updates replace only the main executable. To update the extension and connection components, use the full installer or portable package, set up and reload the extension, then refresh video pages. See [extension setup](../extension/#connection).
