The public release is [Electron v0.3.1](https://github.com/Wutpeach/Ameow/releases/tag/v0.3.1). Rust / GPUI is the current source baseline and has no public installer.

<Steps>
1. For the public release, check the assets on the [v0.3.1 release page](https://github.com/Wutpeach/Ameow/releases/tag/v0.3.1).
2. To run Rust source on Windows x64, install Rust 1.93.0, Visual Studio C++ Build Tools, and the Windows SDK.
3. Run `cargo build --locked` at the repository root, then run `./target/debug/ameow.exe`.
</Steps>

A source build is not a public release. Native macOS and Linux operation is unverified. See the [developer guide](../developer/).

## Before and after running

Running source requires the Windows x64 / MSVC toolchain; the app itself does not require Node, Python, or Electron. Component preparation may need network access, and the output folder should exist and be writable. After building, follow [Get started](../getting-started/) to submit a public single-video link.

Assets and the old extension on the historical release page belong to Electron and do not establish Rust features or platform support. See [release history](../releases/).
