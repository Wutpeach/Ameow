## Running on Windows

Source builds require Rust 1.98.1, Visual Studio C++ Build Tools, and the Windows SDK. Run `cargo build --locked --bin ameow` at the repository root, then `./target/debug/ameow.exe`.

After an official release, the installer will provide a Start menu entry, Windows uninstall registration, and an optional desktop shortcut. Fully extract the portable ZIP and start `AmeowLauncher.exe`. Both use the same app and secure updater. Uninstall retains `%LOCALAPPDATA%\Ameow` user data by default.

## Running on macOS

Apple Silicon Macs can run from source; see [local development](../developer/local-development/) for the toolchain. If you already have a Rust test build of `Ameow.app`, place it in `/Applications` or `~/Applications`, then open it from Finder. The menu bar provides open, settings, and quit; no Dock icon appears by default. See [first launch on macOS](../troubleshooting/macos-first-run/).

The app prepares and manages its download components; using it does not require a separate Node, Homebrew, or Python installation. First-time component preparation may need network access, and the output folder should exist and be writable. App updates and component updates are separate; see [settings and updates](../desktop/settings/).

Assets and the old extension on historical release pages belong to older versions and do not establish current Rust features or platform support. See [release history](../releases/).
