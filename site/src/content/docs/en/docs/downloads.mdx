Mac requires macOS 13 or later and Apple Silicon. Intel Macs, Universal, and Linux are outside this version's scope.

## Windows

<Steps>
1. Run the installer, finish the wizard, and open Ameow from the Start menu. For the portable version, extract the whole archive and run `AmeowLauncher.exe`.
2. Follow the [quick start](../) to choose a destination and submit a link. Ameow prepares the required download components over the network on first use.
</Steps>

Keep the portable directory intact. Exit before moving it, then check shortcuts and login startup. Uninstall keeps user data by default.

The linked 0.5.0 installer is in English. The newer installer follows the Windows display language for Chinese or English and falls back to English for other languages; the [app language](../desktop/settings/) is separate. Region, date, and number formats do not choose the installer language.

The 0.5.0 package does not include the CLI added later. See the [command-line guide](../cli/) for availability and use in versions that include it.

## Mac

1. Download and extract the Mac ZIP, place `Ameow.app` in `/Applications` or `~/Applications`, and open it from Finder. You do not need to install Homebrew or Python separately.
2. Choose Open or Settings from the cat in the menu bar. No Dock icon appears by default; see [Mac help](../troubleshooting/#mac) for entry points and launch problems.

## Upgrade

In the Rust app, check for application updates in [Settings → About](../desktop/settings/), then follow the download and restart prompts. Download components are managed separately in Components.

<details>
<summary>Moving from the old Electron app</summary>

Install the Rust app and choose your save folder and preferences again. The apps keep separate data; old settings, caches, and history do not migrate automatically, and an automatic upgrade is not promised.

</details>
