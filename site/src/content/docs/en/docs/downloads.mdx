Rust / GPUI is the only product line and has not been officially released. The Windows x64 installer and portable ZIP release process has been prepared, but no Rust download has been officially published yet. [Electron v0.3.1](https://github.com/Wutpeach/Ameow/releases/tag/v0.3.1) is discontinued and unsupported, retained only as history.

<Steps>
1. Use the source-build steps below; historical Electron packages are not the current product.
2. To run Rust source on Windows x64, install Rust 1.98.1, Visual Studio C++ Build Tools, and the Windows SDK.
3. Run `cargo build --locked` at the repository root, then run `./target/debug/ameow.exe`.
</Steps>

A source build is not a public release. Native macOS and Linux operation is unverified. See the [developer guide](../developer/).

After an official release, the installer will provide a Start menu entry, Windows uninstall registration and an optional desktop shortcut. The portable ZIP must be fully extracted and started with `AmeowLauncher.exe`. Both use the same app and secure updater. Uninstall retains `%LOCALAPPDATA%\Ameow` user data by default.

## Before and after running

Running source requires the Windows x64 / MSVC toolchain; the app itself does not require Node, Python, or Electron. Component preparation may need network access, and the output folder should exist and be writable. After building, follow [Get started](../getting-started/) to submit a public single-video link.

Assets and the old extension on the historical release page belong to Electron and do not establish Rust features or platform support. See [release history](../releases/).
