Install Rust 1.93.0, Visual Studio C++ Build Tools, and the Windows SDK on Windows x64, then run at the repository root:

```powershell
cargo build --locked
./target/debug/ameow.exe
```

There is no public Rust installer. See [local development](../developer/local-development/) for the full prerequisites.

Move the pointer near the compact window to expand it, check the output folder in settings, and paste a public single-video YouTube or Bilibili link. Watch the queue and open the folder after completion. First run may need network access to prepare components. See [links and queue](../desktop/links-and-queue/) and [troubleshooting](../troubleshooting/).

## Your first download

1. In download settings, confirm the output folder exists and is writable; change it if needed and open it to check the location.
2. Copy a supported public video URL in the browser and press `Ctrl+V` in Ameow's input entry to submit it.
3. Wait for component preparation and queue processing. If components need attention, open components management and follow its prompt.
4. Once the task shows completion, open the file in the folder selected at submission.

Move the pointer near the compact window to expand it. Downloads continue while hidden; restore it from the tray. When quitting with active tasks, choose continue or stop and exit; the latter waits for cleanup. See [floating window](../desktop/floating-window/) and [download components](../advanced/download-dependencies/).
