There is no public Rust installer yet. Check [downloads and startup](../downloads/) for platform scope and [local development](../developer/local-development/) for source-build prerequisites and commands. Start an existing Windows test distribution through `AmeowLauncher.exe`; open an existing macOS test build of `Ameow.app` from Finder.

The app starts with the cat in the compact window (Compact). Move the pointer near it to expand the full window (Full). Restore a hidden window from the Windows system tray or the Mac menu bar. No Dock icon appears by default on Mac.

## Your first download

1. Open settings from the Full window's right-click menu or the tray/menu bar. In Download, confirm the output folder exists and is writable; change it if needed and open it to check the location.
2. Copy a supported public video URL in your browser, such as a single YouTube or Bilibili video. In Ameow, press `Ctrl+V` on Windows or `Command+V` on macOS to submit it.
3. Wait for component preparation and queue processing. First-time preparation may need network access. If components need attention, open Components management and follow its prompt.
4. Once the task shows completion, open the file in the folder selected at submission. Open that folder from settings or by double-clicking the Full window's empty background.

See [supported sites](../extension/supported-sites/) for other public image and generic-link scope. Quality and output folder are captured at submission; later setting changes affect new tasks. See [links and queue](../desktop/links-and-queue/).

## Hide and quit

Downloads continue while hidden. Choose open from the tray or menu bar to restore the window. Quitting stops tasks and waits for safe cleanup, without a routine confirmation dialog. Only a cleanup problem displays its cause and available recovery actions. See [floating window](../desktop/floating-window/) and [download components](../advanced/download-dependencies/).
