## In preparation

- A global shortcut to show or hide Ameow.
- Browser page tools, a compact extension popup, site-session authorization and single-range clips, with optional precise re-encoding.
- Download progress shows network speed; media processing shows a processing multiplier. Copy diagnostics when a task fails.
- CLI improvements and a Windows installer that follows the display language.
- Improved YouTube section transfer and precise encoding speed. Precise cutting still re-encodes and validates the resulting boundaries.

Use the full installer or portable package to update the extension and connection components. Set up and reload the extension, then refresh video pages. Windows in-app updates replace only the main executable.

The published release remains [v0.5.0](../0-5-0/).
