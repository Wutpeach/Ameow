The current source is the Rust / GPUI application at the repository root, verified on Windows x64 / MSVC. Rust has not been officially released; the release process for the installer and portable ZIP has been prepared. [Electron v0.3.1](https://github.com/Wutpeach/Ameow/releases/tag/v0.3.1) is discontinued and unsupported.

- [Local development](./local-development/): toolchain and launch.
- [Environment variables](./environment-variables/): data path and test inputs.
- [Testing](./testing/): validation scope and native UI.
- [Documentation and locales](./docs-and-locales/): independent site development and deployment.

See [CONTRIBUTING](https://github.com/Wutpeach/Ameow/blob/main/CONTRIBUTING.md), the [Rust contract index](https://github.com/Wutpeach/Ameow/blob/main/.trellis/spec/rust/index.md), and the [repository handoff](https://github.com/Wutpeach/Ameow/blob/main/docs/repository-handoff.md) for source structure and constraints. Historical Electron source is available at the [v0.3.1 tag](https://github.com/Wutpeach/Ameow/tree/v0.3.1).
