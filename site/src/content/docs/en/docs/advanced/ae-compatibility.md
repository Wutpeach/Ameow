---
title: AE compatibility
description: Version scope of the historical AE format feature.
---

The old Electron version offered an AE compatibility format feature. Current Rust / GPUI does not provide that historical feature and cannot guarantee output encoding or containers suitable for After Effects. Verify the completed file in your target software; use a separate tool suited to your workflow if conversion is needed.

See the [Electron v0.3.1 source](https://github.com/Wutpeach/Ameow/tree/v0.3.1) and [release notes](https://github.com/Wutpeach/Ameow/releases/tag/v0.3.1) for historical behavior.
