---
title: Extension disconnected
description: Current Rust does not connect to the old extension.
---

Current Rust / GPUI does not provide the old browser extension connection, so restarting Rust cannot clear the old extension's `Disconnected` status. Paste a public single-video link from a [supported site](../../extension/supported-sites/) directly into the app.

If you are using historical Electron, check the installed version and consult the [v0.3.1 release](https://github.com/Wutpeach/Ameow/releases/tag/v0.3.1) and [source](https://github.com/Wutpeach/Ameow/tree/v0.3.1) for historical material.
