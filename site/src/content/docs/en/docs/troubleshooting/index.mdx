## Download problems

Read the queue message and check the stage:

| Symptom | What to do |
| --- | --- |
| Link rejected | Use a [supported public media entry](../supported-sites/). Remove video playlist or series parameters. |
| Component preparation failed | Open [Components](../desktop/settings/#components) and follow the retry or recommended-version recovery prompt. |
| Request rejected or rate-limited (403 / 429) | Wait before retrying. A status code alone does not establish the cause; site, permission, or network changes can affect results. |
| Saving failed | Check that the task's original folder exists, is writable, and has enough space. Submit a new task to use a different folder. |
| Cleanup problem while quitting | Follow the app's wait or cleanup-retry prompt. Collapsing the view does not cancel quitting. |

Retry a failed or partial task when offered; its original quality and folder are retained. Content requiring login or regional access may be unavailable even if it plays in a browser.

<span id="files"></span>

## Missing files

<Steps>
1. Confirm the queue shows completion; wait until post-processing finishes.
2. Open the [destination folder](../desktop/output-folder/). If you changed it after submitting, check the task's original location; retries also retain it.
3. For a failed task, resolve permissions or space problems and submit again. The app's data directory is not a fallback download location.
</Steps>

<span id="editor-audio"></span>

## No sound in an editor

If a player has sound but an editor detects no audio track, keep the original and check the editor version, container, and codecs. In one Windows Resolve Studio case, an H.264 + Opus MKV had audio after remuxing to MP4 without re-encoding. Results vary with the file and editor version; Ameow does not perform this conversion automatically.

## Mac entry points and startup

Ameow runs in the menu bar with no Dock icon by default. Closing settings does not quit it; reopen from the menu bar.

<ManualFigure kind="mac" lang="en" />

If the floating window is missing, choose Open from the menu bar or return to a normal desktop.

<details>
<summary>Window, paste, and startup details</summary>

Compact follows ordinary Spaces but does not cover another app's fullscreen Space. This behavior does not apply to Full or settings.

Press `Command+V` in Full to paste; its right-click menu has no Paste item. If nothing happens, include the app version, entry point, and steps in your report.

If macOS blocks launch, check the [installed version and source](../downloads/) and keep the complete system message for a report. Follow system prompts for login-startup or update authorization; see [Settings and updates](../desktop/settings/).

</details>

## Report a problem

Copy diagnostics from a failed task or Components. Include system/app versions, time, and reproducible steps in [GitHub Issues](https://github.com/Wutpeach/Ameow/issues).

<Aside title="Before sending">
Review diagnostics and hide personal paths, private links, and login details. Routine troubleshooting does not require clearing app data.
</Aside>
