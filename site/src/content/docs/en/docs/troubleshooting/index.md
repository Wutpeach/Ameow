Check the task status and message, then see [download failures](./download-failures/), [error messages](./error-messages/), or [missing files](./missing-files/). The old extension does not connect to Rust; see [extension disconnected](./extension-disconnected/). See [macOS first launch](./macos-first-run/) for platform scope.

Copy failed-task diagnostics for a report; do not publish cookies, tokens, or private links.

## Suggested order

1. Confirm the link and content fall within the [public media scope](../extension/supported-sites/).
2. Read the queue message to distinguish component preparation, downloading, and saving.
3. Check the output folder captured at submission; do not clear the data directory.
4. If the issue persists, copy diagnostics and record shareable steps, time, and the error message.

Diagnostics help identify the phase and component state. Review what you share and avoid private links or login information.
