description: Error messages
---

For invalid links or an unconfirmed media target, use a public link within the [supported scope](../../extension/supported-sites/). For component preparation or verification failures, check connectivity and follow components management prompts; for save failures check the task's original folder and space.

HTTP 403 means forbidden; 429 indicates rate limiting. Neither alone establishes the cause. Copy task diagnostics and record the action and message when consulting or reporting on [Issues](https://github.com/Wutpeach/Ameow/issues); do not publish private links, cookies, or tokens. If cleanup is unconfirmed, follow the app's waiting or cleanup retry prompt.

## Before reporting

Record the phase, steps, task message, and approximate time. For a final failure, use the task's copy diagnostics action; if copying fails, do not assume the clipboard contains it.

For component errors, check components management and [recovery guidance](../../advanced/download-dependencies/); for destination errors see [missing files](../missing-files/). Do not delete app data or publish private paths or credential-bearing links.
