---
title: First launch on macOS
description: Current Rust platform scope and historical macOS releases.
---

Current Rust / GPUI has only been verified on Windows x64 / MSVC. Native macOS operation is unverified, and there is no public Rust installer.

The public historical release is [Electron v0.3.1](https://github.com/Wutpeach/Ameow/releases/tag/v0.3.1). For its macOS assets and notes, see that release and its [versioned source](https://github.com/Wutpeach/Ameow/tree/v0.3.1); old launch instructions do not establish current Rust macOS support.
