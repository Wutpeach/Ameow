---
title: Connect to the desktop app
description: The old extension connection does not apply to current Rust.
---

The current Rust / GPUI application does not provide the old browser extension connection. Restarting Rust or changing network settings will not connect the old extension.

Paste a public single-video link from a [supported site](../supported-sites/) directly into the application. The historical Electron and extension connection implementation is in the [v0.3.1 source](https://github.com/Wutpeach/Ameow/tree/v0.3.1); public assets are on the [release page](https://github.com/Wutpeach/Ameow/releases/tag/v0.3.1).
