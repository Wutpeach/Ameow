---
title: Install the extension
description: Ameow 0.5.0 and the historical browser extension.
---

Ameow 0.5.0 does not connect to the old browser extension, so no extension installation is needed. Paste a supported public single-video link directly into the application; see [supported sites](../supported-sites/).

The historical extension belongs to the Electron version. For old release assets or instructions, see the [v0.3.1 release](https://github.com/Wutpeach/Ameow/releases/tag/v0.3.1) and [versioned source](https://github.com/Wutpeach/Ameow/tree/v0.3.1). Historical assets and site behavior do not establish Ameow 0.5.0 support.
