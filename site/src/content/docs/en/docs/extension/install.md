---
title: Install the extension
description: Current Rust and the historical browser extension.
---

The current Rust / GPUI application does not connect to the old browser extension, and there is no extension installation procedure for Rust. Paste a supported public single-video link directly into the application; see [supported sites](../supported-sites/).

The historical extension belongs to the Electron version. For old release assets or instructions, see the [v0.3.1 release](https://github.com/Wutpeach/Ameow/releases/tag/v0.3.1) and [versioned source](https://github.com/Wutpeach/Ameow/tree/v0.3.1). Historical assets and site behavior do not establish current Rust support.
