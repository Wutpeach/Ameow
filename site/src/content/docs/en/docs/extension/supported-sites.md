---
title: Supported sites
description: Distinguish current Rust downloads from the historical extension.
---

The current Rust / GPUI source accepts public single YouTube and Bilibili videos, as well as explicit Imgur image/album and Bluesky single-post image links. Other public HTTP(S) links can be attempted, but are delivered only when the downloader can verify a single video or image and its result; success is not guaranteed. Real network downloading of an Imgur album remains unverified. Site changes, regional restrictions, or permissions can still cause failures. Current Rust does not connect to the browser extension or import cookies or browser login sessions.

The generic entry does not imply support for arbitrary sites, mixed posts, large playlists, or web resource collection. See the [Electron v0.3.1 release](https://github.com/Wutpeach/Ameow/releases/tag/v0.3.1) and [versioned source](https://github.com/Wutpeach/Ameow/tree/v0.3.1) for the historical scope; sites may have changed since then.
