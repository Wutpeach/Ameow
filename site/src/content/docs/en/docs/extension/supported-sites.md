---
title: Supported sites
description: Distinguish current Rust downloads from the historical extension.
---

The current Rust / GPUI source accepts public single-video links from YouTube and Bilibili. Site changes, regional restrictions, or permissions can still cause failures; availability of every item is not guaranteed. Current Rust does not connect to the browser extension or import cookies or browser login sessions.

Other sites and web resource collection were historical Electron / extension capabilities and do not imply Rust support. See the [Electron v0.3.1 release](https://github.com/Wutpeach/Ameow/releases/tag/v0.3.1) and [versioned source](https://github.com/Wutpeach/Ameow/tree/v0.3.1) for the historical scope; sites may have changed since then.
