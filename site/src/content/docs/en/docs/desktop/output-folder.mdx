In Download settings, choose an existing writable folder, open it, or copy its path.

<ManualFigure kind="settings-download" lang="en" />

## Drop a folder

Drag one writable folder onto Full and use the feedback below to confirm the change.

<ManualFigure kind="folder" lang="en" />

The change takes effect after success feedback; files, multiple folders, and unwritable folders do not switch the destination. New tasks use the new location, while queued tasks and retries keep their submission folder. Existing files stay put.

## Open downloaded files

Double-click Full's empty background or open the current confirmed folder from settings. The old folder does not open while a change is being saved. If [files are missing](../../troubleshooting/#files), confirm the task completed and check its submission folder. Ameow does not silently switch to another destination.
