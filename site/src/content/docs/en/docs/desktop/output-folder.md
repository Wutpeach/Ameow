In download settings, view, open, change, or copy the output folder. Choose an existing writable folder.

![Output folder in download settings](/Ameow/images/docs/rust-settings-en-download.png)

This reuses accepted historical #15 evidence with the path redacted, not a new capture. A task retains its folder at submission; changes affect new tasks. If the original folder is unavailable the task may fail rather than silently switch folders. See [missing files](../../troubleshooting/missing-files/).

## Change and find

1. View the current path in download settings and use open to check the folder.
2. To change it, choose another existing writable folder; copy can place the path on the clipboard for your file manager.
3. New tasks use the new folder; earlier tasks keep their submission folder. Check the appropriate location after completion.

If the folder moved, permissions changed, or space ran out, address the task message first. Submit a new task to use a new folder; retry of a failure retains the original folder. Do not delete application data to look for files.
