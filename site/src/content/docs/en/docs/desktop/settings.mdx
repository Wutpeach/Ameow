Choose quality in [Full's right-click menu](../../supported-sites/#quality). Download settings manage the [save location](../output-folder/).

## Update the app

Check in About, then follow the download and restart prompts. You can enable automatic checks, background downloads, and automatic restart after tasks finish. Running tasks finish safely first.

<ManualFigure kind="updates" lang="en" />

Windows launches the new version through the Launcher. Mac updates the complete `Ameow.app`, requesting system authorization only when directory permissions require it. Cancelling authorization or failing verification leaves the update uninstalled. Follow recovery prompts if replacement or startup fails; user data is retained.

## Manage download components

Ameow prepares required components on first use. Normal startup checks stay quiet with a healthy cache. In Components, manually check stable yt-dlp versions, then confirm a selection to download, verify, and switch safely. Checking alone does not change versions.

If preparation fails, follow the message to retry or confirm restoring the recommended version. A healthy cache with signed proof can recover offline; a cache without proof needs network access. Failure keeps the original selection. Do not replace cached programs manually or clear app data.

<details>
<summary>What each component does</summary>

| Component | Purpose |
| --- | --- |
| yt-dlp | Parse and download videos. |
| gallery-dl | Download images and galleries. |
| Deno | Provide the downloader's JavaScript environment. |
| FFmpeg / ffprobe | Process, merge, and inspect media. |

</details>

<details>
<summary>Login startup, moving the app, and data location</summary>

Windows login startup points to `AmeowLauncher.exe`. Check shortcuts and startup after moving a portable folder. On Mac, manage system login items from the installed `Ameow.app` and approve in System Settings when prompted. Recheck after moving the app.

| Platform | User data directory (not downloads) |
| --- | --- |
| Windows | `%LOCALAPPDATA%\Ameow` |
| macOS | `~/Library/Application Support/AmeowNative` |

Settings and component caches live here; routine troubleshooting does not require clearing them.

</details>
