Open settings from Full's right-click menu, the Windows tray, or the Mac menu bar. Closing settings does not quit the app.

Choose theme, language, and tray icon in General. Choose quality in [Full's right-click menu](../../supported-sites/#quality). Download settings manage the [save location](../output-folder/).

<span id="shortcut"></span>

## Summon shortcut

Record Show / hide Ameow in General. The default is `Ctrl+Shift+F`.

<ManualFigure kind="shortcut" lang="en" />

Leave the field or press Tab to save, press Esc to cancel, or use X to clear and disable it. On Mac the default appears as `⌃⇧F`.

<details>
<summary>Shortcut conflicts or save failures</summary>

An occupied combination or failed save keeps the previous preference. If the original shortcut is also unavailable, a message appears beside the field. A new shortcut takes effect only after a successful save.

</details>

## Browser sessions

In Components, select the Set up extension wrench on the first row and copy the displayed path. Follow [Install and connect](../../extension/#connection) to load the extension in your browser.

Authorized sites appear as brand badges and names in Download settings. Hover or focus a site to see its status. For help with a sync problem, expand diagnostics and copy the report. See [Browser session sync](../../extension/#sessions) for authorization and removal.


## Update the app

Check in About, then follow the download and restart prompts. With Automatic updates on, Ameow downloads in the background and restarts to install at a suitable idle time after tasks finish and resources are released. Turning it off keeps checks active and leaves downloading and installation to you. Update notifications independently controls the app update reminder at the lower-left of Full without changing automatic update policy. You can also download or restart an update directly from that popover.

<details>
<summary>Update and recovery details</summary>

Starting with 0.5.2, Windows launches a complete new version through the root Ameow.exe. Existing users should first [fully reinstall](../../downloads/#upgrade). Mac updates the complete `Ameow.app`, requesting system authorization when directory permissions require it. Cancelling authorization or failing verification leaves the update uninstalled. Follow recovery prompts if replacement or startup fails; user data is retained.

</details>

## Manage download components

Ameow prepares components on first use. The check icon at the top of Components checks both yt-dlp and gallery-dl. When an installable update is available, use that row’s update arrow to download, verify and switch; hover to see the target version. Each downloader’s more menu can restore Ameow’s recommended version. Checking or opening the page does not install anything.

The navigation dot marks an unseen version and clears after viewing; a component-row dot means an update is still available. Optional downloader updates appear only in Settings. Other runtime components follow Ameow updates. The browser extension is the first row. After its files update, reload it in the browser and refresh your pages as prompted; Full’s extension entry opens that row directly.

<details>
<summary>Component preparation and recovery</summary>

Startup checks stay quiet with a healthy cache. If preparation fails, follow the prompt to retry or confirm restoring the recommended version. A healthy cache with signed proof can recover offline; one without proof needs network access. Failure keeps the original selection. Do not replace cached programs manually or clear app data.

</details>

<details>
<summary>What each component does</summary>

| Component | Purpose |
| --- | --- |
| yt-dlp | Parse and download videos. |
| gallery-dl | Download images and galleries. |
| Deno | Provide the downloader's JavaScript environment. |
| FFmpeg / ffprobe | Process, merge, and inspect media. |

</details>

<details>
<summary>Login startup, moving the app, and data location</summary>

Windows login startup points to `Ameow.exe`. Check shortcuts and startup after moving a portable folder. On Mac, manage system login items from the installed `Ameow.app` and approve in System Settings when prompted. Recheck after moving the app.

| Platform | User data directory (not downloads) |
| --- | --- |
| Windows | `%LOCALAPPDATA%\Ameow` |
| macOS | `~/Library/Application Support/AmeowNative` |

Settings and component caches live here; routine troubleshooting does not require clearing them.

</details>
