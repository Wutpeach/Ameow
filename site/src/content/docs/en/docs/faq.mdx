## Is there a Rust installer?

Rust has not been officially released; its installer and portable ZIP remain under controlled validation. [Electron v0.3.1](https://github.com/Wutpeach/Ameow/releases/tag/v0.3.1) is discontinued and unsupported. See [downloads](../downloads/).

## What is supported?

Current Rust supports public single YouTube and Bilibili videos, without the old extension or session import. See [links and queue](../desktop/links-and-queue/). Native macOS operation is unverified.

## Does hiding stop tasks?

No; quitting with active tasks asks for confirmation. Files use the folder captured at submission; see [missing files](../troubleshooting/missing-files/).

## When do quality and destination apply?

Both are captured on submission; changes affect later tasks. Retrying a failure retains the original values. See [quality and formats](../advanced/quality-and-formats/) and [output folder](../desktop/output-folder/).

## Can components work offline?

A healthy cache with signed proof can be recovered offline; an older cache without proof needs online bootstrap. See [download components](../advanced/download-dependencies/).

## What if a download fails?

Check the public single-video link, task message, and original output folder, then follow [download failures](../troubleshooting/download-failures/). Do not publish login details or private links.
