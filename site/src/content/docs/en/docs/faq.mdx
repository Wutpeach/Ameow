## Is there a Rust installer?

Rust has not been officially released. Version 0.5.0 is still a source version, with no public installer or signed update feed. [Electron v0.3.1](https://github.com/Wutpeach/Ameow/releases/tag/v0.3.1) is discontinued and unsupported. See [downloads](../downloads/).

## What is supported?

Current Rust source supports public single videos and some image links, and can attempt limited generic links, without the old extension or session import. See [links and queue](../desktop/links-and-queue/). Windows x64 and Apple Silicon Macs have native verification. Mac testing covers macOS 26.3 only; the declared macOS 13 minimum does not establish verification on older systems. See [first launch on macOS](../troubleshooting/macos-first-run/).

## Does hiding stop tasks?

No. Downloads continue while hidden; restore the window from the Windows tray or Mac menu bar. Quitting stops tasks and waits for safe cleanup; recovery actions appear only for cleanup problems. Files use the folder captured at submission; see [missing files](../troubleshooting/missing-files/).

## Does the cat show download progress?

No. The Compact cat is a quiet idle view; tasks, progress, and the queue appear in Full. Light theme shows a black cat, Dark a white cat, and reduced motion keeps it still. See [floating window](../desktop/floating-window/).

## When do quality and destination apply?

Both are captured on submission; changes affect later tasks. Retrying a failure retains the original values. See [quality and formats](../advanced/quality-and-formats/) and [output folder](../desktop/output-folder/).

## Can components work offline?

A healthy cache with signed proof can be recovered offline; an older cache without proof needs online bootstrap. See [download components](../advanced/download-dependencies/).

## What if a download fails?

Check the public media link, task message, and original output folder, then follow [download failures](../troubleshooting/download-failures/). Do not publish login details or private links.
