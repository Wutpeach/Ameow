Ameow is a desktop-edge entry point for downloads and quick collection. You can hand it local files, folders, web links, and browser content, then let the desktop app handle the output folder, download queue, and common preferences in one place.

If this is your first time, read in this order: "Download Ameow -> Core Concepts -> Getting Started." Check the FAQ first for common issues, then move into troubleshooting pages when you already know the symptom.

## Read by task

### Organize local files

Start with [Floating Window](./desktop/floating-window/) and [Output Folder](./desktop/output-folder/). The key rule is simple: dropping a file copies it, while dropping a folder changes the output folder.

### Download web content

Start with [Links and Download Queue](./desktop/links-and-queue/). If a page needs login state, cookies, or page context, continue to [Browser Extension](./browser-extension/).

### Install and connect the extension

Use [Browser Extension](./browser-extension/) for the full workflow. If you want the step-by-step setup path, read [Install the Extension](./extension/install/). If connection fails, go to [Connect to the Desktop App](./extension/connection/).

### Tune download results

If you care about quality, file size, or stability, read [Quality Preferences and Formats](./advanced/quality-and-formats/). If the media is headed into After Effects, continue to [AE-Compatible Formats](./advanced/ae-compatibility/).

### Troubleshoot issues

If you are not sure which page applies yet, start with the [FAQ](./faq/). If you already know the symptom, jump straight into [Troubleshooting](./troubleshooting/).
