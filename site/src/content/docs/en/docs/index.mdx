## Start here

1. Read [downloads](./downloads/) for the public Electron release and unreleased Rust source.
2. Run source on the verified Windows x64 target, open settings, and choose a destination.
3. Paste a supported public single-video link, wait for the queue to show completion, and open the result.

Current Rust does not connect to the old browser extension or provide session import or local file collection. Webpage selection is future research. See [download components](./advanced/download-dependencies/) and the [FAQ](./faq/).
