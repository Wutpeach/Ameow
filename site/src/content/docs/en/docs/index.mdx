This manual covers Ameow 0.5.0, a floating download app for Windows and Apple Silicon Macs that has not been publicly released yet. See the [release status and installation guide](./downloads/). Once you have 0.5.0, launch from the Start menu or `AmeowLauncher.exe` on Windows, or open `Ameow.app` from Finder on Mac.

<ManualFigure kind="start" lang="en" />

1. Open settings from Full's right-click menu or the tray/Mac menu bar and choose a destination folder.
2. Copy a public media link and paste it into Ameow with the shortcut shown above. First use may need network access to prepare components.
3. Wait for downloading and post-processing to finish, then double-click Full's empty background to open the destination.
