# 设置与组件诊断

## Mode

Operate

## Scope and evidence

2026-11-03 从 settings_window.rs 与 settings_components.rs 提取；根 PRODUCT.md、DESIGN.md 提供产品与视觉上下文。记录当前实现，不批准新设置、能力或平台支持。

## User and success

用户在独立窗口中选择外观与语言、检查下载位置和偏好、查看组件与版本、执行明确的更新／恢复动作或复制诊断。操作结果、等待原因与下一步必须能从当前状态中理解。

## Current composition

- 144 宽侧栏承载常规、下载、组件与诊断、关于；文字左侧使用 Lucide sliders-horizontal、download、blocks、info，图标 14、文字间距 8。主内容区可滚动，左右留白 24。
- 以系统 UI 字体为主：页面标题 18/24 Medium，正文及标签 13/20，控件 13，说明 12/20。路径、版本和诊断保留现有等宽字体例外。
- 默认动作按钮高 32、圆角 6；选择器高 28、宽 144、左右留白 10，选项高 28、菜单圆角 6；导航项高 36。开关轨道 32×18，滑块 12，透明点击区域保留 40×32。
- 简单设置行最小高度 56；常规、下载与关于省略重复副标题。常规页启动项反馈紧邻开关下方，与其他偏好留出 12 间距；关于页版本为普通右对齐数据文本。异常诊断与恢复入口移到组件版本之前，正常状态保持底部诊断入口；内容溢出时显示滚动位置提示。
- 下载位置行右侧集中“打开”和“更改”操作，间距 8；两者均使用标准按钮，高 32、左右留白 12、圆角 6。路径直接显示，右侧为独立 Lucide 复制图标按钮（32×32 点击区），完整路径提示只绑定路径文字。浅色错误正文使用局部 `#B8323C`，保留图形状态色。Tab/Shift+Tab 切换后按控件实际位置滚动，不干预随后手动滚动。
- 更新确认与恢复提示采用当前局部面板，颜色与层次以真实状态为依据。
- 组件版本使用普通数据文本右对齐；yt-dlp 的版本值／不可用状态与下拉箭头共同组成点击入口，替代原常驻详情区。浮层收纳来源、策略、检查更新与检查结果及相对时间；组件用途与更新检查错误类别通过名称／错误文字的悬停提示查看。错误原因、更新进度、恢复操作及更新确认继续直接显示。
- 组件异常以一个局部中性状态区呈现：图标和标题、具体原因、底部右对齐的复制诊断与重试操作，重试在最右侧。版本浮层宽 272、最大高度 320、圆角 8、surface 背景、细边界与柔和偏移阴影，右侧锚定且限制在窗口内；以已验证版本号与中性描边“推荐版本／自选版本”badge 为主，“来源：PyPI”为次；内容与全行更新操作之间用一条细分割线。无已验证版本时仅显示策略，不暗示已安装或可用；保留版本与目标版本有真实值时另行显示。Enter/Space 打开、Tab/方向键进入操作、Escape 关闭并返回入口；点击外部、焦点移出、主内容滚动、切换页面时关闭。以上交互已实现，最新原生运行效果仍待验证。

## Behavior and boundaries

页面消费 Coordinator snapshots 与 command replies，不拥有 runtime 文件或持久化真值。pending、cooldown、disabled、failed、recovery 与 cleanup 未确认状态保持独立；不能因文案优化提前开放动作。拖动区不置于可聚焦交互祖先内。保留 Tab/Shift+Tab、Enter/Space、方向键和 Escape 的现有路径。

## Verification when this surface changes

按影响检查浅深主题、中英文及长路径／版本、滚动裁剪、键盘焦点和选择器、pending/disabled、断网与恢复、检查冷却、更新确认和诊断反馈。只改文档不触发实际组件下载、升级或运行时切换。
