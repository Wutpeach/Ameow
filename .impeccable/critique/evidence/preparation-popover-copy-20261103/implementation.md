- 标题＋一条通俗原因／必要提示，移除失败阶段、HTTP 状态码拼接与重复复述按钮的建议。后端原始字段及诊断生成不变。
- 清理未确认／清理等待优先于旧失败：组件未能正常停止时提示暂时无法重试；等待清理时提示完成前不能重试。不出现底层线程、资源、路由等内部说明。
- 准备阶段标题依次为准备中、下载中、验证中、安装中、检查中、即将就绪；正文说明准备期间仍可粘贴视频链接。Publish 不提前宣布已就绪。Ready 保留原短暂就绪指示器行为，不新增成功弹窗。
- 活动下载保留真实字节、已知总量与百分比；未知总量只显示已下载字节。清理／异常时不展示残留下载进度。
- 取消使用“准备已停止”，不称为准备失败。中英文同步。

## 失败正文

| 原因 | 用户可见正文 |
|---|---|
| 超时 | 连接超时，请检查网络。 |
| 连接失败 | 无法连接，请检查网络。 |
| 代理不可用 | 无法使用代理，请检查代理设置。 |
| HTTP 404 | 未找到组件下载文件。 |
| HTTP 403 | 下载请求被拒绝。 |
| HTTP 429 | 请求过于频繁，请稍后重试。 |
| 其他／未知 HTTP 错误 | 暂时无法获取组件。 |
| 大小／完整性验证失败 | 下载的组件文件未通过验证。 |
| 解压失败 | 无法解压组件文件。 |
| 权限 | 无法访问组件文件夹，请检查权限。 |
| 可用性检查 | 组件暂时无法使用。 |
| 存储 | 无法保存组件，请检查空间和权限。 |
| 取消 | 需要时可重新准备。 |
| 未知 | 暂时无法确认失败原因。 |

标题继续标明对应组件；表内技术类别仅作为本记录的映射依据，不显示在弹窗。
