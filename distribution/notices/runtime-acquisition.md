# Owner-visible on-demand runtime acquisition declaration

Scope: R11 owner-only private validation materials. It is not a license approval, a legal conclusion, or a claim that runtime notices/source obligations for public redistribution are complete.

This private local validation package does not contain yt-dlp.exe, deno.exe, ffmpeg.exe, or ffprobe.exe. At first use, Ameow obtains the fixed Windows x64 publisher releases below directly from their listed HTTPS release URLs, verifies the pinned hashes in the embedded manifest, and prepares them in the current user's managed application cache. The executables are separate downloaded tools, not files embedded in the package.
