# Third-party materials

The root [LICENSE](LICENSE) is the Rust application's own MIT license, preserved from the accepted Rust package. It does not license third-party code or resources.

- [distribution/license-inputs.json](distribution/license-inputs.json) and [distribution/notices/](distribution/notices/) preserve the existing private minimum-material inventory and original notices.
- [assets/runtime-notices.md](assets/runtime-notices.md) records on-demand runtime provenance and license boundaries.
- [assets/fonts/OFL.txt](assets/fonts/OFL.txt) and [assets/brand/README.md](assets/brand/README.md) accompany embedded resources.
- [distribution/packaging.md](distribution/packaging.md) describes hash-bound private review and the independently blocked public Gate B.

The layout/name change does not approve redistribution, renew an old private review or establish complete public-release compliance. `Cargo.lock` and SPDX dependency metadata are not substitutes for actual license texts and source obligations.
