# 规范迁移来源

本目录保存 2026-11-15 将旧规范整理为 OpenSpec 时的来源映射。当前正式行为要求见 [OpenSpec](../../openspec/README.md)，更新方法见[规范维护](../spec-maintenance.md)。

- [章节映射](section-map.md)：旧章节的去向与替代依据。
- [覆盖表](coverage.json)：旧 6 份规范、695 行和 105 个标题的来源哈希及映射。
- [迁移时点的验证边界](unresolved.md)：解释原报告的范围，避免把历史结论扩大为当前产品承诺。

这些文件保留规范沿革，不是原始证据副本或当前待办清单。旧相对路径按原报告时点理解，已提交内容可用 `git show <commit>:<path>` 查询；未跟踪或忽略产物的可用性不能由 Git 推导。

迁移时采用的主要替代依据包括：下载器负责解析与选流，音轨可选；文件采用原标题与实际分辨率；gallery-dl 集合 Partial 续作保留为普通失败重试的例外；进度使用 primary 与固定两行布局；静默启动、菜单和空闲反馈以当时后续设计决定为准；发行流程使用真实签名与源码身份，旧审核文件接口退役。后续行为变化继续维护主规范与正式 change 历史，不回写成迁移时点的验收。
