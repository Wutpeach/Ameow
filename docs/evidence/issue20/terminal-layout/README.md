# 终端菜单排版修正（2026-11-04）

用户反馈：切换场景不断追加输出，操作指南逐渐被顶走。

正常交互终端改为清屏重绘当前菜单：顶部指南、当前场景、最近结果固定排列，场景目录按窗口高度分页（每页最多 12 项）。n / p 循环翻页；任意全局编号或完整名称仍可直达，成功切换后自动定位所在页。窄窗口使用名称、说明两行排列，长行按终端字符宽度截断，避免自动换行挤走指南。重定向输入/输出保持普通文本，-List 保留完整目录。
