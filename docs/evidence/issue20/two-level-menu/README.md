# 两级终端目录（2026-11-04）

用户试用后要求先选择界面，再在该界面内连续切换状态。本轮以两级目录替代上一版 84 项平铺交互目录，原截图保留作历史证据。

- 第一层按实际 EXE 场景目录的 surface 分类，依次显示折叠主界面、展开主界面、下载队列、设置、组件管理、诊断、托盘弹窗、右键菜单、退出确认；每项显示状态数。
- 第二层只显示所选界面的状态，编号从 1 开始；切换后留在本分类，b / 0 返回界面目录。进入和返回分类只浏览目录，不改变当前预览。
- 长目录继续分页，n / p 翻页；分类内编号跨页一致，可直接输入未在当前页显示的编号。完整场景名可从任意层级直达并进入对应分类。
- -List 保留完整平铺目录，编号仅作索引；-Scene / -Capture 保持原用法。只修改 PowerShell 菜单与说明，未修改 Rust 或场景目录，无需重编译。
