# 图标按钮样式一致性

退出异常页独立实现了24px命中区、12px信息图标和圆角矩形悬停底，与Full左下24px圆底、16px图标不同。本轮将同类独立图标按钮的圆底、图标尺寸和光晕归入公共样式，保留各页面的交互与密度。

- 退出异常：信息入口与Full左下保持相同24px圆底和16px图标；重试采用16px中性圆形高亮及柔和光晕；右上收起保持既有命中区、18px圆底和16px关闭图标。
- Full：失败/部分完成的复制操作也改为中性高亮，取消仍有红色强调；两处右上关闭共用圆底尺寸和光晕，位置保持一致。左下浮窗内微型复制保留8px图标与紧邻标题布局。
- 设置：独立图标操作与信息按钮用圆形交互底；路径复制复用既有icon_button，不再走另一套尺寸和样式；窗口关闭改为既有X SVG，保留键盘焦点和可访问名称。
- 队列：行操作与返回用圆形交互底和公共悬停光晕；固定轨道与操作说明保留。
- 托盘：独立更新图标改为中性圆形交互底。文字菜单行、分段选项与带版本文字的整行操作继续保留各自形态。Gallery及组件/许可页面共用上述呈现，无需新增状态。

用户在中途纠正重试不应使用红色。本轮最终候选采用中性底，早期candidate-01及native-01/native-02只保留过程证据；native-01的路径复制坐标、native-02的悬停断言已在最终交互检查中修正。最终结果以candidate-02、native-03和native-actions为准。
