用户授权一次完成普通 UI 动效，随后统一验收。本轮已完成本机实现与集中检查；主观手感等待用户验收。全部改动留在 main 工作区，未提交、未推送。

## 结果

普通 UI 由 Ameow 的原生呈现层统一控制动效，参考 motion-primitives 的 Animated Background、Transition Panel、Morphing Popover 和 Disclosure。没有安装 React 或引入网页层。三个设置 Select 改用 GPUI Base 的无样式语义根，保留键盘、焦点与无障碍能力，触发器、选项和进退动画由 Ameow 绘制。

| 区域 | 本轮结果 |
| --- | --- |
| Full 右键菜单 | 淡入、淡出和 4px 进入位移；画质选中背景滑动；操作行共用悬停背景；退出途中右键可反向打开 |
| 设置分栏 | 共用选中背景移动，前后页面短暂交接；旧页面不接受操作 |
| 设置开关 | 启动项和三个应用更新开关的滑块、轨道颜色过渡；真实设置仍等待原有确认 |
| 主题、语言、托盘图标下拉框 | 进入、退出和选项背景移动；方向键移动光标，Enter/Space 确认，Escape 取消，Tab 关闭后离开 |
| 说明与组件版本浮层 | 短位移和淡入淡出；关闭期间保留绘制并停止接受操作 |
| 许可与队列子页 | 进入、退出及返回的内容交接 |

| 托盘弹窗 | 按任务栏所在边进入、退出；操作背景平移；业务动作立即提交，退出绘制随后完成 |
| 复制反馈与提示条 | 复制图标变化有轻反馈；设置、下载路径、应用更新与复制失败提示条展开、收起 |

进入约 180ms、退出约 110ms、控件反馈约 150ms；参数仍可按用户验收调整。过渡从当前可见位置接续，减少动态时直接进入目标状态。动效不推迟命令，不增加业务状态。

与本轮前备份逐字节比较，`model.rs`、`magnetic_spring.rs`、`repair_motion.rs`、`native.rs` 和 `indicator.rs` 未改动。已验收的 6px 单层磁吸、无展开回弹、Full→Compact 特调弹性和两处 Full 关闭按钮几何保留。
