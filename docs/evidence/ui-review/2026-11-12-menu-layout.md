# 右键菜单单页布局

2026-11-12。用户批准将画质选择放回菜单首页，以右上关闭图标替代含义含糊的返回箭头。修改未提交、未推送；菜单原生点击与视觉待用户验收。

## 最终行为

- 在现有 200×200 Full 内显示单页菜单：画质三段选择、设置、隐藏到托盘、分隔线和退出。取消画质二级页及翻页状态。规格使用悬停说明；退出默认中性，悬停强调。
- 右上关闭图标和 Esc 关闭整个菜单。左右键选择画质，上下键在视觉分组间移动，Tab/Shift+Tab 可遍历选项、操作及关闭按钮。标题的非按钮区域保留拖动，其他区域消费点击。
- 保留现有异步设置 owner 和对应 generation 的回执：保存成功后关闭菜单，失败保留已确认画质并允许重新选择；旧菜单回执不能关闭新菜单。
- Full 底部没有保存状态文字。保存时仅在画质标题旁显示加载图标并禁用选项；失败时显示异常图标，原因通过悬停说明呈现。正常状态无额外标记。菜单状态字段的注释也明确其内容仅用于控件悬停说明。
- Gallery 更新 menu.root，补充最高、省流、保存中、保存失败场景，当前目录共117项。预览仍拒绝真实设置写入。
