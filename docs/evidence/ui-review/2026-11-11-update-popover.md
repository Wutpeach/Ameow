# Full 应用更新弹层调整

2026-11-11，按用户最终确认的紧凑布局完成本地实现，尚未提交；原生视觉与点击验收待用户进行。

- 更新就绪时，图标、版本号和“重启更新”组成一个原生 Button，整行只有一个动作，沿用原有 Restart 与设置页流程。移除弹层中单独的查看更新按钮和重复状态标题。
- 组件空闲时不展示准备提示；正在准备、下载、验证或存在失败/清理异常时显示组件区。独立组件 Ready 的短暂提示保留，和应用更新同时出现时省去普通 Ready 占位。
- 组件信息在上、更新按钮在下，共存时有一道分隔线。标题使用主文字色，状态颜色收在标题左侧的小圆点；正文与标题左侧对齐。
- 失败标题后紧跟现有复制图标，图标 8px、点击区域 24×24px，默认无边框和底色；悬停提示“复制诊断”，收到复制成功回执后短暂变为对勾。复制中禁用重复点击，沿用原有异步剪贴板结果。
- 可重试时，单独的“重试”按钮靠右；仍由真实的组件重试权限决定是否显示，不增加无效操作。
- 更新按钮及仅更新时的入口图标改用中性色；更新行默认无底色和可见边框，悬停才显示轻微底色，保留键盘焦点边框。
- 等待任务、已恢复版本等状态保留简短文字，点击进入设置页，不作为重启按钮。
- 增加 `full.app-preparing` 和 `full.app-conflict-copied`，更新 Full 应用更新场景说明；`app-waiting` 预览携带未完成任务。已复制场景只固定展示反馈，不发送真实剪贴板命令；切换场景时清除旧复制反馈。

## 用户验收

本轮未启动窗口或接管桌面，尚无最终版本弹层的原生截图或点击通过结论。打开新版 Gallery：

```powershell
& 'D:\Ameow\target\debug\ameow.exe' --gallery
```

鼠标移到 Full 左下角入口查看弹层：

1. `full.app-conflict`：失败标题后的复制图标足够小且紧邻标题，悬停提示“复制诊断”；红色仅用于异常标记，更新行没有常驻灰底或蓝色图标。
2. `full.app-conflict-copied`：同一位置显示对勾；此场景用于检查反馈样式，不代表实际复制成功。
3. `full.app-ready` / `full.app-preparing`：单一更新行排版正确；只有正在准备时才出现组件区。
4. `full.app-waiting` / `full.app-rollback`：保留等待/恢复文字；无“重启更新”的误导。

点击与实际排版由用户验收；工程测试不代表上述视觉与交互已经通过。
