## 亮点
- Ameow `0.3.0` 是从 `0.2.9` 以来最大的一次桌面端更新：应用底层已从 Tauri 迁移到 Electron，新的桌面外壳让启动、托盘、窗口切换、设置页、浏览器扩展联动和打包发布流程都更接近真实原生应用体验。
- 下载运行时改为由桌面端统一托管，`yt-dlp`、`gallery-dl`、抖音下载器和后续转码流程现在走更清晰的引擎路由。应用会自动准备所需运行环境，减少用户手动安装或排查依赖的成本。
- 浏览器扩展能力大幅增强：新增更完整的悬浮下载入口、页面媒体扫描、弹出面板媒体列表、当前页面优先识别、质量选择、站点登录同步和调试信息，适合在 YouTube、Bilibili、小红书、微博、Instagram、知乎、Pinterest、X/Twitter 等页面中直接捕获素材。
- 设置页重做为更清楚的分区导航，下载目录、下载后重命名、站点登录、插件/集成、更新通道等配置被重新整理，紧凑窗口里的控件布局也更一致。
- `0.3.0` 开始随 GitHub Release 一起发布浏览器扩展压缩包，并生成应用更新所需的 `latest.json` 元数据，为后续从稳定版直接检查和安装新版本打下基础。

## 下载与站点支持
- 扩展了多站点下载策略，更多图片、视频和图集会优先走更合适的下载引擎，而不是统一塞进同一条下载路径。
- 新增和强化了 `gallery-dl` 支持，覆盖 Pinterest、Instagram、小红书、微博、X/Twitter 等更适合用图库/媒体抓取器处理的场景。
- 抖音下载链路接入了托管下载器和站点会话流程，下载时可以使用应用管理的会话状态，并对输出目录结构做了整理。
- YouTube 默认更偏向扩展模式下载，质量选择、片段下载、进度反馈和失败兜底更稳定。
- Bilibili 下载恢复了片段范围与预览素材处理，兼容格式的视频会避免不必要的二次转码。
- 小红书视频和图片下载经过多轮修复，增强了拖拽素材、详情页回退、token 化链接解析、页面提示保留和媒体命名稳定性。
- 微博图片会尝试升级到更高质量地址，短链接会先展开再处理，拖拽图片下载恢复得更可靠。
- 粘贴链接下载会尽量恢复资源标题；直连下载会跟随系统代理；下载失败时保留更明确的错误码和上下文，方便后续排查。

## 浏览器扩展
- 新增页面内悬浮下载启动器，可以根据当前页面状态显示下载能力、当前任务和质量选择。
- 新增弹出面板媒体控制台，扩展可以扫描当前页面中的视频和媒体候选，并优先展示当前正在浏览或播放的素材。
- 浏览器扩展与桌面端的连接更稳，修复了应用重启后的 WebSocket 重连、首次点击下载触发不稳定、页面注入控件丢失等问题。
- 新增站点登录同步能力，扩展可以把当前页面的登录会话同步给桌面端，用于需要登录态的网站下载。
- 新增站点图标、本地站点目录、登录状态提示和隐藏站点会话目录，后续可以继续扩展更多需要登录态的网站。
- 移除了部分旧的、分散的页面按钮和遗留扩展路径，扩展入口更加集中，界面也更适合小尺寸弹窗使用。

## 桌面体验
- 紧凑窗口、图标模式、主窗口和托盘之间的切换更顺滑，减少了悬停折叠、拖拽展开、窗口强制全尺寸、完成提示和状态切换时的竞态问题。
- 下载准备、下载中、转码中、完成和失败状态的反馈重新打磨，进度环、完成勾号、队列状态和前景动画更一致。
- 拖拽文件、拖入文件夹、双击输出目录、设置输出路径等桌面交互经过重构，减少了窗口状态和输出路径不同步的问题。
- 设置页增加了分层导航和更稳定的开关/行布局，下载相关设置从通用设置中独立出来，插件页也有了后续扩展的基础结构。
- UI 主题、语言初始化、浅色主题表现、按钮/输入框/开关样式和紧凑窗口控件都做了统一调整。

## macOS 与 Windows
- macOS 打包流程经过重点修复：应用启动、托盘表现、Dock 图标隐藏、紧凑模式位置、窗口阴影、拖拽展开、输出目录交互和打包后运行时引导都更稳定。
- macOS 下载运行时改为随应用包管理，并补充了打包后 Python 运行时、下载器引导和迁移重建相关验证。
- macOS Release 产物现在以 arm64 为主，并提供定制布局的开源 DMG 包和 zip 包。
- Windows 恢复并强化了开机自启、系统代理、安装包启动、便携包渲染器加载、托盘入口和窗口任务栏行为。
- Windows 正式安装包仍是主要推荐安装方式；便携包适合手动下载使用，不建议依赖应用内自动更新。

## 应用更新
- 主窗口右下角的更新入口已经从单独的 `yt-dlp` 更新提示切换为应用版本更新提示；`yt-dlp` 相关更新能力仍保留在设置页中。
- 新增“接收预发布更新”开关。默认只接收正式版；开启后可参与 beta / rc 测试通道。
- Release 流程会随版本产出应用更新清单 `latest.json`，用于正式版检查新版本。
- 应用内更新目前优先面向 Windows 安装版；macOS 和便携包用户仍建议从 GitHub Releases 手动下载对应安装包。

## 文档与发布
- 新增公开用户文档站点，并将用户文档迁移到 `site/` 下维护，后续会通过 GitHub Pages 发布。
- Release 流程现在会同时打包桌面端、macOS 安装资产、Windows 安装包、Windows 便携包、浏览器扩展包和更新清单。
- 浏览器扩展发布资产命名为 `Ameow_0.3.0_browser_extension.zip`。

## 修复
- 修复 Electron 版下载完成后未继续进入转码的问题，最高质量下载需要转码时会继续完成 MP4 兼容处理。
- 修复取消转码、下载完成、下载后折叠窗口等情况下队列状态和前景反馈可能不同步的问题。
- 修复浏览器扩展下载按钮、质量菜单、页面注入、当前媒体识别、主题同步和弹窗滚动条样式中的多项问题。
- 修复 YouTube 分段下载、Bilibili 预览素材、小红书详情页与拖拽、Pinterest 视频命名、Instagram 登录态、微博图片质量和 X/Twitter 拖拽图片等站点问题。
- 修复直连下载、代理配置、下载输出布局、任务清理、运行时引导和支持日志导出中的多个边界情况。
- 修复设置页层级、站点登录显示、站点会话刷新、下载后重命名开关和插件入口布局中的多项问题。

## 说明
- 从 `0.2.9` 升级到 `0.3.0` 不需要手动迁移配置。
- 这是一次底层运行时、下载链路和浏览器扩展都变化较大的正式版。若你正在使用 `0.2.9`，建议优先下载安装版完成升级。
- 如果你已经安装过 `0.3.0-rc*` 测试版，可以直接安装正式版覆盖升级。
- 发布前仍建议执行一次 `0.2.9` 安装版到 `0.3.0` 正式版的应用内更新冒烟测试；如发现更新链路问题，应优先用后续 `0.3.1` 修复，而不是反复改写同一个正式标签。
